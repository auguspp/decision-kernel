## 5. Current Radar direction

### Commitment Radar

Purpose: allocate attention to previously frozen commitments that can now be resolved or falsified.

```text
frozen falsifiers
+ resolution paths
+ Human conditions where explicitly frozen
→ candidate new Evidence
```

Current v0 proves exact Research / commitment / Evidence lineage; semantic relevance remains Research cognition. Human conditions remain subordinate to frozen Decision artifacts.

The latest CATL buyback-progress disclosure remains another CATL capital-allocation variant and does **not** satisfy the requirement for a genuinely different second promotion case.

### Surprise Radar

Purpose: discover **post-Research price anomalies** in already-researched cases so the Human can allocate attention.

Eligibility is Research-first:

```text
frozen ResearchSnapshot exists before candidate anomaly
+ anomaly occurs after Research freeze
```

Historical bars before Research freeze remain useful context but are not actual current-v0 Radar observations.

The first real scheduled six-window batch has been reviewed mechanically. GigaDevice's 2026-07-21 → 2026-08-03 drawdown and Sanhua's 2026-08-19 `-7.10%` day both predate their first Full Research packages, so neither is eligible as an actual current-v0 observation/control.

The Human has now frozen a broader alert preference:

```text
CASE HAS PRE-EXISTING FROZEN RESEARCH = YES
CASE REMAINS FOLLOWED = YES
QUALIFIED PRICE ANOMALY = YES
→ MAY ALERT BY DEFAULT
```

Alert suppression requires an **explicit Human opt-out** that the case is no longer followed / no longer of interest.

Do **not** infer opt-out from:

- `WAIT`;
- `NO_ACTION`;
- Research being frozen / STOP;
- no current Human investment decision;
- lack of recent discussion;
- price moving away from an entry band.

Alert semantics:

```text
ALERT = attention notification only
ALERT != automatic Research reopen
ALERT != Fundamental Belief change
ALERT != Odds change
ALERT != Recommendation
ALERT != Action
ALERT != Investment Authority
```

Default flow after alert:

```text
Radar alert
→ Human triage
→ DEEPEN / WAIT / DROP
```

The earlier proposed experiment — earn a Human-alert `positive control` and a large-move `negative control` by repeatedly asking whether each anomaly should alert — is no longer the primary evaluation target for active followed researched cases.

The open Surprise Radar problem is now **signal quality**:

```text
what mechanically qualifies as a price anomaly?
what is ordinary price noise?
what important later evidence was preceded by a quieter path (false-negative candidate)?
```

Current state:

```text

short-lived shadow sampling = available
first real scheduled batch = mechanically reviewed
Human alert preference = frozen
valid post-Research anomaly example = NOT YET EARNED
false-negative candidate = NOT YET EARNED

```
