```text
Reality
→ Evidence / Claims
→ Radar / Attention Allocation
→ Research
→ frozen ResearchSnapshot
→ Observed Market
→ Odds
→ Decision Rehearsal
→ Human Surface
→ Human decides
```

```text
Evidence changes Belief.
Price changes Odds.

Research complete != Probability established != Odds ready.
Research explains reality.
Kernel enforces mechanical invariants.
Human owns the investment decision.
Investment Authority = NONE.
Frozen lineage is authoritative.
```

## 4. Research-method lessons already earned from Sanhua

Sanhua materially improved the Research discipline; this is not a new generic schema.

Reusable lessons already frozen in existing process gates:

```text
industry success
!= company revenue
!= listed-company profit
!= owner cash
```

Research must avoid:
- treating capacity ambition as realized volume;
- treating batch delivery as durable allocation;
- treating group capability as listed-company value capture;
- mixing assumptions from different maturity states;
- adding optionality already embedded in base earnings;
- using an underwritten earnings bridge with an un-underwritten valuation multiple;
- calling an unexplained residual “robot value” or another narrative bucket without an operating-economics bridge;
- inventing probability merely to close a valuation.

Current reusable process pointers:
- `docs/full-research-review-gate-v1.md` — earnings scope, valuation bridge, double-counting, market-expression separation, uncertainty, price reversal.
- `docs/full-research-price-implied-economics-closure-v1.md` — base → residual → required future economics → operating requirements → present-value / observed-price closure.
- `docs/dogfood/sanhua-robot-operating-economics-challenger-2026-09-03.md` — accepted case-specific proof ladder and STOP / REOPEN boundary.

Do not turn Sanhua-specific robot numbers into reusable constants. The method must prove itself on heterogeneous future cases.
