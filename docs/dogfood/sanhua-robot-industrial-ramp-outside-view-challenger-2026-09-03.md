## 0. Question

Sanhua's robot story is currently moving through:

```text
batch delivery
→ production-line ramp
```

The outside-view question is:

> When precision industrial suppliers move from prototypes / small batches into dedicated robot-related production capacity, what usually happens to utilization, price, margin, capital intensity and project return before a mature business exists?

This is a **small human-readable reference class**, not a statistical base-rate engine.

The observations are not interchangeable with Sanhua. Their purpose is to challenge hidden assumptions in the CNY3.5bn success state.

---

## 1. Executive outside-view

The small public reference set points to a much slower economic sequence than:

```text
batch delivery
→ capacity
→ mature revenue
→ mature margin
```

A more evidence-consistent sequence is:

```text
prototype / customer validation
→ pilot / small-batch line
→ capacity construction
→ customer designation / allocation remains uncertain
→ utilization ramps over years
→ ASP declines while cost/yield improve
→ depreciation + working capital arrive before full revenue
→ margin may mature
→ only then can project return / owner cash be judged
```

The strongest current outside-view observations are:

1. **Wuzhou Xinchun** — a new precision robot / intelligent-driving component project models ~31% mature gross margin but only **12.27% post-tax IRR**, with 3 years of construction and 60% / 80% / 100% utilization in years 4 / 5 / 6.
2. **Zhongda Leader** — an integrated robot-component / intelligent-actuator project models **25.84% gross margin but only 7.31% mature net margin**, with post-tax project IRR around **12.21%**.
3. **Shuanglin** — planned CNY995m for 1m roller screws + 0.5m linear-joint modules, yet in January 2026, after establishing 100k screw capacity and pilot module capacity up to 120k/year, the company still said the robot products had **not received formal designation and had little earnings impact**.
4. **Leaderdrive / Green Harmonic** — management once modeled a smooth capacity ramp and price-down path, but later actual utilization was materially below full production and a new expansion project was delayed.

These observations do **not** establish that Sanhua's robot returns will be ~12%.

They do establish that:

```text
30% gross margin
!= high incremental ROIC

capacity built
!= customer allocation secured

batch / pilot delivery
!= mature utilization

volume growth
!= stable ASP or margin
```

## 2. Reference A — Wuzhou Xinchun: mature gross margin does not imply high project return

### 2.1 Capital structure of the project

**MARKET_CONTEXT / MANAGEMENT PROJECT MODEL** — Wuzhou's 2025 refinancing inquiry describes a mixed embodied-intelligence robot + intelligent-driving precision-component project with:

```text
total investment                 CNY1.0547bn
building construction            CNY159.4m
equipment                        CNY721.2m
installation                     CNY3.0m
other construction               CNY60.6m
contingency                      CNY18.9m
initial working capital          CNY91.6m
```

Equipment alone is about 68% of total planned investment.

### 2.2 Ramp assumption

The management model assumes:

```text
construction period = 3 years
sales start = year 4
utilization year 4 = 60%
utilization year 5 = 80%
full utilization = year 6 onward
```

This is important because mature economics are not available when the physical project is first built.

### 2.3 Mature economics

At full production, the project models:

```text
annual sales = CNY1.4739bn
project gross margin = 31.08%
post-tax IRR = 12.27%
post-tax payback period including construction ≈ 6.6 years
```

The project contains both robot and automotive products, so it is **not** a robot-only return benchmark.

But it gives a useful owner-economics warning:

> A project can show ~31% mature gross margin and still produce a low-teens project IRR once construction time, full-process machinery and working capital are included.

### 2.4 Robot-related product economics inside the model

The robot-related mature product assumptions include:

```text
planetary roller screws:
  980k sets × CNY500 ASP
  unit cost CNY318.77
  GM 36.25%

micro ball screws:
  2.1m sets × CNY120 ASP
  unit cost CNY80.06
  GM 33.29%

robot-specific bearings:
  70k groups × CNY2,170 ASP
  unit cost CNY1,540.86
  GM 28.99%
```

**DERIVATION — management-model subgroup only:**

```text
robot-related mature revenue ≈ CNY893.9m
robot-related gross profit ≈ CNY305.5m
subgroup gross margin ≈ 34.2%
```

This cannot be converted into robot-project ROIC because buildings, working capital, R&D, shared equipment and operating expenses are not cleanly allocated to this subgroup.

### 2.5 Full-process internalization lowers project return relative to lighter outsourcing

Wuzhou explains why its new project's IRR is much lower than its earlier overlapping project even though gross margins are similar:

```text
new project needs land + new factory
+
more public supporting equipment
+
full-process equipment
+
longer construction period
```

while the earlier project could use existing facilities / equipment and outsource some rough processes.

**INFERENCE** — Vertical integration is an economic trade-off, not a free margin upgrade:

```text
more in-house content
→ more captured gross value
but also
→ more equipment + yield + utilization + capital burden
```

This is directly relevant to Sanhua's make-vs-buy question.

## 3. Reference B — Zhongda Leader: integrated actuator economics compress between GM and net profit

### 3.1 Project scope and capital

**MARKET_CONTEXT / MANAGEMENT PROJECT MODEL** — Zhongda Leader's robot-body component / accessory / intelligent-actuator production-line project planned investment of approximately:

```text
CNY428.9m
```

The products include robot components, integrated intelligent actuator units, large RV reducers and various geared motors.

### 3.2 Mature P&L bridge

The issuer's financing inquiry explicitly models the project after incremental fixed-asset depreciation.

At full production:

```text
revenue            CNY712.9m
cost of sales      CNY528.7m
gross profit       CNY184.2m
gross margin       25.84%
net profit         CNY52.1m
net margin         7.31%
post-tax IRR       ~12.21%
```

The model assumes:

```text
construction = 2 years
first operating year utilization = 80%
100% utilization thereafter
```

### 3.3 Research implication for Sanhua's 10% net-margin assumption

This is not Sanhua economics.

But it is a useful integrated-component reference showing that:

```text
mid-20s gross margin
→ after sales expense + management expense + depreciation + tax
→ high-single-digit net margin
```

is entirely plausible even in a management success-case model.

Therefore:

```text
SANHUA ROBOT 10% NET MARGIN
```

cannot be justified merely by citing 25-35% gross margins from adjacent precision-component businesses.

It requires a Sanhua-specific bridge through:

```text
purchased content
+ manufacturing depreciation
+ yield / scrap
+ R&D
+ SG&A
+ tax
```

## 4. Reference C — Shuanglin: physical capacity can precede commercial designation

### 4.1 Large mature investment plan

**MARKET_CONTEXT / MANAGEMENT PROJECT PLAN** — Shuanglin's 2025 financing plan proposes:

```text
roller screw + joint-module industrialization project
investment = CNY995.2m
construction = 3 years
mature capacity:
  1.0m reverse planetary roller screws / year
  0.5m linear joint modules / year
```

Wuzhou's financing inquiry reports Shuanglin's project post-tax IRR at approximately **12.48%**.

### 4.2 Real commercialization state before scale

**FACT — 2025H1** — Shuanglin had:

```text
pilot roller-screw capacity = 12k sets/year
customer samples delivered
no formal designation yet
```

### 4.3 Real state after capacity expanded

**FACT — January 2026 issuer IR** — Shuanglin then disclosed:

```text
roller-screw capacity built ≈ 100k sets/year
planned staircase expansion = 1m sets/year
module pilot line essentially completed
module pilot capacity ≈ 120k units/year
```

while saying customer validation had progressed.

Yet in the same IR record the company explicitly said:

```text
robot products had not yet received formal designation
and related revenue still had little impact on company earnings
```

### 4.4 Outside-view implication

This is a particularly clean proof-ladder observation:

```text
prototype validated
→ pilot capacity
→ 100k / 120k physical capacity
```

can occur **before**:

```text
formal customer designation
→ meaningful allocation
→ material revenue
→ mature utilization
```

Therefore a future Sanhua disclosure of robot rated capacity would upgrade manufacturing-readiness evidence, but it would not by itself establish shipment economics.

## 5. Reference D — Leaderdrive / Green Harmonic: planned utilization and realized utilization can diverge

Already preserved in the sibling proof table, the key outside-view evidence is:

**MANAGEMENT MODEL** — the new precision-transmission project originally assumed:

```text
construction = 2 years
post-construction utilization = 20% / 60% / 100%
ASP decline:
  harmonic reducer -3%/year
  mechatronic product -5%/year
```

**REALIZED OUTSIDE VIEW** — company-disclosed theoretical harmonic-reducer utilization later ran around:

```text
2023  ≈ 51.6%
2024  ≈ 42.7%
2025  ≈ 67.8%
```

and the newer expansion project was delayed partly because existing capacity utilization had been low.

This shows why management ramp schedules should not be promoted from project assumptions into realized operating facts.

## 7. What the reference class does establish

### FACT / MARKET_CONTEXT supported

Across the cases:

```text
dedicated precision production requires meaningful equipment
working capital exists alongside PP&E
construction / ramp consumes years
ASP pressure is usually modeled explicitly
formal customer designation can lag physical capacity
utilization can lag management ramp assumptions
```

### INFERENCE

For Sanhua, a durable CNY3.5bn robot profit state should eventually be underwritten as:

```text
customer demand
× actual economic allocation
× mature billable content
→ revenue

revenue
→ gross profit after purchased content / yield / depreciation
→ operating profit after R&D / SG&A
→ NOPAT

then divide by:

development capital
+ pilot / validation capital
+ production PP&E / tooling
+ working capital
+ other incremental invested capital
```

A `10% net margin` numerator without the invested-capital denominator is not owner economics.

## 8. A specific challenge to the CNY3.5bn success state

The sell-side state is:

```text
CNY35bn robot revenue to Sanhua
× 10% net margin
= CNY3.5bn net profit
```

Even if that net margin were ultimately achieved, the reference class says the Research still needs to answer:

```text
How many years before utilization reaches maturity?
How much PP&E is built before designation / allocation is secured?
How much working capital grows with revenue?
How much development capital preceded production?
How much price-down occurs during the ramp?
How much of mature margin is lost to depreciation / R&D / SG&A?
```

Without these answers:

```text
CNY3.5bn ACCOUNTING PROFIT = SUCCESS-STATE NUMERATOR
INCREMENTAL ROIC = NOT ESTABLISHED
OWNER CASH = NOT ESTABLISHED
```

## 9. Next evidence that would materially improve the outside view

The most useful next upgrades are **realized**, not planned:

1. actual first-year / second-year utilization after new robot component lines start;
2. realized ASP versus financing-project ASP;
3. realized gross margin versus modeled mature margin;
4. actual project capex versus planned capex;
5. inventory / receivable burden during ramp;
6. customer designation / allocation timing relative to capacity commissioning;
7. project delays, impairment or capacity reuse when demand arrives slower than planned.

Repeated realized evidence would eventually justify a stronger reference class.

Today it does not justify a numerical Sanhua success probability.

## 11. Current outside-view verdict

The reference class does not disprove Sanhua's ability to earn CNY3.5bn.

It changes what must be proven.

The success state is no longer sufficiently described by:

```text
volume
× value content
× share
× net margin
```

A complete industrial state also requires:

```text
ramp duration
× utilization path
× development / production capital
× working capital
× realized price-down
× conversion from accounting profit to owner cash
```

The current public evidence supports keeping:

```text
SANHUA ROBOT INCREMENTAL ROIC = NOT ESTABLISHED
SANHUA ROBOT OWNER ECONOMICS = NOT ESTABLISHED
```

until robot-specific capital and realized ramp evidence emerge.
