## 0. Question

The 35亿元 sell-side state implicitly treats robot billable content as though it can be translated directly into Sanhua revenue, margin and profit.

The missing industrial question is:

> Which actuator components are actually manufactured inside Sanhua, which are purchased or co-developed, and how does that make-or-buy choice change both margin and invested capital?

This note also tightens the linear-actuator reference class using exchange-reviewed planetary-roller-screw project economics.

---

## 1. Sanhua primary evidence does not establish full vertical integration

**FACT** — Sanhua's 2023 exchange inquiry response describes robot electromechanical actuators as integrating:

```text
transmission
+ drive
+ sensing
+ control
+ brake / bearing auxiliary content
```

The company says it integrates upstream / downstream resources including motor drive, transmission components, encoders and controllers through:

```text
supplier co-development
+
partial component self-development
```

The disclosed R&D goals specifically include:

```text
planetary roller-screw process exploration / productization
rotary-actuator motor power-density improvement
```

**FACT** — The same disclosure says the robot program is an R&D project intended to make mass production possible; it does not establish that all core components are or will be internally manufactured.

Therefore:

```text
FULL CORE-COMPONENT VERTICAL INTEGRATION = NOT ESTABLISHED
```

### Sell-side claim that must stay outside FACT

**MARKET_CONTEXT** — Dongwu's Sanhua deep-dive says motors were then internally produced and expects core components to become fully self-produced later.

That is a sell-side expectation, not issuer guidance or an established mature-state manufacturing map.

## 2. Current-stage external harmonic-reducer sourcing is now directly evidenced

A supplier-side primary filing materially improves the make-buy map.

**FACT — Fengli Intelligent / 丰立智能, April 2026 Shenzhen Stock Exchange financing inquiry response** — The issuer says that during the reporting period it had:

```text
already supplied Xingdong Era / 星动纪元 in batch
and
provided harmonic reducers to Sanhua Intelligent Controls / 三花智控 and Hechuan Technology / 禾川科技
for validation introduction or small-batch supply
```

The same filing lists Sanhua among the known customers of Fengli's new-generation precision-transmission project and says harmonic-reducer orders across the project's known customers were about CNY4.5m / more than 7,000 units as of March 25, 2026.

The filing does **not** disclose what portion of those orders belongs to Sanhua.

### What this upgrades

This evidence supports:

```text
CURRENT-STAGE EXTERNAL HARMONIC-REDUCER SOURCING / VALIDATION INTO SANHUA = FACT
```

It is stronger than the earlier inference from Sanhua's generic `supplier co-development` wording.

It establishes that, at least during the current commercialization / validation stage, Sanhua's actuator effort can source harmonic reducers from an external precision-transmission supplier.

### What it does not establish

It does **not** establish:

```text
Fengli is the only / principal reducer supplier
Sanhua's mature reducer purchase share
Sanhua will not internalize reducers later
which unnamed robot program uses the reducer
Fengli's reducer content maps one-for-one to Sanhua's current batch-delivery actuator
long-run supplier allocation or transfer price
```

Therefore the correct mature-state label remains:

```text
SANHUA REDUCER MATURE MAKE-BUY SHARE = NOT ESTABLISHED
```

The new fact changes the burden of proof, however. A mature model that assumes `100% internal reducer value capture` must now explain how Sanhua moves from an observed external validation / small-batch supply relationship to full internalization, and what incremental capital that transition requires.

## 3. Why make-or-buy changes both numerator and denominator

A robot actuator integrator can reach the same customer billable value through very different economic structures.

### World A — more purchased content

```text
customer actuator price
- purchased reducer / screw
- purchased encoder / sensor / electronics
- assembly / test / manufacturing cost
= integrator gross profit
```

Economic characteristics:

```text
lower internal fixed-asset burden
lower development / machining capital for purchased parts
but lower captured value added
and supplier margin sits upstream
```

### World B — more internal content

```text
customer actuator price
- internal material / labor / depreciation / yield loss
- internal development cost
= vertically integrated gross profit
```

Economic characteristics:

```text
potentially higher captured value added
but requires more PP&E / tooling / working capital / process know-how
and exposes Sanhua directly to utilization / yield / depreciation risk
```

Therefore:

```text
higher vertical integration
!= automatically better owner economics
```

The relevant test is:

```text
incremental NOPAT gained from internalizing a component
/
incremental capital required to internalize it
```

not simply whether the component is produced in-house.

## 4. A primary reference for mature planetary-roller-screw pricing

Five Continents Spring / 五洲新春 disclosed an exchange-reviewed financing model for a humanoid-robot and intelligent-vehicle precision-component project.

### 4.1 Mature project assumptions

**FACT — management project model, exchange-reviewed filing**:

```text
planetary roller screw ASP = CNY500 / set
unit cost = CNY318.77 / set
gross margin = 36.25%
```

The same project assumes:

```text
98万 sets/year new planetary-roller-screw capacity
14 roller screws per humanoid robot
```

This is not a realized market-clearing price and not Sanhua pricing.

It is nevertheless a much stronger industrial reference than an uncited round number because the issuer uses it in a regulated capital-raising project model with explicit capacity, unit cost and equipment assumptions.

### 4.2 Implication for Dongwu's CNY2,000 mature roller-screw assumption

Dongwu assumes roughly:

```text
CNY2,000 / mature roller screw
```

Five Continents' project model uses:

```text
CNY500 / roller screw
```

The two are not necessarily contradictory because:

- specification / load / size may differ;
- customer architecture may differ;
- project assumptions may prove too optimistic;
- realized humanoid mass-production pricing is not yet established.

But the comparison establishes one important point:

> A CNY2,000 mature roller-screw ASP is not a unique industrial endpoint supported by public primary evidence.

Therefore:

```text
CNY2,000 MATURE ROLLER-SCREW ASP
= SELL-SIDE ASSUMPTION
= NOT INDEPENDENTLY ESTABLISHED
```

## 5. Architecture itself can rewrite unit value

Five Continents' reference architecture uses:

```text
14 planetary roller screws / robot
+ 30 micro ball screws / robot
```

Dongwu's Sanhua model uses:

```text
8 roller-screw linear actuators
+ 6 T-screw linear actuators
```

These are different architecture / component-count assumptions.

**DERIVATION — screw-only value, not complete actuator value:**

Five Continents project model:

```text
14 × CNY500
= CNY7,000 planetary-roller-screw bill / robot
```

Dongwu screw assumption:

```text
8 × CNY2,000
= CNY16,000 planetary-roller-screw bill / robot
```

The difference cannot be interpreted simply as price-down because the assumed number and type of screw components differ.

**INFERENCE** — The humanoid `value per robot` is partly an architecture variable, not merely a supplier ASP variable.

Therefore any mature CNY50k bridge must specify:

```text
component count
× component type
× specification
× unit price
```

before it can be treated as economically comparable across sources.

## 6. Linear precision transmission has visible equipment intensity

Five Continents provides a useful component-specific capital reference.

For the 98万 sets/year planetary-roller-screw capacity, disclosed major production equipment totals approximately:

```text
CNY223.15m
```

across 332 pieces of equipment, including large numbers of grinders plus machining, heat-treatment, inspection and assembly equipment.

**DERIVATION — outside-view equipment intensity:**

```text
CNY223.15m / 980k annual sets
≈ CNY228 equipment capital
per one unit of annual roller-screw capacity
```

This excludes allocated buildings, land, common utilities, development capital and project working capital.

It is therefore an **equipment-only outside-view intensity**, not total invested capital.

### 6.1 What that means for a 1m-robot success state

If an actuator supplier used Dongwu's architecture:

```text
8 roller screws / robot
× 1m robots
= 8m roller screws/year
```

and chose to internalize all of those screws at a manufacturing intensity similar to the Five Continents project:

```text
8m × ~CNY228
≈ CNY1.82bn equipment capital
```

This is a **DERIVATION / reference-class diagnostic**, not a Sanhua capex forecast.

If instead the supplier buys those screws externally, that CNY1.82bn-like equipment burden does not sit directly on the integrator's balance sheet — but the screw supplier's depreciation, working capital and profit become purchased-content cost in the actuator BOM.

This is why make-or-buy is the missing bridge between:

```text
customer billable value
```

and

```text
Sanhua incremental ROIC
```

## 7. The full Five Continents project reinforces the capital point

**FACT** — The combined humanoid-robot + intelligent-vehicle project has:

```text
total investment = CNY1.054746bn
engineering cost = CNY883.649m
equipment = CNY721.225m
initial working capital = CNY91.599m
```

The project includes multiple product categories, so these figures cannot be assigned wholly to humanoid components.

**FACT** — The company explicitly says the project includes 98万 roller screws/year and 210万 micro ball screws/year, plus robot bearings and automotive screw products.

**FACT** — The project model's post-tax IRR is only **12.27%**, with a **6.60-year** payback period including construction.

This is management underwriting, not realized return.

Still, it is a useful outside view:

> Even a project that assumes attractive component gross margins can require substantial fixed capital and deliver only low-teens modeled project IRR once the full production system is included.

That is directionally important for Sanhua's owner-economics question.

## 8. Implication for the 35亿元 success state

The sell-side bridge:

```text
1m robots
× CNY50k billable content
× 70% Sanhua share
× 10% net margin
= CNY3.5bn profit
```

still omits a state variable that should now be explicit:

```text
MAKE / BUY MIX
```

A more economically complete bridge is:

```text
robot units
× customer allocation
× actuator architecture
× customer billable price

then split billable content into:

internally manufactured content
+
purchased content

internally manufactured content
→ internal gross profit
→ internal PP&E / tooling / WC / development capital

purchased content
→ lower internal capital
→ lower internal value capture
→ upstream supplier margin embedded in BOM
```

The Fengli evidence means the current observed system already contains at least one externally sourced / validated transmission path.

Only after mature make-buy is established can Research ask whether a 10% net margin corresponds to an attractive owner return.

## 10. Highest-value next evidence

The next evidence that would materially improve the model is:

1. Sanhua issuer disclosure identifying which robot components are already self-produced at batch-delivery stage;
2. supplier-side disclosure quantifying reducer / screw / encoder / sensor shipments into Sanhua's actuator assembly;
3. customer or engineering disclosure showing the mature actuator count and architecture;
4. realized roller-screw ASP / cost / yield from a genuine large-volume humanoid ramp;
5. Sanhua robot-specific equipment, production capacity, working capital and utilization;
6. realized gross margin by robot actuator / new-business product.

Until then, `CNY50k customer content` cannot be translated directly into `CNY50k Sanhua economic content`.
