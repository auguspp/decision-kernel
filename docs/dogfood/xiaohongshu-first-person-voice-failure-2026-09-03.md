# Xiaohongshu Voice Failure — Unnecessary First Person — 2026-09-03

Status: **REAL DOGFOOD FAILURE / VOICE CALIBRATION**

Observed in Sanhua dogfood:

- `这才是我觉得36.3元最关键的地方` should normally be `这才是36.3元最关键的地方`.
- `所以这次我重新拆了一遍` should normally be deleted, or replaced by the actual analytical action such as `先把主业和未来拆开算`.

General rule:

> First person is expensive.

Use `我` only when the author is supplying genuine information that cannot be expressed more cleanly without it: a real personal judgment, an explicitly supplied prior view, or a real change of view. Do not use first person to manufacture presence, narrate research/writing steps, soften an analytical statement, or add emphasis.

Typical rewrite targets:

```text
这才是我觉得X最关键的地方
→ 这才是X最关键的地方

所以这次我重新拆了一遍
→ [delete]
or
→ 先把A和B拆开算

我更想看到的是……
→ 接下来更值得看的是……

我更愿意把X放在18-20倍
→ X放在18-20倍更容易解释
```

Do not ban first person globally. Historical high-read notes sometimes use it when the personal stance itself is informative. The failure is **unnecessary narrator presence**, not the pronoun itself.
