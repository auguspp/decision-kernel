## 2. The Thailand subsidiary / factory is broader than the robot project

The Thailand robot project must not be confused with all capital inside Sanhua Intelligent Drives Thailand.

### 2.1 Prior automotive BOI project

**FACT — Thailand BOI / OSOS** — Before the THB1.8bn humanoid-actuator project, Sanhua Intelligent Drives had already received investment promotion for **advanced automotive components** supplying BYD, Volvo and Tesla, with investment above **THB3.2bn**.

Therefore:

```text
THAILAND SUBSIDIARY CAPITAL
!= ROBOT-ONLY CAPITAL
```

The subsidiary already had a material non-robot industrial program before the humanoid-actuator approval.

### 2.2 Broader issuer drive-factory project

**FACT — Sanhua 2026H1 report** — The issuer separately discloses a `泰国驱动厂房项目`:

```text

opening CIP = CNY371.54m
H1 additions = CNY187.75m
H1 transfer to fixed assets = CNY2.86m
ending CIP = CNY556.43m
```

This is strong evidence that the Thailand drive operation is absorbing real capital and has begun transferring some construction in progress into fixed assets.

However:

```text
THB1.8bn BOI humanoid-actuator project
!= automatically the same scope as
USD140m issuer Thailand drive-factory project
```

and neither can be equated to the subsidiary's entire asset base because the same subsidiary also has the earlier >THB3.2bn advanced-automotive program.

Current scope state:

```text

MAPPING AMONG THE THREE CAPITAL SCOPES = NOT ESTABLISHED
```

This distinction prevents both errors:

