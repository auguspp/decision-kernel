## 4. The mature roller-screw price problem changes direction

The earlier sell-side Sanhua bridge assumed roughly:

```text
roller screw ≈ CNY2,000 / unit
complete roller-screw linear actuator ≈ CNY3,000 / unit
```

Public manufacturer project economics now show that the mature screw price may plausibly move materially **below** CNY2,000.

### 4.1 Wuzhou Xinchun management project model

**MARKET_CONTEXT / MANAGEMENT PROJECT ASSUMPTION** — In its 2025 refinancing inquiry response, Wuzhou Xinchun models its embodied-intelligence / automotive core-component project at mature production with:

```text
planetary roller-screw volume = 980k sets / year
ASP = CNY500 / set
unit cost = CNY318.77 / set
gross margin = 36.25%
```

The company says the project can support roughly:

```text
70k humanoid robots
```

at full production.

**DERIVATION**:

```text
980k screw sets / 70k robots
= 14 screw sets / robot
```

which is broadly consistent with common humanoid architecture counts in public sell-side work.

This is a **project model**, not realized mass-production pricing.

But it is still a manufacturer-backed mature-economics assumption rather than a generic TAM estimate.

### 4.2 Dongwu's own later robot-industry price path

**MARKET_CONTEXT** — Dongwu's broader robot-industry report models planetary roller-screw ASP at approximately:

```text
2025E: CNY10,000
2026E: CNY9,000
2027E: CNY5,400
2028E: CNY2,700
2029E: CNY1,620
2030E: CNY1,296
2035E: CNY897
```

A later Dongwu equipment report also places 2030 overseas roller-screw ASP around CNY1,300 and China around CNY1,000.

Therefore even inside sell-side work:

```text
CNY2,000 mature screw ASP
```

is not a stable terminal constant.

### 4.3 Research implication

The relevant question is no longer only:

> Can roller screws become cheap enough for a CNY3,000 linear actuator?

It is also:

> If roller screws commoditize to CNY500-1,300, how much of the old actuator revenue pool disappears, and who captures the remaining integration economics?

Lower upstream component cost can help Sanhua's margin **if the customer billable module price falls less than BOM cost**.

But lower upstream component price can hurt Sanhua's revenue opportunity **if customer price-down captures most of the savings**.

That spread is currently `NOT ESTABLISHED`.

## 5. Dongwu's own mature whole-actuator value is not stable at CNY50k

Dongwu's February 2025 Sanhua deep-dive uses the familiar mature body-actuator bridge:

```text
14 rotary × ~CNY1,500
+ 8 roller-screw linear × ~CNY3,000
+ 6 T-screw linear × ~CNY1,500
≈ CNY54k literal sum
≈ CNY50k headline
```

But Dongwu's broader robot-industry report uses a different mature-state system path.

For 2030 it models:

```text
rotary actuator demand / robot ≈ 14 units
rotary actuator ASP ≈ CNY1,450

linear actuator demand / robot ≈ 9 units
linear actuator ASP ≈ CNY2,075
```

**DERIVATION**:

```text
14 × CNY1,450 = CNY20,300
9 × CNY2,075 = CNY18,675

combined body-actuator value ≈ CNY38,975 / robot
≈ CNY39k / robot
```

This is not an independent forecast.

It is a **sell-side internal-consistency diagnostic**.

It shows:

```text
CNY50k mature value content
!= stable constant even within one research house's public scenario work
```

Architecture, component count, horizon and price assumptions move the number materially.

## 7. A narrower roller-screw price-down sensitivity

Dongwu's Sanhua deep-dive embeds approximately CNY2,000 of roller-screw content inside each of eight roller-screw linear actuators.

Wuzhou's mature project model uses CNY500 per roller screw.

For a mechanical sensitivity only, if:

```text
8 roller screws / robot
CNY2,000 → CNY500 each
```

and **all other actuator content / pricing stays unchanged**:

```text
value reduction = 8 × CNY1,500
= CNY12,000 / robot
```

The literal CNY54k body-actuator bridge would become:

```text
CNY54k - CNY12k
= CNY42k / robot
```

Again, this is not a forecast: a complete linear actuator does not necessarily pass through screw price one-for-one, and architecture / margin / other component values can change.

But it shows why the mature screw price matters to the revenue pool.

Under the original 1m / 70% / 10% arithmetic, CNY42k would imply:

```text
≈ CNY2.94bn profit
```

and at 50% mature share:

```text
≈ CNY2.10bn profit
```

The purpose is not to promote CNY42k.

It is to demonstrate that the CNY35bn profit state is sensitive to **component commoditization**, not just robot unit volume.

## 8. Outside-view capital evidence from a screw manufacturer

Wuzhou's same 2025 project gives unusually concrete precision-manufacturing equipment evidence.

**FACT / MANAGEMENT PROJECT DISCLOSURE** — Total project investment is approximately CNY1.055bn across multiple products.

Within the project, equipment specifically allocated to planetary roller-screw manufacturing is disclosed at approximately:

```text
CNY223.15m
```

including:

```text
206 grinding machines
35 Swiss-type lathes
55 CNC lathes
16 gear hobbing machines
9 quenching machines
5 straightening machines
inspection / test equipment
3 screw-nut assembly lines
```

for planned mature roller-screw sales volume of approximately 980k sets/year.

**DERIVATION / REFERENCE CLASS ONLY**:

```text
roller-screw-specific equipment
≈ CNY228 per unit of annual rated screw output
```

This excludes an allocated share of:

```text
buildings
land / construction overhead
working capital
R&D
maintenance capital
```

and is not a Sanhua capital estimate.

### Scaling diagnostic only

If one mechanically scaled only this disclosed equipment intensity:

```text
8m roller screws / year
→ roughly CNY1.82bn of equipment

14m roller screws / year
→ roughly CNY3.19bn of equipment
```

This is **not** a forecast and should not be inserted into Sanhua ROIC.

Its purpose is to show the order of industrial machinery required if a supplier chooses full-process internal production rather than external sourcing.

The capital trade-off therefore matters:

```text
buy screw externally
→ lower fixed capital
→ upstream supplier captures margin

make screw internally
→ more value capture possible
→ more precision equipment / yield / utilization risk
```

Vertical integration can increase gross value capture while simultaneously increasing the denominator of incremental ROIC.
