## 3. The key anti-error rule: no peak × peak

2026H1 reported economics are extraordinary:

- H1 revenue ~CNY11.566bn;
- parent NP ~CNY6.857bn;
- deducted parent NP ~CNY4.883bn;
- H1 storage revenue ~CNY9.827bn;
- H1 storage GM ~67.57% versus FY2025 ~42.84%;
- H1 reported NP contains ~CNY1.974bn of non-recurring items, including material financial-asset gains.

The correct first-entry question is **not**:

```text
peak earnings × premium platform multiple = value
```

It is:

```text
what earnings survive normalization?
×
what multiple survives recognition of cycle risk?
=
what terminal value can the entry price tolerate?
```

A first tranche that only works under `CNY18–20.5bn earnings + 21–22x P/E` is not a margin-of-safety entry. It is a favorable-world entry.

## 10. What would make the first tranche thesis clean

A clean first-entry thesis should be expressible without peak × peak:

```text
2026 specialty-memory economics are unusually strong
+ some of the earnings uplift is structural / qualification / product-share improvement
+ MCU / custom memory provide a growing non-cycle base
but
+ storage margins normalize materially from H1 peak
+ terminal multiple recognizes cyclicality
→ entry price still offers acceptable return in partial normalization
→ rapid normalization remains survivable
→ high-core / right-tail worlds are upside, not requirements
```

If the thesis instead reads:

```text
memory stays tight through all of 2027
+ margin remains near peak
+ platform earns a premium multiple
```

then the first tranche is not a margin-of-safety trade. It is a directional cycle bet.
