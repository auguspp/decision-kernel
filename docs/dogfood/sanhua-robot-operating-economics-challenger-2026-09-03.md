## 3. Product architecture / CNY50k value content

**FACT — Sanhua primary** — Robot electromechanical actuators integrate:

```text
transmission
+ drive
+ sensing
+ control
+ brake / bearing auxiliary content
```

The system uses supplier co-development plus partial component self-development. Sanhua has motor capability and has identified planetary-roller-screw process / productization and higher-power-density motors as R&D directions.

### Sell-side mature-state decomposition

Dongwu's reference can be decomposed approximately as:

```text
14 rotary actuators × CNY1,500 = CNY21,000
8 roller-screw linear actuators × CNY3,000 = CNY24,000
6 T-screw linear actuators × CNY1,500 = CNY9,000
--------------------------------------------------
literal total ≈ CNY54,000
```

So the familiar `CNY50k` is a rounded structured sell-side mature-state assumption, not a disclosed Sanhua ASP.

### Rotary budget challenge

A complete CNY1,500 rotary actuator must still contain:

```text
motor
+ reducer
+ driver
+ clutch / brake
+ force sensing
+ encoder
+ bearing / structure
+ assembly / test
+ supplier margin
```

Public harmonic-reducer evidence shows realized prices from aggressive new-entrant levels in the high hundreds of yuan to broader incumbent averages around the low thousands.

Therefore a CNY1,500 **complete** rotary actuator requires coordinated subsystem-wide cost-down, not merely a cheap reducer.

### Linear / roller-screw challenge

Dongwu's mature roller-screw assumption is roughly CNY2,000 per screw.

An exchange-reviewed Five Continents Spring project model instead uses:


and assumes 14 roller screws per humanoid robot.

This does not prove CNY500 is the future clearing price; specification and architecture differ.

It does establish:

```text
CNY2,000 mature roller-screw ASP
!= unique publicly supported mature endpoint
```

## 4. Price-down: manufacturing cost-down vs content-down

The early `CNY200k+ → ~CNY50k` path cannot be treated as one generic 75% price reduction.

### Manufacturing / sourcing cost-down

```text
same / similar content
+ yield improvement
+ automation
+ utilization
+ supplier price-down
+ localization / vertical integration
→ lower customer price
```

This can preserve supplier value added if costs fall fast enough.

### Architecture / content-down

```text
customer redesign
+ fewer drive units
+ simpler mechanism
+ integrated functions
+ lower actuator count / specification
→ lower customer bill because content disappears
```

This can permanently reduce supplier revenue opportunity even with efficient manufacturing.

Mature value therefore has to be underwritten as:

```text
component count
× component type
× specification
× mature price
```

not `early value × generic price-down percentage`.
