## 0. Purpose

This experiment tests a narrow Research Method question:

> **When several admissible economic Reference Frames are applied to the same PIT record, does their divergence reach causal worlds, duration, terminal economics and Odds-relevant outcomes strongly enough to justify withholding a full cardinal probability measure?**

The external prompt for this experiment is the useful idea in `decision-lab`: analyze the same problem through multiple reasonable methods / assumptions and inspect convergence and divergence rather than committing to the first analytical path.

Decision Kernel deliberately modifies one implication:

```text
DIVERGENCE
= potentially strong evidence of model / frame dependence

CONVERGENCE
= weak robustness evidence only
!= Truth
!= automatic confidence upgrade
!= automatic probability qualification
```

This experiment also rejects the opposite overreaction:

```text
any narrative divergence
-> probability not established
```

That rule would be equally wrong.

For divergence to count against cardinal probability, it must pass all of the following:

```text
admissible frame difference
-> materially different causal worlds / duration / terminal economics
-> materially different Odds-relevant outcomes
-> current PIT evidence cannot reasonably resolve the disagreement
```

If the frames merely tell different stories while producing essentially the same owner economics and world surface, the experiment should conclude that the apparent divergence is not decision-relevant.

This is docs-only dogfood. It does not create:

- a new Research schema;
- an Analysis Divergence entity;
- a confidence score;
- a voting system;
- a new probability-readiness enum;
- numerical Odds;
- a Human investment decision;
- a second wake gate;
- an automation;
- any investment authority.

## 2. Frame admissibility gate

A frame is admissible only if the same PIT evidence provides a reasonable economic-model-class basis for it.

The goal is not to manufacture four stories.

### Frame A — specialty-memory scarcity cycle

**Admissible: YES.**

Economic model class:

> **A fabless specialty-memory beneficiary whose 2026-27 earnings are dominated by scarcity rent that should mean-revert materially as supply, substitution and customer resistance respond.**

Why this is reasonable:

- storage dominates current revenue and profit;
- storage GM ~67.57% is exceptional relative to prior company history;
- the company itself warns current prices are historically high and not indefinitely sustainable;
- independent industry evidence contains explicit future supply response;
- historical memory economics support strong cyclicality;
- the non-memory earnings base is real but currently much smaller than storage.

This frame is not allowed to assume immediate normalization merely because memory is cyclical.

### Frame B — structural product-share / platform rebase

**Admissible: YES.**

Economic model class:

> **A multi-product fabless platform using product breadth, long qualification cycles, domestic substitution and customer-share gains to retain materially higher post-cycle earnings than old history would imply.**

Why this is reasonable:

- MCU revenue grew materially rather than simply following memory ASP;
- NOR / DRAM / SLC breadth and industrial / automotive qualification create real customer stickiness;
- custom-memory and adjacent products provide a plausible future second profit engine;
- scarcity can create customer / qualification gains that survive the peak pricing period;
- a fabless model can convert product/share gains into high capital efficiency if margin capture survives foundry economics.

Limitation:

> H1 storage revenue is still almost seven times MCU revenue. Current realized mix does not prove that non-cycle businesses can carry group economics after storage normalization.

### Frame C — hybrid cycle + structural platform

**Admissible: YES.**

Economic model class:

> **A cycle-amplified fabless platform: extraordinary specialty-memory scarcity drives the current profit spike while a genuine structural product platform develops underneath it.**

Why this is reasonable:

- it explains both the exceptional storage-margin evidence and genuine MCU / product-breadth evidence;
- it does not require peak economics to be permanent;
- it does not require all platform progress to be dismissed as cycle noise;
- it matches the two-sided CXMT relationship: supply access can be durable while economics remain cycle-sensitive.

This is the retained frame in the current Decision Hygiene dogfood.

### Frame D — duration / post-cycle-floor underwriting lens

**Admissible: YES, WITH CORRELATION WARNING.**

Economic model class / lens:

> **Value is driven less by one-year peak earnings than by how long specialty-memory scarcity persists, how much owner cash is harvested during that period, and where normalized 2030+ earnings settle after scarcity fades.**

Why this is reasonable:

- 2027 tightness has stronger support than ordinary one-year mean reversion;
- independent evidence makes 2028 specialty-DRAM tightness a serious world;
- 2029 remains plausible but unestablished;
- current published 2028 expectations already contain high-duration worlds;
- the 2030 earnings floor dominates look-through value if investors begin discounting normalization before the accounting peak ends.

Correlation warning:

> Frame D is not a fully independent economic species from Frame C. It is partly a different underwriting lens applied to the same hybrid business. It must not be counted as a fourth independent vote.

### Admissibility verdict

```text
A = admissible model class
B = admissible model class
C = admissible hybrid model class
D = admissible duration / terminal-economics lens, but correlated with C
```

The experiment therefore has roughly **two genuinely opposed model classes (A vs B), one synthesis frame (C), and one correlated valuation/duration lens (D)** — not four independent experts.

That distinction itself is an anti-confidence-machine result.

## 3. Pre-expectation underwriting by frame

Published sell-side forecasts remain hidden in this section.

### 3.1 Frame A — scarcity cycle

Pre-expectation belief:

1. The 2026 recurring earnings inflection is real; H1 deducted NP and OCF are too large to dismiss as one-off accounting gains.
2. The H1 storage-margin regime is exceptional and should not be capitalized as steady state.
3. 2027 can remain strong because mature-node specialty supply is genuinely tight, but duration must be earned product by product.
4. The natural post-cycle prior is **material earnings normalization**, with only a modest upward adjustment for the larger MCU / platform base.
5. The main falsifier of this frame would be strong non-memory gross-profit scaling plus storage margins remaining structurally high after supply begins to normalize.

Pre-expectation causal world surface:

```text
strong 2026 / potentially strong 2027
-> supply / buyer response
-> meaningful storage-margin normalization
-> non-memory growth cushions but does not prevent a large earnings decline
-> normalized model class remains cyclical / low-to-mid-teens operating multiple territory
```

This frame naturally treats the lower normalized-earnings worlds in the existing stress work as more structurally coherent than the durable-platform right tail, but **no probability is assigned**.

### 3.2 Frame B — structural share / platform rebase

Pre-expectation belief:

1. Scarcity explains a large share of the current margin spike, but it can also accelerate qualification and durable customer-share gains.
2. MCU growth, custom-memory commercialization and product breadth are evidence that the company is not merely a single-product memory price taker.
3. Post-cycle earnings can remain materially above prior history if customer positions and non-storage gross profit survive the ASP normalization.
4. The main unknown is not whether storage margins fall from 67.57%; they probably do. The unknown is **how much retained share / mix / product value remains after they fall**.
5. A structurally higher model class requires realized post-cycle ROIC and owner cash, not just revenue diversification.

Pre-expectation causal world surface:

```text
scarcity windfall
+ qualification / customer-share gain
+ MCU / custom-memory scale
-> partial storage-margin normalization
-> higher post-cycle earnings floor
-> potentially higher terminal multiple than a pure memory cyclical
```

This frame makes the higher-floor worlds economically admissible before seeing sell-side forecasts, but does not prove them.

### 3.3 Frame C — hybrid

Pre-expectation belief:

1. The business is simultaneously experiencing a genuine cycle windfall and genuine structural product development.
2. A broad world set is required because both fast normalization and durable rebase remain coherent.
3. The central unknown is the decomposition:

```text
2027 earnings
= scarcity rent
+ retained product / customer economics
```

4. The current PIT can identify variables and resolution paths, but not cleanly separate those two terms.
5. Research can therefore be complete enough while probability remains incomplete.

Pre-expectation causal world surface:

```text
fast normalization
<-> extended scarcity with partial platform support
<-> durable platform rebase
```

The hybrid frame is intentionally broad rather than probabilistically convenient.

### 3.4 Frame D — duration / post-cycle floor

Pre-expectation belief:

1. 2027 tightness is strongly supported.
2. 2028 specialty-DRAM tightness is a serious world; broad NAND cannot be generalized into the same duration claim.
3. 2029 tightness is a Human thesis / plausible world, not established fact.
4. Even if 2029 earnings remain very high, investor returns can be poor if 2030 normalized earnings fall sharply and the multiple compresses before the peak ends.
5. Owner cash harvested during 2027-29 matters, but it cannot repair a low post-cycle earnings floor by itself.

Pre-expectation causal world surface:

```text
duration of scarcity
x Giga margin capture
x owner-cash conversion
x 2030 normalized earnings floor
-> look-through owner value
```

The frame is deliberately terminal-economics-first.

## 5. Expectation / anchoring audit per frame

### 5.1 Frame A audit

The published forecasts challenge a simplistic version of Frame A.

They show that many market participants already model earnings remaining high through 2027 and often 2028.

What changes:

- Frame A must retain an extended-scarcity world as serious market context;
- immediate / one-year mean reversion is not a fair representation of published expectations;
- the frame's edge, if any, must be about **how much of those high earnings survive after supply response**, not that analysts forgot cyclicality exists.

What does **not** change:

- sell-side forecasts do not prove durable post-cycle economics;
- high 2028 estimates can still be temporary scarcity-duration models;
- the company / industry cycle warning remains admissible evidence.

Anchoring risk:

> A cycle analyst can anchor on historical mean reversion and underweight a genuine duration / qualification rebase.

### 5.2 Frame B audit

The published forecasts are broadly compatible with a higher-earnings platform story, but they create the opposite anchoring risk.

What changes:

- high 2027-28 earnings cannot be claimed as an undiscovered structural-share view; the market already models many high-earnings worlds;
- the differentiated claim must be about **retained post-cycle economics**, not merely high 2028 EPS.

What does **not** change:

- analyst forecasts do not distinguish cleanly between scarcity rent and platform economics;
- high forecast numbers can be produced by peak-ish margin assumptions without proving a structural rebase.

Anchoring risk:

> A platform analyst can read high published estimates as confirmation that product/share gains are durable when the models may simply extrapolate a long cycle.

### 5.3 Frame C audit

The expectation evidence mostly confirms that the live debate is already broad.

What changes:

- the serious high-duration worlds must remain in the Research set;
- the original v1 narrow world set was indeed incomplete.

What does not change:

- the sell-side panel does not resolve how much is cycle versus platform;
- the coexistence of high earnings forecasts and lower valuation multiples is consistent with a market that recognizes both earnings strength and duration / terminal risk.

Anchoring risk:

> A hybrid frame can become unfalsifiably broad unless it explicitly states which observations would move it toward cycle or platform dominance.

### 5.4 Frame D audit

The expectation evidence kills the weak variant thesis:

> “2028 will still be good.”

That view is already materially present in published models.

A differentiated duration thesis must instead concern:

- 2029 scarcity duration;
- who captures the scarcity rent;
- owner-cash conversion;
- the 2030+ normalized earnings floor;
- the multiple investors apply **before** the accounting peak ends.

Anchoring risk:

> A duration analyst can mistake “longer than normal” for “long enough to create attractive owner returns at any price.”

## 11. Discriminating observables / resolution paths

The disagreement should narrow only when new admissible evidence arrives.

### Evidence favoring the cycle frame

- storage GM compresses materially as new capacity arrives;
- storage ASP / volume normalize before non-memory gross profit becomes large enough to offset;
- CXMT / foundry cost absorbs a large part of the scarcity rent;
- inventory / receivables rise and OCF conversion weakens near the turn;
- 2028-29 earnings expectations roll over because of realized operating evidence;
- post-cycle NP trends toward the lower stress floors.

### Evidence favoring the structural-share frame

- MCU / custom-memory / adjacent gross profit becomes materially larger;
- customer qualification / product share persists after memory ASP growth slows;
- storage GM settles structurally above the old-cycle baseline despite supply response;
- strong owner cash persists after working-capital normalization;
- post-H-share capital earns attractive incremental ROIC;
- post-cycle earnings remain materially above old-cycle floors after scarcity visibly eases.

### Evidence discriminating duration specifically

- product-specific contract-price trajectory for niche DRAM / SLC / relevant NOR;
- actual mature-node and domestic DRAM capacity ramp timing;
- realized foundry pricing / margin capture;
- 2028-29 inventory and customer qualification behavior;
- 2030 earnings evidence once the market begins discounting normalization.

Resolution principle:

> **Do not resolve a Frame battle with a price move or an analyst target-price change. Resolve it with admissible evidence on the causal disagreement.**

## 13. Failure-condition audit

The experiment was designed to allow a useful failure result.

Did all four frames turn out to be independent, strongly divergent models?

**No.**

Important negative finding:

> **Frame C and Frame D overlap materially. Frame D is mainly a duration / terminal-economics lens on the hybrid frame, not an independent economic model class.**

Therefore it would be wrong to say:

```text
4 models ran
4 models disagreed
-> probability blocked
```

The real evidence is narrower:

```text
cycle-dominant Frame A
vs
structural-share Frame B
```

produce materially different post-cycle economics; Frame C preserves the unresolved mixture; Frame D exposes the value sensitivity of that unresolved mixture.

This means Analysis Divergence is useful **only if it remains causal and non-voting**.

If future dogfoods repeatedly show that supposedly different frames collapse to the same owner-economics surface, no dedicated Analysis Divergence framework should be created.

---

## 14. Method result

This dogfood supports a narrow method hypothesis:

> **Research can be complete enough to identify admissible model classes, invariant conclusions, load-bearing disagreements and resolution paths while a full cardinal probability distribution remains epistemically unqualified.**

It also adds four constraints to any future Analysis Divergence method:

1. **Freeze source records and Claim Audit, not a preprocessed shared market narrative.**
2. **Require Frame admissibility before comparing outputs.**
3. **Count only divergence that reaches owner economics / Odds-relevant outcomes.**
4. **Treat convergence as weak robustness evidence and explicitly inspect common-mode assumptions.**

No Constitution or schema change follows from one successful dogfood.

The next proof should come from another economic species, not from repeatedly re-running GigaDevice until the method looks good.
