## 0. Purpose

This note answers the outside-view question:

> When industrial suppliers move from validation / batch delivery / line ramp toward larger-scale commercialization, how do volume, price, margin, utilization and capital return actually evolve?

This is deliberately a small reference class.

It is not a probability engine and it is not used to assign Sanhua a cardinal robot-success probability.

The cases are selected because they expose one or more of the load-bearing mechanics relevant to Sanhua:

```text
precision manufacturing
+ actuator / transmission content
+ capacity built ahead of full demand
+ price-down
+ utilization / depreciation
+ integration vs component manufacturing
```

## 2. Tuopu: realized actuator margin before material scale

**FACT** — Tuopu's 2025 annual report discloses:

```text
robot-actuator revenue = CNY13.591m
robot-actuator cost = CNY9.752m
gross margin = 28.25%
revenue YoY = +1.22%
cost YoY = +47.92%
gross-margin change = -22.65ppt
```

Cost composition:

```text
direct material = CNY5.928m
direct labor = CNY1.651m
manufacturing expense = CNY2.173m
```

**DERIVATION** — disclosed cost shares are approximately:

```text
material 60.8%
labor 16.9%
manufacturing expense 22.3%
```

**INFERENCE** — an integrated actuator can carry significant purchased-content burden and manufacturing absorption simultaneously.

The business had positive gross margin while still being immaterial in group scale.

Therefore:

```text
early positive GM
!= mature scale
!= mature net margin
!= mature ROIC
```

## 3. Zhongda Leader: an integrated-execution-unit capital budget

Zhongda Leader's `机器人本体组件、配件及智能执行单元生产线项目` is useful because it is closer to an integrated execution-unit business than a pure reducer reference.

**FACT — management project model**:

```text
project investment = CNY428.8856m
mature annual revenue = CNY712.8994m
mature gross margin = 25.84%
mature annual net profit = CNY52.1363m
mature net margin = 7.31%
```

The model explicitly includes incremental depreciation.

Construction / utilization assumptions:

```text
T+1 / T+2 = construction
T+3 = 80% utilization
T+4 onward = 100%
```

The issuer also calculates a 37.36% utilization break-even point for covering fixed depreciation in the relevant project grouping.

### Outside-view implication

**INFERENCE** — The path from `~26% GM` to `~7% net margin` is a useful reminder that:

```text
gross margin
- sales / admin / R&D
- depreciation
- tax
= much lower owner-facing profit margin
```

Therefore Sanhua's sell-side `10% net margin` cannot be validated by pointing to peer gross margins in the high 20s / low 30s.

## 4. Five Continents: high component GM, low-teens modeled project IRR

**FACT — exchange-reviewed management model**:

Planetary roller screw:

```text
ASP = CNY500
unit cost = CNY318.77
GM = 36.25%
```

Combined humanoid / intelligent-vehicle precision-component project:

```text
total investment = CNY1.054746bn
engineering = CNY883.649m
equipment = CNY721.225m
initial working capital = CNY91.599m
mature annual revenue = CNY1.4739bn
post-tax IRR = 12.27%
payback period incl. construction = 6.60 years
```

**INFERENCE** — A product can have a modeled mid-30s gross margin and still generate only a low-teens modeled project IRR once buildings, equipment, working capital, construction time and the rest of the product system are included.

That is directly relevant to the Sanhua 35亿元 question because:

```text
10% net margin
```

still tells us nothing about owner economics until the capital denominator is reconstructed.

## 5. Leaderdrive: ex-ante IRR versus realized utilization path

Leaderdrive's `新一代精密传动装置智能制造项目` provides a rare comparison between attractive ex-ante project underwriting and subsequent real implementation.

### Ex-ante model

**FACT — management project model**:

```text
post-tax IRR = 35.02%
payback incl. construction = 5.66 years
```

The same financing materials assume price-down in key products, including annual decline in harmonic-reducer and mechatronic-product ASPs.

### Realized capacity absorption

**FACT** — later company disclosure shows harmonic-reducer theoretical utilization:

```text
2023 = 51.59%
2024 = 42.67%
2025 = 67.76%
```

The company subsequently delayed the new project from:

```text
2026-12-31
→ 2028-12-31
```

because earlier capacity utilization had been low and management chose to absorb the existing 500k-unit project capacity first.

### Outside-view implication

This is one of the strongest reference-class observations in the current Sanhua work:

```text
attractive modeled project IRR
!= realized demand timing
!= realized utilization path
```

A line can be technically ready while the economically rational action is to postpone the next capacity tranche.

## 6. What repeats across the reference class

The small sample is not large enough for formal base-rate statistics.

But several mechanics repeat.

### 6.1 Commercial proof is a ladder

```text
sample / validation
→ small-batch / initial revenue
→ line ramp
→ capacity absorption
→ stable utilization
→ mature margin
→ mature owner return
```

The stages are not interchangeable.

### 6.2 Price-down and cost-down occur together

A high-volume industrial supplier cannot simply hold mature margin constant while ASP falls unless some combination of the following offsets it:

```text
yield
utilization
automation
labor productivity
material / sourcing cost
vertical integration
product redesign
```

### 6.3 Utilization is a first-order variable

Across precision transmission references, utilization materially changes manufacturing absorption and can change the timing of new capacity investment by years.

### 6.4 Gross margin is not ROIC

The current references span:

```text
realized actuator GM around high-20s
modeled integrated-unit GM around mid-20s
modeled precision-component GM around mid-30s
```

while project-return models range from low teens to mid-30s and realized implementation can still lag those models.

There is no stable mapping:

```text
30% GM
→ X% ROIC
```

without capital / utilization / working-capital evidence.

## 7. Implication for Sanhua's 35亿元 state

The current outside view does **not** prove the CNY3.5bn robot-profit state impossible.

It changes the required proof.

A credible success state now needs to explain simultaneously:

```text
volume ramp
+ price-down
+ cost-down
+ allocation / second sourcing
+ make-buy mix
+ utilization
+ gross margin
+ period-cost burden
+ fixed assets
+ working capital
+ development capital
```

The Research should not accept:

```text
batch delivery
+ planned capacity
+ attractive peer gross margin
```

as a substitute for this bridge.

### Current outside-view conclusion

```text
FAST VOLUME GROWTH = POSSIBLE
HIGH EARLY / PROJECT GM = POSSIBLE
PRICE-DOWN = NORMAL
UNDERUTILIZATION DURING RAMP = COMMON ENOUGH TO MATTER
CAPACITY DELAY = OBSERVED EVEN AT A LEADING SUPPLIER
PROJECT RETURN = HIGHLY SENSITIVE TO CAPITAL / UTILIZATION
```

No cardinal probability is inferred.
