## 1. Same-company A/H evidence exposes the category problem

CICC's post-H1 2026 update used the same 2027 earnings forecast of roughly CNY5.422bn for the same company, but reported the A share at about **28x 2027E P/E** and the H share at about **17x 2027E P/E**.

Sources:
- https://finance.sina.com.cn/jjxw/2026-08-28/doc-inipwhrr4500381.shtml
- https://finance.sina.com.cn/stock/hkstock/hkgg/2026-08-28/doc-inipwhrw0001143.shtml

The business, consolidated cash flows, robot commercialization status and liquid-cooling economics are identical.

The valuation is not.

This is strong evidence that a meaningful part of `28x` is **market expression**, not a pure property of Sanhua's business economics.

It does not prove that 17x is fair value. It proves that 28x cannot be treated as business truth without an explicit market-premium bridge.

## 4. Fundamental P/E sanity check — sensitivity, not truth

A simple justified-forward-P/E identity can be used only as a sanity check:

```text
justified P/E ≈ (1 - g / ROE) / (cost of equity - g)
```

Using a round ROE of ~16%:

### If long-run cost of equity were 9%

| Perpetual growth | Approx. justified P/E |
| ---: | ---: |
| 4% | ~15x |
| 5% | ~17x |
| 6% | ~21x |
| 7% | ~28x |

### If long-run cost of equity were 10%

| Perpetual growth | Approx. justified P/E |
| ---: | ---: |
| 4% | ~12.5x |
| 5% | ~13.8x |
| 6% | ~15.6x |
| 7% | ~18.8x |

This model is deliberately not canonical. Accounting ROE, leverage, payout, reinvestment and cost of equity are all simplifications.

Its use is diagnostic:

> **28x requires a very strong long-duration growth / return assumption. It is not a neutral multiple for a mature manufacturing core.**

Replacing 28x with an equally arbitrary 20x would repeat the same mistake.

## 6. What was wrong in v1

### Not wrong

- core vs optionality separation;
- official evidence hierarchy;
- post-H1 expectation-envelope reconstruction;
- recognition that robot/liquid cooling were commercial but economically unquantified;
- keeping broad-market weakness conceptually separate from company operating evidence.

### Wrong / insufficiently qualified

1. **Terminal multiples were not independently researched.**
2. **A/H market-expression evidence was not used to challenge the assumption that A-share-like multiples represented business value.**
3. **The downside multiple was adjusted because of market-regime logic, revealing category mixing inside Fundamental Belief.**
4. **Upside worlds raised both earnings and the multiple without an explicit duration / reinvestment-return bridge, creating a risk of optionality double counting.**
5. **The probability-weighted terminal value inherited both the already-known probability false precision and this newly identified multiple uncertainty.**

Therefore the CNY37.5435 result should not be used as a current valuation truth.
