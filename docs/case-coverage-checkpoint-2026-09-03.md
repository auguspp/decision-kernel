# 3. Cross-case scars that should remain explicit

## 3.1 Accounting lines do not have universal economic meaning

Different cases now show different accounting distortions:

- Shandong Gold: purchased-gold / trading revenue can dominate consolidated revenue with almost no margin;
- Ninghu: construction-period accounting revenue can move opposite core toll economics;
- banks: operating cash-flow language does not map cleanly to industrial FCF;
- miners: total capex cannot be interpreted without sustaining / development / resource-replacement purpose.

Therefore:

> **Before interpreting an accounting line, identify the economic activity it represents.**

## 3.2 A current good outcome can hide a future economic problem

Examples:

- high gold price can support profit while physical mine output falls;
- strong current toll cash can coexist with a shortening concession life;
- positive company profitability can coexist with unresolved pipeline failure risk;
- low current bank NPL can coexist with deteriorating retail risk generation.

Therefore:

> **Current realized economics and terminal durability must remain separate claims.**

## 3.3 Model-class uncertainty matters more than parameter precision

Giga and Ninghu now provide different positive controls for the same higher-order lesson:

```text
some uncertainty changes a parameter inside one model
other uncertainty changes the model itself
```

Examples include:

- cyclical duration versus structural earnings-floor rebase;
- finite concession expiry versus perpetual-franchise assumption.

Better arithmetic cannot repair the wrong model class.

## 3.4 Optionality must earn entry into Base

Sanhua and BeOne provide two economically different controls:

- industrial optionality around robotics / liquid cooling;
- clinical pipeline optionality around future medicines.

The shared rule is:

> **An option belongs in Base only when evidence is mature enough that excluding it would create the larger distortion.**

TAM, project count, R&D spend, design capacity, early clinical data, or strategic narrative are not sufficient by themselves.

# 8. Current stop rule for case acquisition

The project should **not** keep adding one new company per imagined category.

Another underwriting-language case is justified only when one of these is true:

1. a new real case exposes a material analytic-language mismatch not already covered;
2. Radar discovers an economically important surprise outside the existing case set;
3. a prospective commitment resolves and forces a Research reopen;
4. an Action / Outcome event creates longitudinal evidence;
5. a known method fails mechanically on a non-YTO cross-case.

Otherwise the correct action is to use and observe the current system.
