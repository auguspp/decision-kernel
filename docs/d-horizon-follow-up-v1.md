## What the daily reader now does

After existing independent-stock inputs and before optional index structure, the
normal publisher can append `details/stock/horizon-follow-up.json`, its descriptor
in the original root, and a readable multi-horizon section in README. Activation
uses the existing `INCLUDE_CURRENT_STOCK_INPUTS` flag; workflow clocks are unchanged.

The reading separates the retained economic hypothesis, long-term deadline,
intermediate finite review, backward-looking price context, and forward 5/20
checkpoints. An analyst review date becoming due does not certify operating
results. Investment execution is not evaluated without an execution input. Null
probability/opportunity fields mean not adjudicated, not zero or no opportunity.

S0 is the first explicit completed SSE session whose close is strictly after the
original freeze. Closed dates are supplied by the existing source calendar, not
inferred from weekdays or missing prices. A missing calendar day stops only the
calendar-dependent dates after that gap. A later valid calendar can establish S0
even if that day's price acquisition failed. S0 never rolls to a successful price.
The current declaration covers this SSE case, not all exchanges.

All four price/factor endpoints for one result come from **one** already admitted
source archive. `stock_market_inputs.evaluate` performs the original arithmetic.
Missing internal price bars are not a gate; missing an endpoint/factor affects its
window. No factor=1 default, price/factor cross-archive splice, fabricated daily
path, or MAE/MFE is introduced. Old context and the latest failure stay separate.

When a valid checkpoint result was already observed, a later source gap retains
that result with an **explicit prior-reading commit and report path**, not a false
same-R archive link. Repeated endpoint results keep their first recorded clock;
changed endpoints are revisions, not new market events. The original Git reading
contains the full prior evidence. Later acquisition is labelled as later knowledge,
not historical same-day availability. A changed declaration or revised calendar
cannot silently rebase the same case. Earlier readable prices/Research remain usable.
