## 1. 最小研究主线：六个阶段，不是六个 Agent

| 阶段 | 必须留下的研究成果 | 不足时怎样交付 |
| --- | --- | --- |
| A. 定义问题与经济结构 | 最小事实底稿、经济引擎及关系、关键问题集、初始解释和查证计划 | 结构不清先定向补证，不先给目标价 |
| B. 实证分析 | 关键变量的证据—机制—反证桥；适用的跨期财务诊断、竞争/周期分析和外部参照 | 明示覆盖、类比局限和待验证假设 |
| C. 股东经济结果 | 同期间、同范围的利润/现金/资本与每股结果勾稽，联合世界的可行性 | 可给条件范围；不能编造分部现金与资本分摊 |
| D. 模型反驳与裁定 | 冻结 Builder 摘要、Challenger 的具体挑战、逐项处置和剩余争议 | 保留竞争解释，不用角色投票得出真值 |
| E. 独立估值与市场对照 | 主动预期对照前的经营版本、独立估值依据、预期对照与价格要求、修订桥 | 反推条件不冒充市场实际信念或成功概率 |
| F. 交付与积累 | 结论及局限、关键 UNKNOWN/STOP/复核条件、底稿与真实保存状态、适时复盘 | 保存失败明确 NOT SAVED；未发生的接受/监控/结果不补造 |

这些阶段可以在一次用户请求内完成，相关步骤可迭代，不要求每步向 Human 请示或交付一份报告。已有底稿直接引用，不重复抄写。新增研究只针对实质缺口，不为满足阶段数多次调用模型。最低可复核成果见 [工作底稿模板](templates/full-research-workpaper-v3.md)。模板不是填空评分表，也不要求正文按其目录展开。

### A. 先有最小记录，再提出关键问题

先按入口固定当前 main 为 M、Research cutoff、证券与股类、实际数据期间、价格权限和 Human 已明确的期限/风险条件。资料先做足以识别公司经济对象的基础阅读；不能在没看业务记录前凭空选定 Frame。

按经济结构方法识别最少但足够的经济引擎，说明报告分部与分析引擎的映射；一个引擎已足够时不硬拆。关系须说明方向、传导机制、时滞、约束及证据资格，不只画箭头。

通常聚焦 3–5 个会改变判断的关键问题，但这不是遗漏重大风险的上限。对每个问题写明：哪条判断依赖它、当前竞争解释、什么可观察事实能区分解释、影响哪段利润/现金/估值、下一项最有价值的查询。问题集随新证据修订并记录原因。

**能够分别变化，不等于统计独立。** 旧业务、新业务、利用率、现金需求可能受共同需求、供应链或融资约束。联合世界必须保留相关性与可行性；不能把分轴理解为可以随意组合，更不能未经依据相乘概率。反对角世界是检验工具，不是每家公司必交四象限。

### B. 实证分析：每个关键结论要有桥

最低要求是让另一位研究者能够检查：

```text
具体问题
→ 来源实际支持的观察（日期、期间、对象、位置）
→ 因果机制与适用条件
→ 推导/假设/计算及量纲
→ 对集团或每股经济结果的影响
→ 最强替代解释与区分证据
→ 当前处置和局限
```

官方来源也只支持其具体声称的内容。管理层计划、卖方预测、同行实际结果和模型假设分别标明；复制同一新闻的多个网页不算独立证据。未知的传导不能用“因此受益”替代。

**经营、竞争与周期镜头。** 只在决定经济结果时使用，必须落到变量而非行业背景：终端需求与补库存怎样区分；新增供给何时影响利用率与价格；成本下降由公司还是客户获得；第二供应商、客户自制、价格年降会怎样改变份额/单位利润；扩产瓶颈在认证、良率、资金还是需求。正常化盈利须有量价、成本、产能和持续期依据，不自动回到历史均值。

**财务矛盾诊断。** 通常争取约 5 年与最近 8 个季度的可比观察，按公司存续、披露与经济结构调整范围，不把年限当机械门槛。只提取关键项：量价/收入、产品组合、利润率、应收/存货/应付及合同项、经营现金、资本投入/研发、净债务、股本。公开报告只有累计数据时，单季差分需同口径并留公式；并购、汇率、重分类或重述需先调节。缺失不能补零，旧口径不能硬接成趋势。

输出不是一堆比率，而是“利润表的解释是否被资产负债表与现金流支持”。对异常保留观察、至少一个合理解释、竞争解释、尚需材料及对估值的影响。应收增长或单季负现金本身不证明造假或经营恶化；没有异常也需说明检查范围，不写模板式‘财务健康’。

**Outside View / Reference Class。** 针对一个关键变量选择同阶段、同经济机制的参照，而非因为同行名称好看就类比。记录选择标准、检索范围、起点定义、期限、来源时点、成功/失败/仍未结束的对象及主要差异。正式概率或历史分布须有可审查的分母、遗漏和删失处理；只有几个挑选出来的案例时标为 `ANALOG_ONLY`，不是校准 base rate。

外部参照应明确改变或约束哪一项假设，例如商业化时间、价格侵蚀、利用率或资本需求。没有适合参照时写 `NO SUITABLE REFERENCE CLASS FOUND WITHIN SEARCH SCOPE`，给局限和其他可用证据，不强行输出‘行业通常几年’。参照不是目标公司结果，也不单独推翻目标公司的更强证据；内外部判断冲突时解释差异并留下版本桥。历史回放只使用 cutoff 前可知的信息；后来结果属于结果评估，不能倒灌成当时依据。

### C. 股东经济核算：把关系变成可复算的账

首先选择口径：企业经营现金、普通股权益现金还是实际分红；三者不混用。至少核对基准期和最能改变判断的联合世界。不同引擎先回到集团利润，再处理抵销、未分配总部费用、利息/税、少数股东、权益法投资及股本。不得把所有分部都当成 100% 归属于上市公司，也不能把总部成本扣两次。

适用于普通非金融企业的简化桥为：[E1][E2]

```text
FCFF = NOPAT + 已扣非现金费用 - 资本投入 - 非现金经营营运资金增加
FCFE = 净利润 + 已扣非现金费用 - 资本投入 - 非现金经营营运资金增加 + 净借款
```

这是在期间、权益范围、税与非现金调整已一致化后的分析表达，不是所有报表都可直接代入的统一公式。并购现金、资本化开发、租赁与其他重大项目按所选口径单列并勾稽，不能漏掉，也不能与资本投入或债务重复计算。

**从已报告 CFO/OCF 出发时，先核验利息、税和现金流分类；经营营运资金的影响通常已在其中，不能再扣一遍。** `CFO - capex` 可以是现金诊断起点，不自动等于可分配给普通股股东的现金。[E1]

维护与增长投入无法可靠分离时，披露估计范围、依据与敏感性，不默认折旧等于维护 capex。被计入增长预测的必要增长投入不能免费。费用化研发不二扣，资本化研发现金仍需计入；如分析性资本化研发，利润和资本分母应一致调整。

净借款可以进入 FCFE 或融资可行性分析，但不是业务创造的自由现金。增发资金不计为经营成果；需展示融资缺口、债务义务、稀释和每股结果。滚动现金按期初现金、经营/投资/融资及汇率等变动到期末现金闭合；分红、现金本金、金融收益、股权和 royalty 的重复计价继续按原入口检查。

增量 ROIC 须说明增量税后经营利润来自何处、由哪一批新增资本产生、投入与产出时滞，以及收购、研发、营运资金和租赁的范围。`ΔNOPAT / Δ投入资本` 只在可比、可归因时使用；分母过小、为负、业务大幅变化或只是周期复苏时，不把机械比率叫真实新增项目回报。可以给有界资本需求，不能伪造归因。[E2][E3]

按经济对象使用原 Species Playbook：金融机构更重权益回报、资本约束、信用损失及可分配权益；特许经营/资源要看期限、权属与全周期投入；网络要区分总部与全网络；单一成熟业务无需强制 SOTP。这里补强的是经济核算，不是所有公司套制造业 FCFF。

### D. Challenger 必须留下具体挑战及裁定

先保存 Builder 的经济结构、关键假设和计算摘要；Challenger 检查原证据与底稿，而不只读结论。优先不提供目标价/第一笔结论；若同一会话已见过价格、修订答案或用户反馈，必须承认这些暴露。

区分 `SAME-CONTEXT SELF-REVIEW` 与实际隔离上下文的复核。换角色名称、换提示词或同一模型多说一遍，不证明独立性；即便另一个模型参与，也不能假设误差独立。无需为此新建 Agent 框架。自我复核的作用是产生可查挑战，效果须实测。[E4][E5]

Challenger 优先攻击遗漏的经济引擎、被错误绑定的变量、不能兑现的利润—现金桥，以及符合现有证据却产生不同股东结果的解释。每条挑战注明对应原假设、证据/公式、影响范围和可解决方式；不能用宏观下行等通用风险凑数，也不为反对而编造替代 Frame。

Reconciliation 逐项给出 `REVISE / RETAIN WITH REASON / UNRESOLVED`，以及改变的底稿位置。需要查询时只追最有判别力的缺口。找不到反例不等于正面证据；反驳未成功不能自动增加概率、估值或‘研究可靠度’。结构性争议未决时并列条件分析，不能靠多数角色投票强行冻结唯一解释。

### E. 独立估值、市场对照和价格要求

先保存主动预期对照前的经营版本与已有市场信息暴露；这不是宣称完全市场盲。独立论证与经济对象匹配的估值方法、持续期、资本回报和重大参数。**先有估值桥，才有可靠的价格反推；不能先反推，再挑倍数解释结果。**

再比较有明确机构/日期/目标年/利润范围的公开预期与价格要求。研报可以带来待核事实或模型挑战；只有核实后的证据、可解释的方法修正等理由才能改经营判断，不能为了贴近报价调整世界。

修订顺序沿用原协议：pre-expectation view → 明确对照 → 原因可追溯的 post-expectation belief。没有需要改变的地方就不改。利润预测与期末倍数分别论证，并检查业绩改善但估值收缩等合理组合。‘价格要求什么’是条件反推，不等于识别出市场唯一真实信念。

缺可信概率时保留 ordinal / bounded 研究和条件收益，不制作期望收益、胜率或伪概率加权。Full Research 完成、有资格做条件分析、canonical 数值 Odds 可用、Human 接受和投资决定是不同事项。

### F. 交付、UNKNOWN、保存与复核

Value of Information 从 A 阶段起使用，不等最后才决定搜什么。定性比较：问题能否改变判断、证据能否区分解释、当前能否取得、成本/时效以及现在知道与以后知道的差别。优先追少数高影响且可解决的缺口。

不把主观的‘敏感度×可验证性÷成本’包装成已计算的信息价值。量化 VOI 需要明确决策集合、可能答案、概率、效用与成本，本版不要求也不提供这样的默认计算。

每个关键 UNKNOWN 留下 `PURSUE NOW / DEFER / FUTURE EVIDENCE ONLY / NOT MATERIAL TO THIS QUESTION` 的文字处置、理由和下一项区分证据；这些不是新增 runtime 枚举。未来才可能观察的事实不能靠继续搜索消除。获取失败不等于不存在，也不等于穷尽公开信息。未知只限制其影响的结论，不能让一个无关缺口阻断全部研究。

正常交付用清楚的业务语言说明：核心经济问题与当前判断、关键证据和争议、利润/现金/资本结果、当前价格还要求什么、哪些条件下可复核以及完整下行。底稿可详，正文不写工具流水账。

复用现有保存路径，记录底稿、计算和来源身份及 commit/readback。无合格价格仍可独立保存研究；只有价格变化时复用冻结研究和有效估值条件重算，核验是否有需重开经营判断的变化，不重新从零 Full Research。方法修正、期限滚动与新经营证据都不能假称单纯 price refresh。

未实际写回时写 `NOT SAVED`，未执行 validator 时写 `NOT RUN`。本方法不自动实现保存能力，不把归档当监控。Human 研究接受、价格卡接受、投资决定与成交沿用原协议分开保存。

## 2. 如何判定研究动作完成，而不是只写了对应标题

| 原有闭合要求 | v3 复核时要找到什么 |
| --- | --- |
| A. Economic decomposition | 经济引擎/披露映射及为何此拆分足够；或单引擎理由 |
| B. Relationships / causal axes | 关键问题集和关系的方向、机制、约束；联合世界为何可行 |
| C. Owner economics | 报表矛盾诊断及可复算的现金/资本/每股桥；缺口的影响边界 |
| D. Adversarial worlds | Builder、真实挑战、裁定；外部参照资格及其改变/未改变的假设 |
| E. Valuation bridge | 独立参数依据、预期对照、反推与正向勾稽、重复计价及完整下行 |

可以写 N/A，但必须给与本公司相关的理由。重大缺口应输出局部 `BOUNDED CONDITIONAL REQUIREMENTS`、`RESEARCH CHALLENGE` 或 `NOT METHOD-READY`，而不是因完成模板就给 PASS。人工语义审阅、工具算术和 Kernel 校验分别记录；Kernel 验身份/时间/来源一致性，不验证经济真相。

## 3. Learning Loop：记录错误，不用‘用户喜欢’替代能力检验

每次首版交付保留当时主动发现的关键问题、已有答案与局限。Human 复核后只记实质变化：后来新增哪个关键问题、当时是否合理可发现、影响多大、是否重建 Frame/现金桥，以及原因属于 METHOD / EXECUTION / SOURCE / JUDGMENT 哪些缺口。可以多因并存，不因来源合法就排除理解或执行失败。

‘Human 又提出一个问题’本身不是错误。新证据、不同偏好、合理分歧、事后才可知问题要与原本遗漏区分；Human 未指出问题也不证明没有遗漏。须抽查首版底稿，防止靠多列模糊问题或一律 WAIT 获得假好成绩。

使用少量可核验指标而非总分：重大可发现遗漏、无依据推断/数值、算术或口径错误、被证据支持的有效修正、误报/无必要阻断、实际研究成本与 Human 追问负担。每项保留观察范围和分母；没有完整初稿或审阅记录就写 UNKNOWN，不补造‘改进百分比’。

季度/年度结果真正出现后，按原结果协议比较 PIT 预测与同口径实际，归因到 Frame、量、价、份额、利润率、持续期、资本或估值表达。价格涨跌不单独证明经营判断对错。只有实际作出概率预测且得到足够可比结果时才讨论概率校准；过程能力验收不必等待多年收益，但不能冒充收益验证。
