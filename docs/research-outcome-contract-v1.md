# Quick / Full 成果与交接边界

## R5.1 Full：一次委托的自主推进与有依据的停止（2026-09-24）

依据：[Human授权及光迅/兴森对照](https://github.com/auguspp/decision-kernel/issues/524#issuecomment-5808199281)、[#321已完成的自主研究验收](https://github.com/auguspp/decision-kernel/issues/321#issuecomment-5714722473)、[#508成果导向原则](https://github.com/auguspp/decision-kernel/issues/508#issuecomment-5772427849)。这是既有Full职责的执行澄清，不是Research v4、新schema或固定循环算法；本节优先解释下方“有限成果可交付”和历史方法的停止措辞。旧成果及其当时验收不重签。

**Full是一次有边界的自主研究委托，不是第一版报告的格式要求。** Human直接委托或选择Quick后，研究者负责在获准范围内自行取证、分析、质疑和修正。对于可能实质改变本次判断、当前仍有合理推进办法且处于实际权限/资源范围内的重要工作，应主动继续；不能仅写成“下一步建议”交回Human，等待逐轮“继续”。问题可以重构，顺序和工具可以改变，UNKNOWN也可能增加。无需调用旧direct-deep的execute_pass、复制固定Agent/轮数/文件树或新建Kernel loop才能履责。

**按原委托核对完成范围。** 依[本次Human采纳](https://github.com/auguspp/decision-kernel/issues/297#issuecomment-5809534393)，回答几个子问题不自动完成整个Full；原关键问题须交代已回答、为何被证据重构/取消，或仍未完成。结论可收窄，但不能悄悄缩小委托来获得PASS。“不做Odds”不自动取消原委托内对未来经营/股东经济的研究责任，也不反向授权价格、概率、仓位或交易；原任务确实不涉及价值时，不额外强加DCF。

这里的Hosted是研究执行交给可替换的研究者，不意味着已部署无人值守生产。普通交互、定时、Deep research的能力和权限分别留证。一次委托不永久等于一次HTTP，也不授权无限运行、另建任务、跨会话自动重启、付费调用或权限扩张；真实平台限制不能靠提示词承诺消失。

### 结束前检查的是剩余工作，而不是章节是否齐全

研究者应审视当前解释中最可能改变结论的缺口和最强可行替代解释。重要挑战需要实际影响取证、计算、范围或结论，或者留下有依据的保留/未决理由；增加通用风险段落、换角色名称或重复自查不构成实质修正。无需为留下记录制造多轮、独立Agent或假反证；原判断有充分支持时可以不改。

将剩余工作的性质分开处理：已取得资料上的未完成分析；已披露但本次未取得/未核验的资料；当前公开范围无法识别的变量；必须等待未来事件的事实。前两类先评估并执行仍值得做的获准工作，不能都转成“等待下季报”。一次下载/整页读取失败不是资料不存在或公开证据穷尽；复用已记录尝试，选择有判别力的合理替代来源/原件/计算，而不是反复请求同一失败端点。明确访问或安全拒绝不绕过。

**没有新证据，不禁止继续完成同一次委托的分析。** 旧研究去重防止把已完成工作重新包装为新发现，不阻止补算经营/现金桥、检查单位与归属、检验替代解释或处理明确的方法挑战。后续材料使用真实来源与时钟，新增/更正以可恢复版本绑定前驱，不覆盖旧cutoff、失败或Human原话。

需要价值判断时，利润×倍数端点只是条件敏感性，不能替代有依据的经营世界。对能支持的部分，说明经济引擎怎样经量价/成本、资本与营运资金、融资和经济归属形成集团及每股结果；必要参数不能识别时给有依据的区间/约束或限制结论。不能凭任意利润/PE网格就宣布所有合理世界均高估，也不能为得到可买价格补造乐观世界。没有概率、买点或完整分部现金本身不构成失败；未能完成的论证与其原因必须明确。

**范围判断与条件试算分开。** 缺少精确客户单价或分部现金，不自动证明任何有用范围都无法建立；在原范围内评估可比口径、成熟业务基准、产能/成本/资本及融资归属能否约束结果。说明哪些区间有证据支持、哪些只是声明假设的敏感性、哪些仍无法识别；不得将任意格子当合理世界或为了完整性补造参数。数值与分母的单位、期间、主体及有效产出含义须匹配，已含良率/资金占用不重复扣减。

### 停止必须与本次声明结论相匹配

| 结束性质（自然语言即可，不新增状态机） | 需要留下的依据 |
|---|---|
| 本次问题已得到足够回答 | 关键结论有证据/必要计算，重要挑战已处理；剩余未知不阻止所声明的有界结论，或原研究命题已被有据重构/否定。不要求继续做无关估值或消灭全部UNKNOWN。 |
| 在当前范围到达证据边界，或继续工作边际价值不足 | 对重要未决项说明实际检查/尝试、所得及限制，为什么下一项合理工作现在无法区分解释、只能等未来或不足以改变本次结论。不是声称穷尽整个互联网；“列了UNKNOWN”“报告很长”“已保存”不是停止依据。 |
| 工具、权限、预算或运行资源中断 | 明确这是执行未完成，保留已有成果、受影响结论、准确阻塞与可接续工作。运行结束不冒称研究完成，获取失败不冒称未来事实等待。不能伪造不可观测预算或内部调用数。 |

不同问题可以处于不同结束性质，局部缺口只限制其承载的结论。整体交付必须让Human看懂哪些已经回答、哪些尚未回答及为什么停；不能用局部充分或形式完整掩盖仍影响主结论的未完成工作。任何时点均可保存部分成果，保存不是结束研究的额外门禁。

### 成果、充分性、发布和接受分别验收

可恢复原件/算术正确，不自动证明研究推进充分；研究推进充分，也不自动证明经济真理或Human接受。Kernel只核对身份/时间/来源/前驱/权限及用途一致性，不用非空字段、轮数、CI或AI自报STOP认证研究质量。保存、独立恢复、正常登记/发布、研究充分性、Human接受和投资决定各保留实际证据。

验收看可检查的工作变化和有依据的停止：重要缺口怎样被追查或限定，什么证据/计算支持修订或保留，尚未推进的高影响工作为何不在本次继续。简短说明并指向真实底稿即可；不索要隐藏思考、完整聊天、逐工具日志或每次调用checkpoint，不以UNKNOWN数量下降评分。

**验收与原范围及真实用途相称。** 不在每次审阅后追加固定轮数、独立Agent、全部来源字节或唯一估值等通用完成门槛；新发现的实质缺陷仍须处理，并说明它影响哪条结论/用途。审阅者本次打不开外部页面，只能标明该次独立复验的限制，不能推断作者未读取，也不能据此认证原文正确。局部修订、来源复验、研究完成、正常发布与Human接受分别记账；公司研究的未决问题不自动成为无关P1工程的永久阻塞。

对照复用[光迅裁定原件](readings/002281-accelink-full-research-2026-09-17/reconciliation.md)与[兴森固定原件](https://github.com/auguspp/decision-kernel/blob/a4cb0c0b44970ef3b96f0f570107093e7a1eb7ae/docs/readings/002436-xingsen-full-2026-09-24/report.md)。光迅已有实质补证/重算/修订并保留NOT_METHOD_READY的历史样本；不是完美金标准，也不要求复制文件数或参数。兴森有价值的有限成果及算术/留存事实保留，但Human已明确不满意其研究深度；这不是看空/看多、拒绝公司或投资决定。其自主推进充分性仍待实证，不能以入口文字更新宣称修复有效。旧direct-deep机制说明的早期NOT_ESTABLISHED不是#321最终产品状态；历史PASS也不证明新环境永久可靠。

## R5.1：研究有用，而且下一位研究者接得上

当前可修订架构：[ARCH-20260924-continuity-v1](https://github.com/auguspp/decision-kernel/issues/508#issuecomment-5806130438)；验收顺序：[RM-20260924-r5.1](https://github.com/auguspp/decision-kernel/issues/297#issuecomment-5806149428)。研究者/方法可替换，历史可恢复，必要一致性与 Human 权限保持；不是“只要日志”或永久最薄架构。未来修订沿已有前提变更记录，不覆盖旧来源、方法、失败与Human原话。

跨会话交付复用自然语言成果和既有档案/索引，留下原对象/范围/时点、关键判断和依据/必要计算、反证与重要 UNKNOWN、停止/重开条件、前驱/修订及实际保存/登记/交付状态。记录可检查的工作成果，不索要隐藏思考或完整聊天，不按每工具调用建状态，不新建 Memory/Trajectory schema。摘要可重建，不取代历史原件；Human 接受不是模型建议可以补填的字段。

**关键来源在成功取得时尽量留住内容。** 沿[已有档案协议](research-archive-v0.md)，对承载核心结论的材料优先保存获准留存的原件；不能取得/保存原字节时，保留实际取得的关键文本或表格及必要上下文、来源定位/页码、表头、单位、期间、主体和公开/取得时间。明确区分原始字节、页面留存、提取内容与研究者转述；提取内容或链接不冒充原件，摘要不提升来源资格。按已有文件/预算/版权与权限边界保存、精确读回；大原件复用原独立归档引用，不扩现有读取上限、不另造来源库，也不把全PDF下载成功设为研究前置门禁。保留不全应说明影响范围，不倒填旧档案的来源保管资格。

P1 必须分别验证研究质量和至少一个真实独立会话恢复：交接仅给项目入口、精确 GitHub 定位及获准范围，不由 Human 粘贴正文补记忆。恢复后无变化复用，有实质新证据/方法挑战才有界续接；价格变化不改 Belief，读取失败不当无变化。直达恢复、正常入口可发现性、真实交付各留实证。不存在自然增量就标未验证，不强求换模型、付费实验或合成自然成功。首轮技术失败及其诊断可用于工程恢复，但不是合格 Quick 或研究连续性验收；一次报告/CI/保存成功也不证明长期可靠性。

工具能力按同 M 的 AGENTS 和 [#524/5806243062](https://github.com/auguspp/decision-kernel/issues/524#issuecomment-5806243062) 的有范围实测纪律执行；不从通用文档推断当前没有写工具，不把交互成功当定时成功，明确拒绝不绕过。本次解释不改旧 pilot、任务或权限，不追认运行成功；R5-2 紧接真实成果，Radar 扩建和 P1 后整理按当前方案处理。

## R5 当前成果责任：自主 Quick，Radar 补充视野

依据：[RM-20260924-r5](https://github.com/auguspp/decision-kernel/issues/297#issuecomment-5805763775)。本节是新托管工作的现行解释；下方 R4 的“一个合格具体问题”“不是自由选股器”和单次调用边界只保留为旧 API 方法的合同，不限制 R5 在授权范围内自主发现研究对象。旧对象及 validator 不重签、不放宽。

**Radar** 获取、机械筛选/计算、去重并保存有来源、时钟和覆盖范围的观察；它不必先证明经济重要性、挑出受益股或形成正式 Question。其观察资格不成为所有研究的统一 Price Gate。

**Quick** 围绕明确目标，使用公开网络、获准工具、旧 Research 和 Radar，自主发现变化、关联公司、选择候选、提出和修订问题、按需查证，解释哪些值得关注或 Full。输入可以没有 ticker 或具体经济问题；输出也可以只有有价值的行业观察、暂不深入的理由、UNKNOWN 或部分成果。问题与候选是研究工作对象，不是统一入场券。一个 Quick 任务不永久等于一次模型请求；不建立新的 Pre/选题AI/固定多层Quick漏斗。

**Full** 在 Human 选择或直接委托后，承担更深入结论的论证责任；工具不必比 Quick 多，必须交代关键证据、计算、反驳、问题变化和局限。双起源保持真实证明，共用成果与归档；可以否定 Quick，不能继承其结论为独立 Evidence。

**Kernel / 可信宿主** 核对可观测的身份、时间、来源/产物绑定、实际权限、前驱、消费与保存及用途资格，不认证经济真理；Human 保留最终研究、判断与资本决定。托管执行不伪造旧 API identity、raw request 或内部 token/call receipt。

Quick 的验收看实际价值：为何现在值得看、依据支持到哪里、最强反证/替代解释、尚未建立什么、现在是否有值得 Full 的可执行工作，以及旧研究能否复用。自然语言即可，重要结论有可复核来源；不能按候选数、未知数、涨幅或 schema 非空验收。WAIT 是等待未来可区分事件，当前必要来源取得失败仍是缺口；STOP 不表示永远不研究。Full 候选只是建议，不自动产生执行、Odds、接受或交易权限。

GitHub 是 canonical 成果/证据/过程后端，不是唯一信息来源。实际用到的新检索保留真实出处及公开/获取/适用时间，不补造 Radar origin、不倒灌旧 cutoff；网页转载不算独立证据。旧研究/失败/更正/消费记录保留，新日期、新 prompt 或 read-model SHA 变化不自动获得重复研究资格。

沿原原生 Git/档案/用途索引保存实际成果并读回，来源不足或保存/登记/发布未完成分别说明。可以自然表达研究正文；未执行原 typed validator 不能称通过，未登记不能称已进入正常读取面。不可取得的内部模型版本、token 或调用次数为 UNKNOWN，不索要私有思考。定时执行、普通聊天、Deep research 的读/研/写能力与平台审批分别实测；没有权限不绕过、不静默切 API。

本次只对齐入口责任；不部署任务、改 runtime/schema、继承旧出站许可、修改日程或复活 #525。具体试运行/写入位置与实际交付在 #524/#297 留回执。R5-1 从第一轮包含归档、读回和可读交付，不将这些推迟到 P1 末尾；P1 仍按真实覆盖、质量、遗漏/误报、连续性与 Human 负担验收。

## 三种责任

| 责任方 | 应交付什么 | 不负责什么 |
|---|---|---|
| Quick | 对一个有资格的具体问题，给出可读的研究价值解释：什么变化、为什么与公司相关及可能重要、支持到哪里、反证/替代解释、决定性未知、当前值得查证的工作或未来触发、旧研究关系和处置。内容可合并表达，不必按这串顺序思考或逐项展开成巨型表。 | 不是小号Full、自由选股器或投资结论；不要求先证明市场误价，不以标题、涨幅或未知数量自动升级。 |
| Full | 接收可推翻的委托；交回有依据、可质疑、可恢复的研究判断与局限。原问题可重构或否定，但要交代原关键问题的去向、新发现的重要问题及未完成部分。 | 不负责证明Quick正确；不强制固定Agent数、Builder/Challenger文件、轮数、目录树、分析顺序或UNKNOWN净减少。 |
| Kernel / 可信宿主 | 核对对象/问题/版本、真实权限、PIT与来源/产物绑定、消费/前驱、真实调用及保存、下游用途资格；代码只验证明确的机械一致性。 | 不把非空字段、schema通过、角色投票、CI或保存成功认证成经济真理、Human接受或投资许可。 |

## Quick 的最小可用成果

可读解释应能回答“为什么现在值得我看”；有来源的主张继续区分FACT、MARKET_CONTEXT、INFERENCE、ASSUMPTION，引用具体材料/页/时点。查过什么反证、最强替代解释、哪些未查必须诚实；没有找到相反FACT可以成立，未检查不能说成已排除。

| 业务处置 | 研究责任 |
|---|---|
| Full候选（可投影为原DEEPEN_REQUIRED） | 有可追溯观察、非空泛公司联系、可能重要且尚未被旧研究解决的具体问题；指出现在能做、不同结果可能改变判断的调查。无需已有预期差或必有相反FACT。结构合格仍须内容审阅。 |
| WAIT_FOR_TRIGGER | 本次声明范围的Quick完成，关键辨别确实依赖未来事件；说明触发及为何重要。当前必要材料取得失败不是等待未来。 |
| STOP | 本次范围无值得继续投入的问题、影响不足或已有结果已回答；说明理由和可重开条件。机械重复在宿主复用，不冒充新Quick。 |

来源、准入、模型或校验GAP是执行事实，不是第四种模型业务route；保留原文与已有局部成果，不补造STOP/WAIT。重要WAIT也应可读，不能只有Full候选可见；可读与主动提醒的原资格分别处理。

## Full 的委托与返回

交接引用原问题、Quick精确原件/输入/方法/cutoff、来源及已知限制、已做/未做、拟查问题和停止/重开条件。交接本身没有执行权限；机器候选不伪装为HUMAN_ORIGIN_DIRECT_DEEP。Human明确直接Full时无需补造Quick或Pre。r4.1的两种起源通过共同FullResearchCommission进入同一研究者/成果接点，起源资格分别核对，具体实现与未运行边界见[共享入口说明](single-quick-contract-v1.md)。

合格返回应让下一位研究者找回关键判断、依据与必要计算、反驳及裁定、重要未知和问题变化、适用范围/停止理由、实际保存位置。研究者可改变调查顺序、重新定义问题或发现更多未知；所声明结论的负担不变。需要估值时保留独立依据、股东经济勾稽和重复计价检查；没有足够依据时交付有限结果，不伪造概率、目标价或全量估值。

Quick是待检验解释，不是新的独立Evidence。Full可否定Quick；新增证据使用自己的时间范围，不回填旧cutoff。未完成用原progress/archive；符合条件的成果再用method-agnostic ResearchCommitPackage。RETAINED、COMMITTED、数值Odds-ready、Human接受和交易仍是不同事实。

## 保存、兼容与实际交付

同一业务问题共用原security_id/question_id根及day/slot/launch记录；换方法/provider/prompt不自动获得再消费资格。有真实新证据、方法修正或明确续作时，可按实际获准范围绑定前驱，而不是终身禁止再研究。未决写入先对账，不重复调用。

旧v1的Pre/Quick/失败/hash和来源原件不变；新单Quick不构造虚拟Pre。新方法无Pre应显示“该方法不设Pre”，不是执行失败；未知或混合版本明确拒绝，不通过多个解析器猜版本。

正常交付应先展示对象/变化、为什么值得看、知道/不知道、当前处置和需要Human判断什么，再提供原件。不得用旧成功覆盖新失败、用保存代替用途登记、用publisher成功代替Brief实际送达。既有股票价格观察、行业背景保持各自资格，不为进入公司Quick强挑ticker。
