整体仍为 **0 → A → B → C → D，L 横向贯穿**，但 A 不再只等部署/回应，也不先完成所有来源再做人可用页面。以下是计划导航，不是新的 runtime 枚举或工作流。

|---|---|---|---|

### 2.1 下一实际工程批次：A1-H

先在一个可用增量中交付 Attention → 同公司 → 研究/更正 → Odds/原条件 → 历史回应/接续。重点是自然语言标题、紧凑目录、可阅读研究正文、清楚的历史/当前适用区分、合理显示精度、默认折叠技术信息和手机阅读。

不需要把每页做成同一种卡片流。优先使用已有正文和明确字段；没有可靠当前结论或更正关系就显示待核，不能按文件更新时间猜“最终版本”。Research 保存回执不是研究正文；历史 Odds 标签不因显示成中文而升级成当前合格数值。

同时只读核验 A2-Refresh/Quick 的宿主与官方入口、授权、现役消费者和保存路径，形成明确可用/未验证/受阻结果。不要先造一个通用 action bridge 再寻找执行者。

## 3. 所有功能页的人类问题与信息层次

**默认层是人的问题与关键内容；第二层是研究上下文；第三层是 Evidence/原件；最后才是机器身份与技术诊断。** 这不是第二套数据源，也不是强制所有页面采用相同版式。

| 页面 | 首先回答 | 默认结构 | 下钻 |
|---|---|---|---|
| Attention | 什么值得知道、什么真正等我回应、相较之前新增什么？ | 有范围的研究增量与事项；资讯、请求、等待、历史和影响性缺口分开。 | 关联对象/研究版本/原回应/依据。 |
| News | 已覆盖窗口里发生了什么，哪些已解释、哪些待分析？ | 能可靠归并的事件、时间、涉及对象、具体来源、已有 Quick；关联不足时保留原条目。 | 事件更新、不同观点、研究、原文；不是十篇转载等于十份独立证据。 |
| Markets / Global Markets | 已覆盖市场处于什么状态，哪里变化了？ | 按区域/资产类别与市场结构组织指数、板块/概念及已接通资产；关键日期、单位、延迟/休市口径可见。 | 历史走势、行业/成分、异常、新闻及研究。快照与收盘 Radar 分开。 |
| Research Book | 研究过什么、现在有什么可用结论、哪里改变了？ | 对象/成果类型、可用结论或阅读摘要、变化、重要 UNKNOWN、下一验证点。允许公司/行业/主题/事件。 | 完整研究、版本/更正、支持反证、计算、历史回应；不是 commit.json 文件目录。 |
| Odds Book | 算过什么、哪份仍适用、价格与原条件是什么关系？ | 紧凑列表；结果类别/资格、价格及其时点、适用前提、明确复核条件、Human接受边界、变化类型。 | 原测算、条件世界、历史修订及对应 Research；无合格数据就明确未建立。 |
| Calendar | 接下来什么有来源的事件值得复核哪些假设？ | 近期列表/周视图，确认/预约/预计窗口/未知，关联研究与验证点。 | 原日期/改期、来源、实际发布、取得、分析、回应。 |
| My / 关注与持有 | 哪些对象是我明确关心或持有的？ | 显式身份及其时间、相关研究/事件/条件/回应。 | 原话、范围和历史；研究过≠关注≠持有，不推断成本、仓位或交易。 |
| Health | 哪个缺口影响我现在的阅读或判断？ | 平时次级入口；影响性故障进入相关页面/Attention，说明影响而非堆日志。 | 实际运行、覆盖、研究消费与技术详情，不用绿色CI认证经济结论。 |

公司/主题/事件详情、全局搜索和 Evidence 阅读是共用能力，不因后台多一个模块就增加一级菜单。资料库与 Research Book 关联但不混成一种成果。逐项原件、真实错误和历史仍可查。

### 3.1 简洁不能削弱关键事实

首屏继续保留：数据/分析的实际时点与范围、必要单位/口径、研究受挑战/不再适用、重大反证/限制和会影响当下判断的读取缺口。长 commit、SHA、source path、raw enum、完整诊断默认下钻；不能把“陈旧”“未分析”“未接受”一起藏掉。

格式化不改变数值；适度小数位仅用于显示，原值可查。收益率分数/百分比、累计/年化、价格/收益率、金额单位不得猜测。读取包更新不冒充行情更新；零项只覆盖真正检查过的范围。

前端只显示有来源、明确绑定版本的已有分析和机械投影。新的原因解释、观点共识/分歧、事件关联和注意力判断由实际 Research 形成并保留，不用标题关键词/来源数量/漂亮文案虚构。相同来源转载不增加独立 Evidence 数。

此前聊天举例中的股票价格、报告日期、所谓“当前状态”、任务步骤和数量只是界面示意，不得作为生产资料。只有实际存在的研究、来源和 Human 原话能够支撑正式显示。

## 4. 按需刷新与“让 Quick 看”的产品合同

### 4.1 五种意图区分

1. **读取最新已保存结果**：不调用来源或研究，只读取正常发布的实际数据。
2. **重新采集来源**：在明确范围内刷新 News/行情快照/日常 Radar；不隐式发起 Quick、Full 或 Odds。
3. **开展 Quick**：Human 明确把当前事件/公司/市场范围交给研究者；附原版本/更正/材料，但不限制其自主公开查证。
4. **委托 Full**：Human 明确选择对象和范围；Quick 建议、已读/复制不构成委托。
5. **重算 Odds**：沿有效 Research/价格资格/原算术和许可；价格变化本身不改 Belief，不强制经过 Quick。

按钮写业务意图，不写 workflow 文件名。来源 refresh 和 Quick 分开显示；未来组合动作必须明确其整体范围，不能藏在普通刷新内。阅读或切页绝不隐式执行。

### 4.2 先接真实执行者，不制造“WebGPT API”

现役 Hosted Quick 责任继续按 [RESEARCH-ENTRY](RESEARCH-ENTRY.md)、[成果合同](research-outcome-contract-v1.md)及 [#524](https://github.com/auguspp/decision-kernel/issues/524) 的后继事实。#524已有成功/失败和关闭历史保留；一键入口的新增产品范围归本计划/#351，不为新按钮重开旧失败执行。

[GitHub 官方 dispatch](https://docs.github.com/en/rest/actions/workflows#create-a-workflow-dispatch-event)提供现役 workflow 的触发机制，但不证明该工作流能启动现用网页版研究。先核 action allowlist、真实日常用途、来源权限、session/去重与下游影响；Sector完成交易日生产不能冒充盘中/全球快照，历史修复选项不能默认重跑。

[Workspace Agents 官方触发说明](https://learn.chatgpt.com/workspace-agents/trigger-runs)提供已发布 agent 的触发入口，并有 beta run 状态；文档同时说明当前不能经该 API 取得 agent 的研究响应。它是候选机制，不是本项目账号/宿主可用性的证据。需分别核 agent/工具/凭证/费用、当前上下文是否可访问、GitHub保存与精确恢复，不把202/运行完成等同成果可读。

[ChatGPT插件UI](https://developers.openai.com/plugins/build/chatgpt-ui)依赖实际宿主环境，不能把内嵌组件能力外推给独立 Sites。先发现真实宿主工具/官方接点，现有环境可用则复用；缺入口只阻塞该动作。不静默启用旧 API、切换模型/研究者、绕过权限，或造PR/邮件/新轮询任务来假扮Quick触发器。

尚未建立执行接点时，按钮只能诚实地表达“准备/复制接续请求”或“前往研究”，不能写“研究已开始”。过渡方案不算一键Quick验收完成。没有额外费用或权限的普通工程继续；新增支出、服务/账号连接或私人资料外发须按实际边界处理，不默认获准。

### 4.3 一次明确请求的生命周期

请求须绑定真实 owner、对象/事件或市场范围、实际 M/R 与前驱/更正、所选动作、已有权限和来源范围。技术参数由已验证定位恢复，不让 Human 手搬 hash；来源正文不能升级为指令或授权。

有读/写分离、服务端凭证、有限动作与参数校验。浏览器/公开URL/日志不放 token；owner-only 页面不等于后台任意 dispatch 权限。重放、跨用户请求及伪造对象要失败，不把隐藏按钮当安全控制。

连续点击、已在途执行、同次提交响应不明和自然任务重合要先对账；复用既有请求/执行记录，不新建竞争状态中心。不宣称 concurrency 等于 exactly-once。未经明确有效许可不重跑历史消费；失败后保留原请求、源时点和部分成果。

页面分别报告实际可观察的“已提交/待启动/运行中/等待外部动作/失败/成果已保存/已发布可读”，具体用现役真实状态投影，不为这些文字新增一套Kernel枚举。不得编造研究内部阶段或百分比；“请求停止”不等于“实际停止”，关闭网页不证明后台任务存在或已停止。

完成后回读该请求真实成果和适用范围；旧数据在失败时仍带原日期，新失败不被旧成功覆盖。GitHub成功、来源无增量、保存失败和研究未完成均不同。Quick能建议Full，不能自行委托Full、接受研究、交易或改变个人身份。
