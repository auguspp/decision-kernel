## 1. 当前与下一阶段；谁拥有哪种决定

当前 R5.1/R5-5 自然使用、研究连续性、唯一交付和真实故障维护继续。原 5–10 个真实交易日的观察不能用 CI、历史回放或同日多个 runner 替代；本文件不宣布 P1 整体验收完成，也不追加新模块作为原 P1 收口条件。

主交付保持 **0 架构复用 → A 可用 Home → B 世界观察/日历 → C 发现质量 → D 机会与校准**。**L 持续学习横向贯穿**。这是交付顺序，不是五个新后端，更不是要先完成全部底座才让用户使用。

- Requirements Management 拥有目标、顺序、范围、验收和前提变化处置；#297 是当前执行导航，本文件是版本化方案，不另建需求数据库。
- Main Construction 拥有具体实现、实际工具/依赖验证、代码级复用、测试、正常合并与发布、失败处置和回退。已批准范围内的普通技术选择不逐个问 Human。
- Researcher 自主探索和解释，保留可检查的结果、支持/反证、计算、UNKNOWN 和适用边界。Kernel 验证身份、时间、来源、前驱、用途与权限的一致性，不认证经济真理。
- Human 保留 Full 委托、研究/方法接受、个人风险与偏好、资本决定及重大产品取舍。继续施工不是接受研究；接受研究不是交易。

**默认一个主工程交付批次，另可有一个不争用同一状态的有限只读准备/评估。** 不是 API 调用额度，不是禁止独立工作。只有实际交付、身份/权限或严重误导的故障可抢占；其他新想法回到台账，不无限加入当前批次。H5 未确认前，仅沿已有授权做架构只读准备，不用本文件开启生产改动。

## 3. L：贯穿的持续学习，而不是最后一个大系统

原件：[#508 Learning Loop](https://github.com/auguspp/decision-kernel/issues/508#issuecomment-5835509882)、[Full Method v3](full-research-method-v3.md)、[原决定/结果协议](prospective-decision-outcome-capture-protocol-2026-09-03.md)。复用现有案例、前驱/更正和用途索引；不新增五个学习 Agent 或五套状态。

- **L0（0 批）**：找回现有正例/失败例、规则适用范围、接受/生效版本和消费入口；分清案例记录、候选经验、已接受方法和实际采用。优先比较现有恒瑞写作回归的机制，不把它的文章结构套到 Full 研究。
- **L1（A 批）**：一个有界案例能从实际反馈形成可检查的经验/修改，经适用权限接受，在后继真实相关任务中定位到采用或不适用的记录，并保留效果未知/退化可能。内容被注入、单测通过不等于语义效果已改善；没有自然后继就分别交付机械能力、保留真实采用待验，不重跑旧公司凑数。
- **L2（B/C）**：来源错误、重复新闻、漏检、业务关联/现金桥修正、Human 追问与复用决定分别归因；正向观察结果和反向漏检分开，案例相互关联不能当独立样本。
- **L3（D）**：季度/年度实际结果到来，才对预测的量/价/份额/利润率/资本/现金/期限和估值表达分别比较。过程质量不必等多年收益，长期统计不能提前造数。

闭环是 **案例 → 反馈/结果 → 可检验经验或修改 → 对照/反例 → 接受与版本 → 后续采用 → 效果复核/撤销**。只按任务检索相关且已适用的经验，不把全历史常驻塞入上下文。新经验不能倒灌为历史时点已知；原方法回放与新方法的反事实对照分别标识。日期过滤不能证明模型没有训练知识污染。

记录反馈、提出候选、采用已有有效规则，不等于授予自动修改研究方法的权限。研究方法、个人风险/偏好及判断的实质变化仍须对应明确接受；AI 不从点击、沉默、同代码成交或短期盈亏推断个人心理/原意。工程缺陷按原批准工程权限修复，不为每条经验增加一个永久 CI 门禁。

## 4. 全阶段执行原则：开工、审阅、交付都要检查

### P01 认识论与权属不漂移

Evidence changes Belief. Price changes Odds. Data != Evidence != Judgment != Decision. Radar 机械发现，Research 自主解释；UNKNOWN 可保留，不编造为什么。Kernel 验一致性而非经济真理。AI Investment Authority=NONE。页面、数据接入和学习不能产生新的投资权限。

### P02 每模块三层最佳实践核查，自建须举证

沿 [AGENTS Reuse First](../AGENTS.md)：内部实现/真实消费者/既有成功失败；官方能力/工具/接口；外部开源和成熟模式均要覆盖。严肃候选须看具体代码/合同/测试和实际使用约束，而非仅 README/stars。保留精确版本、实际阅读范围、适配/不适配、维护与当前许可义务，以及 REUSE / THIN_ADAPTER / NEW_BUILD_JUSTIFIED。

复用仍有效的旧审阅并补查 delta；不强制候选数量或无限全网调研。不选依赖也可以借协议、测试和反例。当前具体 blocker 以外的“以后更灵活”“写起来快”不足以支持自建。用户是个人实际使用，不预建商用、多租户、机构审批或通用终端；现在真实适用的许可、隐私和安全义务仍须遵守。

### P03 可插拔是可替换、可停用、可失败，不是插件平台

薄宿主 + 普通有界模块 + 明确装配优先。模块声明实际输入/输出、依赖、兼容版本、数据时钟/来源、权限和失败影响；不先造万能 schema。界面、来源适配、研究执行环境可以分别替换；不因新增 Calendar 重写 Research/Odds。

关闭或失败一个可选模块，无关阅读继续可用；真正依赖它的结论保留未检查/缺口。版本不兼容显式失败，不静默换来源口径。读取本身不调用新模型、重算 Odds、收费取数、启用 Watch 或交易。首版不做动态远程插件、插件市场、微服务群或通用事件总线。

### P04 一个事实/结果有一个明确拥有者

GitHub 继续是正式状态、证据、版本与过程后端；多个视图只投影或引用同一记录，派生搜索/缓存可重建，不成为第二个研究或决策库。Quick/Full 是成果类型，不割裂成两套档案。公司、主题和事件共用定位，允许没有股票的研究。

若 Human 选择公共核心 + 私有资料仓，必须先明确互不竞争的数据归属、访问与恢复路径；这不是批准把同一状态双写两处。外部服务缓存不得夺取 canonical ownership；模块或模板升级不覆盖私人历史、Human 回应、前驱/更正或原始证据。

### P05 隐私是发布前置，不是隐藏网页菜单

本轮 GitHub 实际 metadata 显示主仓库 `private=false / visibility=public`；不能从“个人使用”推断仓库私有。H1 决定前，不向公开仓库新增真实持仓、成本/数量、私人回应、个人偏好或校准画像；规格文档/无私人数据的测试可继续。

私有视图的 HTML/JSON、构建附件、日志、搜索索引和缓存也要纳入访问边界；秘钥不进入浏览器、源码或公开 URL。旧公开历史是否需处理另作有范围清单，不擅自删除/重写，不承诺改变可见性会收回已传播副本。第三方接入仍核具体服务、数据接收方和实际权限，预算批准不是任意外发授权。

### P06 数据与研究时钟、覆盖和有效性分别呈现

代码 commit、读取包 commit、市场日、统计期间、公开/取得/修订时间、分析截止各守原用途。局部结果不当全市场，旧成功不抹新失败；没有取得不能写零，无新闻不等于没有事件。

宏观前值修订、商品合约/换月、债券期限/单位、股票股类/币种/公司行动、加密资产场所/计价/现货衍生品在消费者实际使用时明确。外部观察不需先成为股票候选，经济映射由 Research 解释，不让技术筛选替代研究准入。

### P07 Attention 保持续事项，采集/研究/打扰三个节奏分开

Quick 给分析，不是所有可见事实的唯一闸门。有效已登记价格复核、明确等待 Human 回应等必要事项，在分析延迟时仍可见且标为待分析；不得说第一笔已就绪。重大事件的强制分类/优先级须有明确产品定义，不借原则任意增提醒。

同一事件归并更新，不每天包装为新发现；已读≠处理，暂缓≠拒绝，同意 Full≠接受研究≠资本决定。价格距离复用有效边界，未定义的接近区间不得自造5%/10%。采集可以更宽，Research 按增量，推送按相关性/必要性和 H4；不以每日候选数为 KPI。

### P08 经验必须能采用和撤销，方法可替换

按第 3 节 L 验收，不将日志、反思、规则注入与实际改善混用。固化成果责任而非私有思考过程、工具顺序或固定 Agent 数；方法可以修订，原历史不能因此改写。候选方法/个人判断修改不自动升正式政策，收益、点赞和 Human 满意不能单独决定研究对错。

### P09 前提变化先对账，模块退出连同专属负担处置

沿 AGENTS 的 Reconcile Before Continuing：旧前提 → 新证据/指示 → 影响的当前与待建项 → 保留/合并/退役/挂起 → 后继。更新当前入口，不只把新决定埋在评论；同时保留历史原文。

模块退役同批核专属执行器、任务、依赖、fixture、测试、配置与引用；共用保护和必要历史 reader 保留。不得以零引用或年代自动删测试，也不得默认 CI 只增不减。新正式边界必须解释交接、恢复、兼容和长期维护成本。

### P10 验收针对真实产物，遵守现役 CI，不制造合规工程
