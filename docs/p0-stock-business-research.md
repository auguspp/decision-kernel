## Source scope and clocks

Use the original official CNINFO organization mapping and coherent pagination
for one explicitly recorded 400-day query. Select the most recent **reporting
period** among complete annual/half-year reports, then its latest published
version. An old annual report reissued later cannot displace a newer half-year
period. Summary titles do not count as full business reports. Ambiguity, unknown
or future publication times/periods are source gaps.

Capture ALL disclosures from the earliest full version of the selected reporting
period through that inventory, including intervening risks and prior report
versions. The latest report version is labelled explicitly; a later correction
does not reset the inventory anchor or erase earlier risk disclosures. The bound is 32 required bodies,
not a bullish headline filter. Original PDF bytes, original extracted pages,
decoded query responses and partial process records stay in the original run
artifact. Decoded API JSON is not labelled HTTP wire bytes. The full declared
body scope is supplied without silent clipping. This is not every issuer channel,
industry/customer/competitor evidence or full-company Deep Research.

New source acquisition may occur after the market session. This is current
Research triggered by a dated price observation, NOT historical price-causality
or PIT research at that market close. Price/member identity cannot establish
business benefit, economic significance, current expectations or WHY.

Original PDF structure/identity checks run first. Missing/damaged extraction
may use the existing same-PDF PDFium representation and trusted-main page notes;
no unreadable page is silently dropped. Bound representations and actual visual
notes are checked again before each model stage. Different representations are
not independent Evidence. Table semantics/signatures/source truth still require
appropriate interpretation; hashes do not certify them.

Complete context must fit a finite 448 KiB saved-context bound and a 512 KiB
system/input/schema request bound. The original executor's default stays 128 KiB;
only this trusted caller opts in. A larger required packet fails explicitly,
without selecting convenient snippets or claiming Research completed. These are
technical byte limits, not monetary/daily quotas, full HTTP-wire sizes, or proof
that a provider will accept every permitted request. Original extraction limits
and the existing 200-page alternative-representation bound remain.
