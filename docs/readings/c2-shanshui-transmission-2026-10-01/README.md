## 1. 本轮问题及实际处置

原研究已从股价/概念标签提出“氯代吡啶的销量与成本、6-硝体的价格与销量分别贡献什么”。本轮不把该问题包装成新发现，而是补三项可检查的回答：**哪个产业观察能够使用；产品层面已经兑现了多少收入与毛利；现金增长是否来自经营。**

结论是：现有材料支持公司氯代吡啶业务扩张的解释，却不足以将所有增长归因于染料涨价，也不足以认定产业指标已提前识别公司盈利拐点。保留有依据的经营解释，拒绝错配的行业代理；没有从涨幅直接提名 Full 或创建 Watch。

## 2. 先检查产业观察是否真的是同一种东西

本次从固定 R `d1127cf0cf7c7dd3ec3d2e8a4415160a0186a22f` 实际读取原 `industry-fundamentals.json`：10个来源族、360条分口径序列。只选择与本问题可能有关的三条，不声称审过全部公司映射；同一 observation 在 current 中重复展示不重复计数。

| 已保存观察 | 本例可以怎么用 | 不能据此推出什么 |
|---|---|---|
| 2026年9月中旬95%草甘膦原药，27092.9元/吨、原报告较上期+6.4% | 保留为该明确产品的产业价格背景 | 草甘膦不是氯代吡啶；所获公司描述列举敌草快、氯吡脲及医药用途，没有建立该报价到公司实现售价的直接桥 |
| 2026年8月“布”产量26亿米、同比+5.2% | 宽口径下游活动背景 | 不等于酸性染料需求、6-硝体订单或单位耗用量 |
| 2026年1—8月“布”产量198亿米、同比+3.2% | 累计观察，与单月分别保留 | 不能与单月相加，也不能直接解释上半年公司收入 |

[公司年报 ANNUAL](https://money.finance.sina.com.cn/corp/view/vCB_AllBulletinDetail.php?id=12226509&stockid=301190)对6-硝体的主要用途描述是酸性染料。原“分散染料”概念成员资格不能替代具体产品暴露。这是本案例的证据映射判断，不新增全仓业务分类门禁。

另读 [行业协会体系发布的上半年印染分析 ASSOCIATION](https://www.cntac.org.cn/zixun/shuju/202608/t20260811_4418268.html)：规模以上印染产量同比+4.93%、营收+0.87%、利润+6.75%，2043家企业中779家亏损。它提供独立于公司的行业背景，显示增长和压力并存；但其底层统计仍注明来自国家统计局，不能与同源统计重复算成多次独立确认，也不支持公司的具体客户、酸性染料用量或农药中间体价格。

## 3. 用实际产品数据检验增长解释

年报同一收入表的2024、2025年口径可比：合并收入增加 **265817202.79元**，其中氯代吡啶系列增加 **261606937.64元**，占总增量 **98.4161%**；6-硝体与氧体合计增加2332102.52元，其他增加1878162.63元，三项精确勾稽。这里是**公司收入增量分解**，不是市场份额、利润贡献或因果识别。

[半年报已取得的产品明细 H1](https://money.finance.sina.com.cn/corp/view/vCB_AllBulletinDetail.php?id=12526458&stockid=301190)补上原 #701 聚合数字的构成：

| 2026H1，人民币元 | 收入 | 成本 | 差额毛利 |
|---|---:|---:|---:|
| 6-硝体、氧体 | 179325374.25 | 103994070.06 | 75331304.19 |
| 氯代吡啶系列 | 252106810.63 | 170446543.44 | 81660267.19 |
| 其他产品 | 45751616.83 | 38419597.52 | 7332019.31 |
| 合并合计 | 477183801.71 | 312860211.02 | 164323590.69 |

氯代吡啶已是较大的收入来源，但染料中间体仍提供重要毛利；两类毛利率分别约32.39%与42.01%，不能把收入份额当成利润份额。上述总收入、总成本与前驱逐字面值相同，新增的是拆分，不是更改已知总量。

本例没有补造完整2025H1同口径产品表，也没有把2025全年与2026半年直接当同比。不同产品组合、产线爬坡与成本分配仍可能同时作用；产品家族平均值也不是相同规格的成交价。毛利尚未扣管理、研发、税息及资本负担，不能据此宣称项目 ROIC 或股东现金回报已成立。

## 4. 现金变多与经营造血不是同一结论

年报合并现金表2025年度列显示：经营现金 **-146250662.98元**，购建长期资产现金 **69364751.75元**，两者相减 **-215615414.73元**。投资现金净流入 **481594417.12元**，其中收回投资757000000元、投资付款222000000元，另有投资收益收款、资产处置与长期资产付款。

加上筹资现金-74766006.95元，三类现金净额与现金增加260577747.19元勾稽；期初至期末现金也另行核对。原汇率影响栏留白，本例只报告零残差，不把留白补成发行人明确报告的零。

这改变了本例的研究重点：不能因为期末现金增加就跳过经营回款，亦不能把全部投资流出视为资本开支。2026H1前驱已经报告经营现金转正，但不同期间的现金管理、票据结算、再投资和经营表现要分别追踪。上述现金缺口不是 FCFE、维护资本开支或投资毁值的证据；未来能否持续自筹经营和建设仍未识别。

## 5. 哪些是补证，哪些仍未取得

ANNUAL 是本次实际打开的发行人年报镜像解析正文；H1、ASSOCIATION 是搜索返回正文片段，直接打开失败。没有保存原始HTML/PDF，没有视觉复核，也没有声称查全公告。不同镜像和媒体对同一公告的复述不是独立经济证据。9月29日6-硝体量价说明仍缺原公告完整对应段落，不用二手重复补成数值输入。

2025年实际、2026上半年实际、8月产量和9月中旬价格是四种期间；资料公开日期、实际10月阅读、Git保存也不同。新取得的旧期间明细属于材料覆盖补充，不是10月新发生的公司经营事件，不回填历史已知或自然领先效果。

## 6. 复用与复算

四个文件是 `facts.json`、`replay.py`、`validation.json`、本说明。`replay.py`只构造本例显式输入，并调用已有 `research_comparison` 和原两文件 create-only writer；没有新比较算法、依赖、生产源或指标引擎。源事实固定于 `422f83d2af8357a4f6d7dff8aec2a306a088d459`。旧 #701/#702 的 pandas2.2.3 运算复用评估仍适用；本批分数交叉计算使用标准库，不为研究判断安装框架。

在包含本批所用原Kernel代码的环境，恢复前驱 research-use.json 后显式执行：

```sh
python replay.py facts.json /path/to/original-research-use.json /new/output/directory
```

原比较器处理35条源绑定观察、27项比较；验证记录保存完整输出JSON/Markdown的字节数和SHA256及report_hash，不再把同一长输入/输出复制多份进仓库。独立Fraction核对全部27项，另核两个收入差额和现金余额滚动；实际原CLI与本例输出逐字节相同。篡改、合并/母公司混用、期间不匹配、权限升级被拒绝，缺前驱不补零，已有输出目录拒绝且不变。准备时的本地导入、两文件发布及字典显示顺序修正留在validation，不改共享合同凑通过。

用途入口以同一 `c2-k3-research-use-20261001` 明确接续本目录，并保留首段旧原件链接；不新增第98条、不隐藏前驱、不扩大192KiB上限。正式PR、主干、正常发布与新R实际恢复分别沿后继回执确认，本说明不自签完成。
