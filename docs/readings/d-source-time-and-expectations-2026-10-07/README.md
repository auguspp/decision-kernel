## 1. 普源精电：报告口径与预期口径必须先对齐

原预告三项实绩均在区间内的结论保持：总收入、归母净利润、扣非归母净利润分别 486842894.90、37147734.08、23048069.32 元。原预告为 2026-07-06 文件，H1 实绩为 2026-08-26 A 股报告（S1/S2）。同比改善不自动构成对市场的正向意外。

新增原件 S3 的港股结果表以千元列示收入 486843、净利润 37147；第22页 non-IFRS adjusted net profit 为净利润加股份支付 3757，得到 40904 千元。它不是 A 股扣非 23048069.32 元。把 40904 与原扣非预告区间相比会人为制造超预期；A 股报告另有剔除股份支付影响口径，仍需保持表名、精度及准则边界。

更重要的反例：A 股报告第28页总营业成本 220805439.15 / 上年158352858.95 元，相应毛利率约54.6454% / 55.3896%；港股第3页 cost of sales 为231887 /170651 千元，毛利率约52.36925% /51.92496%。同比方向也不同。已对原 PDF 页面作目视核对；这里只证明列报不可直接拼接，不认定公告有误，也未查明 11081560.85 元当期成本差异的具体会计重分类桥。经营判断应沿同表口径，再查明成本组成、费用、现金和股数，不能把表间差异当经营变化。

港交所结果文件的列表发布时间为 2026-08-25 20:55（网站显示的香港当地时间，S4）；这是该具体文件的可得时间证据，不是所有渠道最早披露的证明。CNINFO 的 announcementTime 为8月26日日期，storageTime 解码为8月25日17:12:08（UTC+8），后者不是已证明的公开时钟。不得把报告日期00:00写成精确首发时刻。

命名券商摘要 S8 将2026/27收入预测10.75/12.80亿元调至11.05/13.20亿元，而净利1.66/2.13调至1.29/1.97亿元：上调收入与下调利润可并存。该摘要不是全市场共识；新浪标8月26日、同花顺索引标8月25日，原券商完整PDF与原预测版本未取得，故不把摘要日期当精确事件前预期。此项仅为有来源限制的叙事反例，不作交易信号。

复核条件：取得可比成本重分类、现金改善与融资后每股盈利证据，再判断经营兑现；事件前市场预期、同期合格价格路径仍不足，期限特定 Odds 与机会概率仍未建立。

## 2. 圆通：原始量价已确认，单位利润仍未知

S5 原始2026年8月经营快报（1页、未经审计）明确：快递产品收入58.19亿元，同比7.95%；业务量28.36亿票，同比12.93%；单票收入2.05元，同比−4.40%。这补上原档案仅有媒体转述的来源缺口。

若沿披露单票收入与同比做近似反推，上年约2.14435元，本期收入压力约0.09435元/票；要维持同口径单票毛利，成本下降至少抵消该量。因披露舍入，58.19/28.36的比值不必精确等于2.05，不应据此指控错误。

该一页公告不披露当月单票成本、利润、末端补贴或加盟网络健康。H1成本与同业并表后单价不能填为8月实绩。量增长可与单票利润下滑并存，单票利润下滑也不必等于总毛利下降，必须联合考虑量、价、成本及资本投入。

复核条件沿原 YTO 证据触发设计；需公司同口径成本、季度单位利润及现金/加盟网络证据。保留原 QUIET 和原Human状态，不因取得原件创建价格触发或自动跟踪。
