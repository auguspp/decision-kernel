## 交付结论

本批分别处理 MU→兆易、三花、同业申通→圆通三个不同的经济问题。结论不是一律“没有机会”，而是排除三个不够成立的理由：把收盘后发布的结果归因给此前收盘；把目标价降幅全部当盈利下修；把并表后的同业单票收入增长当成另一家公司已兑现的单位利润。本次没有新建研究/交易平台，亦未生成三个历史买卖信号。

### 1. MU→兆易：日历日期相同，不代表同一信息集

美光8月26日的预约稿先宣布9月30日14:30 Mountain的电话会；它证明预约早已公开，不能提前交付财务结果。选定的发行人业绩发布稿标示 **9月30日16:01 ET**。按该日期纽约时区换算为 **10月1日04:01北京时间**，比9月30日A股15:00收盘晚 **13小时01分**。[M0、M1；时区复算]

因此，保存的兆易9月30日收盘及以该日结束的5/20交易日变化，不能归因为对**这份随后发布的业绩稿**的反应。这里没有认定财报全部内容此前绝不可能被预期，也没有排除早期公司指引、其他公告或行业信息；只是为这一个来源明确适用时间。发行人分发稿时间也不认证所有相关事实的最早市场知悉时刻。

经济链仍需分别成立：MU发生变化的实际产品/供给变量，是否关联兆易真实产品暴露，重要程度多大，价格和成本如何传到毛利额、营运资本及现金。MU的公司业绩不能直接成为兆易的实现值。本件不重复原经营算术，也不改10月4日冻结案例。[G0]

**期限处置：** 对9月30日及之前的短窗，停用这份结果稿作事后反应依据；对原冻结后的5/20交易日窗口，沿既有日历/价格规则等待真正完成的端点，不倒填收益或重置S0。中期传导假设只有在相关产品、成本后毛利和现金新资料支持时才增强；产品供给缓解、成本吞掉收益或现金转换恶化时削弱。原长期Research截止2027-09-02与11月30日分析者复核日不变，不以美国电话会时刻代替A股窗口。

### 2. 三花：盈利修订与目标价变化不能合并成一条“基本面恶化”

已恢复9月2日16:46:48Z保存的原研究版本；其第8节记录同一家中金的2027年归母预测下修 **4.0%至54.22亿元**，H股目标价 **40→35港元**。本次重新核该历史commit的正文blob与现役文件相同，来源资格仍是保留的分析者预期复原，**不是新取得中金完整报告或模型**。[S0]

新分解为：
- H股目标价变化 `35/40−1 = −12.50%`；
- 以该2027利润变化作一个分母，剩余目标价/利润比变化 `0.875/0.96−1 ≈ −8.85%`。

这个剩余量**不能直接命名为纯市盈率下调或已识别原因**：原始估值年份、汇率、股数、估值方法和目标期限的完整桥尚未取得。它足以排除“目标价下调12.5%，所以公司盈利下调12.5%”的误读，却不能据此给A股套一个新的买点。54.22/0.96倒算的原利润仅约56.48亿元，源修订百分比有舍入，不添假精度。

**期限处置：** 短期目标价/估值表达与当期经营分开；新的可比同机构盈利修订及其业务原因可以推进对应桥，单纯目标价或倍数变化不能证明核心经营改变。原Human约30元条件及**实际执行后3–6个月**评价窗保持，不能从9月3日记录日或9月30日行情日启动。没有新的执行输入，本件不评价该Human决定的盈亏。[S1] 长期仍由核心制冷/汽车业务、现金和增量资本回报支撑；机器人/液冷商业化语言不能自动变成已实现利润。更强反例是目标价可能因估值或风险溢价改变，即使经营预期相对稳定；这不应被错误算作经济假设失败。

### 3. 申通→圆通：并表、平均单价、单位利润是不同层次

申通8月经营简报的发行人正文明确列出收入同比 **21.95%**、业务量 **18.00%**、单票收入 **3.40%**，并说明丹鸟自**2025年11月**纳入合并范围，数据未经审计、单票计算存在舍入影响。本次使用文字段落，不读取未取得的图片表格。[Y0、Y1]

这意味着该2026年8月与上一年比较有业务范围变化。不能直接将混合后的平均单票收入增长叫同口径提价，更不能移植为圆通单位利润改善。与此同时，也不能反向断言全部增长都来自并表；未取得剔除并购的同口径数据，真实有机增长仍待判定。

**算术挑战与反驳一起保留。** 若三项增幅都是同范围精确比率，单票增幅应为 `(1+21.95%)/(1+18.00%)−1 ≈ 3.34746%`。只允许两个增幅最后0.01个百分点的四舍五入，导出范围约 **3.33884%–3.35607%**，与3.40%的对应舍入带不重合。但这**不证明公告错误**：公告的舍入说明可能发生在单票金额层，而非只在增幅最后一位。

具体的合成反例：假设未舍入上期单价为 **2.064**，当前为 **2.1330915…**，真增幅正是3.34746%；先将金额保留两位小数后得到2.06和2.13，再计算增幅约3.39806%，即可显示为 **3.40%**。这只是构造出的可行舍入路径，**不是从未读表格取得的原始单价，也不证明发行人实际采用此算法**。故本次不会自动纠错、清洗或否决原来源。

**期限处置：** 同业一个月的单票收入不是圆通的利润/现金证据；日到数周的“行业修复”理由应先查剔除并表和产品组合的同口径变化。中期要看圆通自己的单位收入、单位成本、加盟网络经济和现金是否共同变化。原圆通“单位快递利润明显低于0.18元、连续两个季度且无结构性成本重置”的反证对象是**公司单位利润**，不能换成同业月度收入、一个月结果或新自动门槛。[Y2] 原Research保持，新的公司证据才使相应桥重开；Peer观察本身不启动Full或Watch。
