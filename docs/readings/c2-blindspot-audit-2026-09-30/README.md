## 结论先行：现在不该统一放宽门槛

1. **宽行业稀释、当前门槛与交付失败是三种不同问题。** 旧104交易日、三日上四分位挑战中，军工装备宽类从未满足里程碑，航海装备细类4月27日满足；这说明那个旧规则存在颗粒度问题，不能据此宣称后来的生产持续性/加速规则永远发现不了航海装备。后来的66日研究里，宽军工装备与细航海装备9月4日均产生ACCELERATING_ENTRY。
2. **更早不自动等于更有用。** 同一个已冻结66日研究中，航海装备7月10日被简单baseline选中、没有新Radar entry；20日超额连续为正只有1日，不足原两个生产门槛的5日。此后T+5超额约-8.893%、T+20约-2.052%。这是反对“为抢早直接降低持续性”的真实负对照，不是独立投资错误概率或交易回测。
3. **成果没送达不能伪装成没发现。** 9月29日Quick实际完成并向Human交付迪哲医药、长盈通两个Full候选；canonical保存被拒而NOT_SAVED，Brief随后把未取回压成无新候选。旧Brief指令本已禁止这种推断；native Library fallback在该次自然运行之后部署，仍需下一次自然消费证明。不能靠本地回放补签PASS，也不为此另建仓库Brief子系统。

实际用户处置：保留现有门槛，保留宽/细类及注意力成本分层；对缺失成果使用“截至读取未取得”而非“没有新研究”；继续单列独立个股覆盖与历史成员资格，不把未证明部分封成工程完成。
