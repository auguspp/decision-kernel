## 已交付的用途与结论

将北大荒、光电股份、茅台的八份真实历史原件组成可重复的 D2 对照：当后续复盘要归因于价格、方法、概率或 Human 行为时，先看这几个具体反例。不是新增通用准入层，也不自动裁定经济真理。

**最重要的结果：四次版本变迁不能算成四个独立预测结果。** 本证据集可以确认一次估值解释修订、一次精确版本的 Human 接受、一次单位表达错误及估值挑战；另一次标签变化原因不足以归因。没有匹配的成熟经营实绩、合格概率—实现值对或真实执行结果，预测误差、Brier 分数、胜率和方法改善幅度均保留 `null`，不是零误差或零能力。

原 Odds Book 已记录这些事件，本件不冒称首次发现。新增工作是：从固定读取根取回原件、核实前驱与接受目标、对共同数值做控制比较、把文字单位与 JSON/每股算术交叉核对，并给这些案例实际运行负向错绑测试。

## 1. 北大荒 BA1 → BA2：同价、同 Research、同计算框架，解释改变

两份原 JSON 的 Research commit/path/blob 相同，参考价同为 2026-09-15 的 12.33 元公共背景价，三年、10%工作敏感性和1.20元累计税前分红假设也相同。两者 `schema_version` 都是1，但 BA2 明确声明 `VALUATION_INTERPRETATION_NOT_PRICE_ONLY`、无新经营证据、未刷新价格。[BA1、BA2]

共同21倍和24倍反推所需2029归母利润分别仍为1,287,652,277.39元与1,126,695,742.72元，数值完全一致。条件首笔**复核区**却从10.0–10.7元变为9.8–10.3元，两个端点分别变化−0.2和−0.4元。这是原解释/选用假设的修订，不是本次设定新价位，也不能归因于价格变化、算术纠错或新增实绩。

可查责任：BA2原作者关于核心倍数及利润增长证据的重新解释。尚不能查明：未记录的内部模型/提示版本；未来哪个方法更准确。**同一序列化版本不代表同一研究方法；不同 Git commit 也不等于方法已升级。**

原 Human 文本“嗯，我现在同意了 odds”明确指向 BA2 的精确 commit和blob，且声明仅用于决策准备，无投资决定/Action。[BA3]

## 3. 光电股份：可确定的表达错误，与仍未解决的经济桥分开

除同R原JSON和后继复核外，本次按复核明确引用，取得原工作分支的完整Markdown（独立历史commit，不伪装成R内副本）。[GD_JSON、GD_REVIEW、GD_MARKDOWN]

五个世界的十个利润端点，旧正文的字面 bn CNY 金额都是 JSON 元数的十倍；但用原 JSON 的人民币元、股数与倍数复算，十个每股端点均与原显示值在两位小数舍入范围内一致。核心世界仍可复算为11.0515–17.4181元，对应旧显示11.05–17.42元。

因此已定位的是**旧Markdown单位标签与结构化金额不一致**，不是证明模型少算了十倍价值，更不是概率校准失败。原复核关于历史高低点、跨机构/跨年份预测与首笔梯度的挑战仍单独有效。单位更正不能给旧盈利世界背书、恢复行动梯度或撤销任何真实Human决定。本轮不重做该公司的估值。

## 5. D2本批责任分栏

| 责任 | 本批能验证什么 | 不能升级为什么 |

```sh
python audit.py --source-dir /path/to/recovered-inputs --check
python audit.py --source-dir /path/to/recovered-inputs --self-test
```

本轮已经执行结果生成、精确字节重放以及十项**明确合成**的负向控制：变价、变期限、错前驱、伪价格单变、把未建立概率变成0、借用别版Human接受、删除单位证据、改每股值、缺标签正文、篡改源字节。它们不是十个真实案例或独立审阅者。`--check`/`--self-test`不写源文件；`--output`只创建不存在的新结果文件。

脚本只是这一组原件的工作底稿验证，不接受任意用户输入去推断语义，不新增生产枚举/校准状态/CI门禁。字符串和数值检查不能保证自然语言推断普遍正确；最终归因解释仍须研究者审阅。详见 `verification.json`。正式CI、合并、正常发布与固定新R采用不由本文件预签。
