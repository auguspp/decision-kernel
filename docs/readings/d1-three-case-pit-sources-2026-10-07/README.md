## 2. 兴业：已知早期业务不归零，但对价不等于全部现金义务

本轮读到7月23日公告2026-046的九页PDF解析文本：取得的业务已有2/3英寸客户认证和小批交付，4英寸验证、规模盈利仍有约束。两者不能压缩为“纯概念”或“已进入高利润量产”。这些基础结论在[9月14日修订研究][X0]中已存在，不重算为新发现。

此次新核对协议p4–5（按PDF从1计页）：交易价款5,500万元，已付1,500万元定金冲抵首期；剩余对价4,000万元。另有向关联债权人清偿553.36万元的条款，原文明确该清偿不抵扣交易价款。[X1]

因此，在这两类约定现金组件内，`5,500 + 553.36 = 6,053.36万元`；不是`5,500 + 1,500 + 553.36`。它不是完整企业价值、全部承担债务或后来实际支付现金总额；未知费用、其他负债、建设与营运资本不填0。不能仅用5,500万元和净资产相除便认证资本回报或交易公允性。

[X0]已经记载后续剩余收购款支付、技术交接及人员入职。本次重读更早合同**不把这些已保存状态回退为全部付款未知**；但它也不能独立证明上述额外清偿、全部过户或未来资本回报已经完成。立案具体事项仍沿原研究UNKNOWN；本轮所试立案原PDF未取得，媒体对动机/具体违规的推测不当监管结论。

**当前处置：** 沿用“传统经济衰减与InP独立接力”的原框架；规模重复采购、良率/实现价、资本投入与现金回款仍是分辨点。仅业务交割、同行需求或股价反弹不足以把3年成功依赖世界压成几周内必然利润。原17元以上WAIT等条件不变，不新增治理折价或概率。[X0、PRE]

## 3. 三花：审批、实施安排、持有人红利与参考除息额分别保存

旧档案9月23日/30日未复权收盘35.99/35.71元保持不改。下表仅展示**额外假设持续持有、在登记日符合资格且按上述安排完成分配**时，该端点比较会怎样；没有核真实持仓/成交、税费、再投资、全部其他公司行动或供应商因子，因此不称完整总回报或可执行策略收益。[W、S2]

## 6. 取得范围与复算

H1/S1/S2及H2实际采用指定报纸发行人公告的搜索索引正文/转载表示；直接HTML打开失败，未持久保存完整原网页。X1得到PDF完整解析文本并实际调用第1/2/4/5页截图，但截图均失败、容器PDF字节下载也失败，故**未做成功的页图核验或原PDF归档**；页码/段落为解析器映射，非原表视觉认证。X0/原五例和价格保管说明按各自精确Git版本读取。N1/N2仅公开解读索引，不冒称发行人原件。失败只限制相应来源，不阻断其他授权研究。

下列离线算术使用Decimal与Fraction；它不是新常驻测试、模拟市场样本或正式CI。按公告每10股结果保留六位直接截位，再除以10，复算参考调整额；持有人毛红利不截成该值。

```python
from decimal import Decimal as D, ROUND_DOWN, getcontext
from fractions import Fraction as F
getcontext().prec = 50
all_a, treasury = 3731477535, 13851943
eligible = all_a - treasury
assert eligible == 3717625592
cash = D(eligible) * D('0.12')
assert cash == D('446115071.04')
ref = (cash / D(all_a) * 10).quantize(D('0.000001'), rounding=ROUND_DOWN) / 10
assert ref == D('0.1195545') and ref != D('0.12')
start, end, div = D('35.99'), D('35.71'), D('0.12')
raw, with_cash = end / start - 1, (end + div) / start - 1
assert F(end) / F(start) - 1 == F(-28, 3599)
assert (F(end) + F(div)) / F(start) - 1 == F(-16, 3599)
assert raw < with_cash < 0
assert abs(with_cash - raw - div/start) < D('1e-48')
assert D('5500') - D('1500') == D('4000')
assert D('5500') + D('553.36') == D('6053.36')
assert D('6053.36') != D('5500') + D('1500') + D('553.36')
```
