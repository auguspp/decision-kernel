## 实质结论

圆通H1归母与扣非实绩均在原公司预告范围内；同比改善和范围兑现不等于超出市场预期。旧版扣非null保留为当时读取缺口，新值来自原表，不借归母填充。

华创7月1日与8月21日的2026–2028年归母预测逐年同口径配对后，显示值均未变；这只证明所选机构的两次公开预测，不代表全市场一致预期没有变化。

单票合并归母低于原估算与快递分部单票利润高于该数字可以同时出现；后者换了利润口径，不能冒充同口径超预期。当前仍未建立新的期限特定机会，原11月30日复核、前向冻结和Human条件不改。

## 3. 一次换口径会把“低于估算”变成“超过估算”

华创7月材料估算Q2单票合并归母0.216元；8月摘要给出Q2合并归母17.97亿元、快递分部归母19.13亿元、件量86.4亿。使用这组明确舍入值，前者除以件量约0.20799元，较原估算约低3.71%；若错误换成快递分部利润，得到约0.22141元，表面反而高2.51%。这两项比率是本件按摘要数字复算，不是额外披露的高精度单位利润。[HC1、HC2；本次计算]

正确用途是辨认利润归属与范围，而不是宣布业务失败：非核心业务对合并利润的拖累可与快递经营改善并存。原估算也含件量假设，差额不能全归因给成本或价格。8月摘要开头把17.2–20.2亿元区间接在H1标题后；7月正文明确该范围是Q2测算，不将它误作H1公司预告。原分部/总部/加盟末端不互相替代。[HC1、HC2]

本次H1扣非实绩不补成8月成本或Q3现金。下一分辨点仍是可比成本、季度单位利润、现金及网络代价；两季度0.18元的旧反证不由本次一个舍入比率触发。新信息足以改变相应经济桥时有界重开；同一材料重复传播则复用本件，不重跑Full。没有把原等待改成自动研究/交易唤醒。[COST]
