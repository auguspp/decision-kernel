## 4. 反推“涨10%”究竟靠什么

10%仅是本件的**毛价格涨幅演示点**，不是原三年10%年化要求、Human目标或推荐收益率。12.63元上涨10%对应13.893元。

在22x不变时，所需年度盈利能力约**11.2260亿元**，比旧正常化上沿10.6亿元高约**6,260.49万元**；在23x时仍约需**10.7376亿元**。若只维持10.6亿元上沿，倍数需约**23.2993x**，已经超过21–23x核心范围。24x行能够给出两位数标价变化，靠的是明确上沿市场表达，不能写成“稳定利润本身证明了两位数机会”。

这把研究问题收窄为：新材料究竟支持新增税后盈利能力，还是只要求市场提高倍数？如果只是上一期结算冲击不重复，不能自动填入上述新增持续盈利。反过来，可靠合同/税务信息减少不确定性也可能引发重新定价，而不要求当期利润先增长；这条正向路径保留，但时间与价格是否已反映仍需证据。

## 5. 两端盈亏平衡只检验论证，不估计真实胜率

暂时假定只有11.3406元和13.7145元两个穷尽的端点、没有其他结果及成本，盈亏平衡高端权重为：`(12.63−低端)/(高端−低端)`，约**54.32%**。若不利端换成原8.1004元压力标价，同一代数权重约升至**80.68%**。

**54.32%和80.68%都不是我们预测的上涨概率，不是历史胜率，也不是审批阈值。** 它们仅展示：选择温和下沿并忽略尾部，会显著美化所需条件。真实结果不是二点分布，窗口内不重定价也不是自动回到参考价；没有实证概率，不计算加权收益、不插入50/50，不让此表升级为“机会成立”。

## 6. 支持、失效和到期如何判

**支持/有界重开：** 新的可比土地收费、成本、经常税负或可分配利润资料，能改变持续盈利能力或不确定性；再核该信息的实际公开时钟、来源和市场表达。只重开受影响的桥，不因一条价格新闻重跑Full。

**反证/停止当前论证：** 资料显示经常税负或成本吞掉正常化盈利，分红/母公司利润约束加重，或所谓新催化仅为旧一次性基数重述，则撤回相应“盈利修复/不确定性下降”的推断。价格下跌本身不证明其中任何经济原因，也不自动触发买卖。

**到期或资料不足：** 11月30日是原分析者有限裁定日，不是自动验收。当时应分别记录实际信息、是否观察到相应重新定价及仍未解释部分；没有材料则记未建立，不回填概率、不顺延冻结、不把没有仓位记录当成今天没有持仓。原Human价格卡与是否执行必须沿自己的记录处理。本件没有自动写入horizon/Watch、任务或提醒。
