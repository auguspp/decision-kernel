2026-10-01。原 C1 的有界研究接续；[本批范围](https://github.com/auguspp/decision-kernel/issues/297#issuecomment-5931030684)。复用兴森 R2 与 #680，不重做 Full，不改研究方法、生产模型或 Watch。资料、条件算术、实际财务结果与 Human 接受分别成立。

## 本次实际改变了什么

**不能把员工持股计划写成公司已经承诺的三年盈利路径。** 公司草案和管理办法的所获正文明确区分激励条件与预测；2027、2028年还允许累计收入达标。把摘要里的80/100/120亿元直接连成唯一经营路径，会漏掉真实替代条件，也无法证明利润、回款或新项目资本回报。

本次取得的9月28日律师见证文本报告相关议案获股东会通过，属于9月24日 R2 之后的治理事项；9月12日计划条款本身则是本轮补读，不是10月新事件。批准不等于员工已缴款、股票已过户、预留份额已授予或成本已确认。未改写 R2 的当时知识、接受边界和已有现金/资本结论。

## 1. 公司收入条件不是三个独立年度预测

按首次份额的公司层面收入条件，令26/27/28分别表示相应年度合并收入，金额为人民币亿元：

| 考核年 | 所获原文支持的公司收入条件 | 解释边界 |
|---|---|---|
| 2026 | 26 ≥ 80 | 是收入条件，不是净利润、现金或资本回报条件 |
| 2027 | 27 ≥ 100，**或** 26 + 27 ≥ 180 | 较早年份的收入可影响本期累计路径 |
| 2028 | 28 ≥ 120，**或** 26 + 27 + 28 ≥ 300 | 本年低于120也不必然失败 |

例如，**90/90/120**与**90/100/110**两组完全虚构的收入路径都满足上述三个公司收入条件。它们不是公司预测、承诺或实际成果。相反，79/101/120中首期条件仍失败；后面的累计达标不自动恢复已取消的首期份额。个人条件、锁定与处置规则还须分别成立，程序不裁定任何员工的实际权益。

管理办法对预留份额在9月30日前、后授予作不同安排。本次未取得实际授予日期，也未解释原文字面在9月30日当天的完整边界，所以不擅自套用首次三期时间表。

## 2. 用原R2实际收入核对今年目标的经营尺度

继承原 R2 计算文件的精确数字，不重新认证发行人财务原件：2025年收入71.9462480467亿元、2025H1收入34.2586343595亿元、2026H1收入40.3783229413亿元。明确分开已发生收入与尚未兑现的条件：

- 2025H2 = 年度 − H1 = **37.6876136872亿元**。
- 为使2026全年收入达到80亿元，H2需 **39.6216770587亿元**；相对上年H2约 **+5.1318%**，相对本年H1约 **−1.8739%**。
- 80亿元相对2025全年约 **+11.1941%**。不能仅凭这个激励目标声称必须出现异常高的H2收入增长，更不能由收入目标推定BGA盈亏平衡。

这些是条件反推，不预测下半年，也不推断目标难易、订单、毛利率、现金兑现或通过概率。原 R2 已表明合并/归母利润、退税与经营现金、投入资本和有效股东归属需要分别解释；本次没有用激励条款填平那些未知。

## 3. 回购、员工受让与股份支付是三笔不同的账

所获草案所列两批原回购股数合计 **5,694,900股**；计划拟从库存股取得全部或部分股票，受让价19.40元/股，对应上限对价 **110,481,060元**。这是拟议规模，不是本次确认的公司现金流入；库存股转让也不是新发股或注销。R2已经知道的9月14日后继回购不自动扩大这份草案的受让数量。

草案以**假设2026年10月过户**、9月11日39.33元/股为基准测算费用。按同一假设，5,694,900 × (39.33 − 19.40) = **113,499,357元**，与披露合计11,349.94万元的舍入尺度吻合。该价格仅是草案自己的历史测算参数，不是本次新行情或公允价值评估。

原表2026—2029年费用分别为1,483.19、5,464.86、3,188.26、1,213.62万元，逐年相加11,349.93万元，比展示合计少0.01万元（100元）。工作底稿保留两个数及差额，不改原表凑平；该残差与分项舍入相容，不据此宣布公司会计差错。真实授予/过户、公允价值、最终可归属数量和实际确认费用仍未知。

**研究采用：**股份支付估算不是同额当期现金流出，但不能据“没有当期付款”认定员工服务或股东经济承担没有成本；也不能把计划全部费用从2026H1已发生利润再扣一次。是否改善长期价值仍取决于经营、再投资及股权权利，不能只用名义股比很小或收入达标代替判断。这里不裁定最终会计处理、税盾、每股收益或估值。
