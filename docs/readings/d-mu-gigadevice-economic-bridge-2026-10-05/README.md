## 可复算的抵消量

基数为旧档案保存的2026H1：存储收入**98.27亿元、毛利率67.57%**；MCU收入**14.30亿元、毛利率38.49%**。来源为历史结构化抽取，分部收入已取整；下表展示到两位小数，计算保留小数不是资料精度升级。不是本轮重获并重审原半年报。[S1]

由此推算存储毛利约66.40亿元，MCU毛利约5.50亿元。在存储收入固定时，每下降1个百分点毛利率，毛利少约0.98亿元。下降10个百分点少**9.83亿元**，相当于原MCU毛利的**1.79倍**。仅按原MCU毛利率补足这部分，需额外约**25.53亿元MCU收入**，为原半年MCU收入的**178.54%增量**；不是将总收入误写成178.54%，也未计费用、税、扩产和现金占用。

| 条件存储毛利率 | 固定旧收入时毛利额（亿元） | 为保持旧毛利额所需收入增长 |
|---:|---:|---:|
| 67.57% | 66.40 | 0.00% |
| 62.57% | 61.49 | 7.99% |
| 57.57% | 56.57 | 17.37% |
| 52.57% | 51.66 | 28.53% |
| 47.57% | 46.75 | 42.04% |
| 42.84% | 42.10 | 57.73% |

42.84%仅是旧档案中的FY2025存储毛利率参考，并非未来必回归水平。其余梯度是显式压力假设，不带概率。保持毛利额所需的是**收入增长**，不能在价格与组合变化时称为所需销量增长。表内也不是整家公司净利润或每股价值。

**最强反例不能省掉：毛利率下滑不一定是经营假设失败。** 以原67.57%毛利率构造同销量、单一抽象产品的基准：售价提高10%、单位成本提高20%，毛利率会降到64.62%，但毛利额仍增长5.20%；售价只提高5%、成本仍提高20%，毛利额则减少2.20%。因此要判断的是成本后毛利额及现金，而不是机械要求毛利率保持峰值。这里的抽象单位不是兆易真实SKU、披露售价或综合单位成本。[本次计算]

## 后继怎样裁定，不另加硬门槛

**支持路径：** 相关产品兑现、可交付供给或售价改善后，实际毛利额增长，且库存、应收、预付等未令现金转换恶化。可以增强经营链，但仍不能单独证明买入机会。

**反证路径：** 相关容量价格/订单走弱，或成本、良率及产品组合吃掉收入增长，导致毛利额与现金共同恶化。即使总存储标题仍强，也应削弱原传导假设。

**资料不够的路径：** 公司不披露容量级收入时，仍先利用已公开分部收入、毛利额和现金/营运资本做有界检查；保留无法归因的部分，不要求全部SKU资料才开工，也不把UNKNOWN写成失败或成功。MCU新材料应落到当期收入与利润贡献，不能拿应用名单替代抵消量。
