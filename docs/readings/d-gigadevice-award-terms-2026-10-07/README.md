## 2. 三个分母，三个不同的问题

采用授奖公告列明的计划采纳日总股数703,971,427股，不声称这是今天最新稀释股数。资本变更公告列示A股670,718,327和H股33,253,100，其和一致；其章程/工商程序状态与股份变动事实分开，不将尚需表决的章程版本说成已经生效。[G、CAP]

|---|---:|---|
| 授予份数 / 原总股数 | 0.211358010131% | 全公司原股本规模比较，不是已实现EPS摊薄 |
| 授予份数 / 原H股类别股数 | 4.474470049409% | H股类别规模比较，不是全公司经济权益被稀释4.47%，也不是自由流通盘占比 |
| 授予份数 / 70,397,142计划限额 | 2.113580122329% | 本批使用计划容量的比例，不是公司股本比例 |
| 假定全由新股履行且无其他股数变化：g/(S+g) | 0.210912230238% | 固定总利润、不计奖励经济成本时，旧持有人单位权益的机械减少；不是实际或加权摊薄EPS |

计划限额减本批为68,909,242股，与所读公告余额吻合。每批25%为371,975份。不能把未使用计划限额当已授予或已发行；也不能把约0.21%的数量尺度当作总经济成本“不重大”的结论。

**“全新发行”只是明示条件，不是本件确认的股份来源。** 新增发行、存量股转让/购买等路径对股数和现金的影响不同；本次没有实际选用路径、受托人持股及资金明细，不能替公司选择有利分支。即便总股数不增加，也不能由此将激励成本置零。

## 3. 股价、购买价和费用不能混算

公告披露的授予日H股收盘为HKD448.20，仅用于口径反例：份数乘该价为HKD666,876,780，不是公司确认的股份支付费用。RMB1购买价对应假定全部接纳/支付的RMB1,487,900，也不是该费用、已到账金额或收入。不同币种不能直接相减；不补汇率、失效率、绩效达成率或估值模型。

[IFRS Foundation对IFRS 2的官方说明][IFRS]明确股份支付需要反映在财务报表和相关损益/财务状况中，涉及权益或现金结算等形式。本件只用它否定“非现金或低购买价必然没有成本”的推断，不据此决定该公司本次的会计分类、计量金额、费用期次、税务或EPS分母。具体成本仍需公司财报附注或有来源的费用测算。

最早一批的声明周年为2027-09-28，晚于原D分析者2026-11-30复核日。**这只否定“这些份额按所列常规时间表在11月前全部归属”的说法，不证明复核窗口内费用为零。** 服务与费用的实际确认期次在本件未知；归属期限不是费用豁免，也不是应自动延长原研究窗口的理由。
