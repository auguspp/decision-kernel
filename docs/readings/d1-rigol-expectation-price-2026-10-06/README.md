## 本次判断改变了什么

**不能再单凭中报净利润同比增长129.08%，把普源列为“新出现的盈利超预期”机会。** 本次取得此前未用于该案例的公司预告解析文本：对应同一2026H1期间，实际总营业收入、归母净利润、扣非归母净利润均落在该预告区间内。它补上一个真实比较基准，不否认原研究已经识别的经营改善，也不宣称已经恢复市场一致预期。[S1、S2]

与此同时，原保存价格包显示9月30日收盘47.80元，9月1日至9月30日的20交易日调整后端点变化约+13.86%，最近5交易日仅约+0.31%。因此既不能从中报同比增幅直接推导尚未定价的上涨空间，也不能用这段已发生的涨幅证明公司现金已经兑现。价格变化的原因、路径与事件效应，本件没有识别。[S3；本次复算]

**长期：** 无新的正常化盈利、资本回报或股东现金证据，不因20交易日涨幅修改长期Belief，也不把H1利润简单乘2后配一个任意PE，制造11月30日目标价。没有可由本件继承的已接受普源长期Full或数值概率。[PRE、S5]

**最强反例：** 公司实绩处在旧预告内，仍可能高于后来下调的市场预期；中报的订单、产品结构或资本使用信息也可能比三项总量更重要。反过来，价格上涨也可能来自估值、资金或其他消息。由于这些预期和归因材料未恢复，本件只否定“三项同比高增长足以证明新增正向意外”的论证，不能宣判所有短中期机会不存在。
