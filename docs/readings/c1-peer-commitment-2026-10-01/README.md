## 3. 把竞争问题接到原经营桥，而不是多写一个风险段落

从原计算底稿只读抽取 `H['gz_op']=-281436038.67` CNY。它是广州兴森法律主体2026H1营业结果，不是纯产品的正常化工厂成本。设需要覆盖的损失为 L=281,436,038.67 元；c 沿用 R2 的新增收入贡献率压力参数；d 是本次新增的0%/5%/10%让价假设，**不来自 AT&S 或兴森实际报价**。

只对追加订单让价，原有业务损失、单位新增经营成本、产品组合及期间固定成本不变。若参考价格为P0，单位新增经营成本为P0×(1−c)，则降价后单位贡献为P0×(c−d)。因此：

- 所需追加销量对应的参考价收入：`L/(c-d)`；
- 按降价后的价格确认的追加收入：`L*(1-d)/(c-d)`；
- 相对不降价情况的所需可售数量倍数：`c/(c-d)`。

只在 `c>d` 时有有限正解；`c<=d` 不得用负收入或0冒充扩量可以弥补。没有识别P0，所以只给相对数量，不给平方米、客户订单数或投产时间。

|---|---:|---:|---:|
| 25% | 0% | 11.2574 | 1.0000 |
| 25% | 5% | 13.3682 | 1.2500 |
| 25% | 10% | 16.8862 | 1.6667 |
| 35% | 0% | 8.0410 | 1.0000 |
| 35% | 5% | 8.9121 | 1.1667 |
| 35% | 10% | 10.1317 | 1.4000 |
| 45% | 0% | 6.2541 | 1.0000 |
| 45% | 5% | 6.6841 | 1.1250 |
| 45% | 10% | 7.2369 | 1.2857 |

例如35%参数下，追加订单价格低10%而单位经营成本不降，所需追加数量比原试算多40%，所需按新价收入从约8.0410亿增至10.1317亿，约多26%。**不是简单“收入多10%就能补回降价”。** 这是条件恒等式，不表示兴森会降价、能取得这些订单或将于某期盈利。

原R2的无让价三格原公式均保留。新增固定投入、折旧、人工、爬坡损耗、原订单重新定价、税费、利息、少数股东及营运资金不在本条件内；不能把结果叫全厂盈亏平衡、归母预测、FCFE或可自筹扩产。融资/客户付款只能影响资金条件，不能自动消灭经营成本或无条件叠加项目价值。
