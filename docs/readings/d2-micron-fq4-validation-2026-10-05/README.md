## 同期间兑现：有正向结果，也有费用抵消

下表金额为**百万美元**，EPS 为美元／稀释股；除收入外采用公司 non-GAAP 口径。毛利率、费用指引本来就是近似值。[S1–S2；本次计算]

| 指标 | 6月24日 FQ4 指引 | FQ4 实绩 | 可复算差异 |
|---|---:|---:|---:|
| 收入 | 50,000 ±1,000 | 54,229 | 高于中点8.458%；高于上沿3,229 |
| 毛利率 | 约86% | 87.0% | 报告取整口径约+1个百分点 |
| 经营费用 | 约1,650 | 2,568 | 多918，约+55.64% |
| 稀释EPS | 31.00 ±1.00 | 33.42 | 高于中点7.806%；高于上沿1.42 |

为解释抵消关系，按指引中点推算营业利润代理值：`50,000×0.86−1,650=41,350`。这不是公司直接给出的营业利润指引。实际调整后营业利润44,636比代理值多3,286，可写成：

`收入变化按原毛利率计3,636.94 + 毛利残差567.06 − 额外费用918 = 3,286`。

残差只作算术分解，不能从中识别价格、销量、HBM组合或SCA贡献各占多少。正向收入兑现与费用压力可以并存；不能只用EPS超指引判为全链条优于预期，也不能因费用上升就忽略实际盈利增量。
