## 两种基线，及不能相互替代的结果

**原条件基线。** 在9/16、23、30这三个实际保存截点，五股均没有触发各自原记录的价格条件；不是逐日或盘中穷尽检查，也不是证明期间没有任何Human成交。该基线回答“原条件是否触及”，不回答“所有期限机会是否存在”。前三例只有研究/赔率接受，两例有附条件资本决定，也不能合为五个统一买卖策略。

**单纯涨价基线。** 前驱完整五名16→23收盘均上升；如果在23日仅用这段上涨把它们全部列成短期机会，后继23→30的四个交易日出现四跌一涨，其中兆易未复权收盘约−11.24%、恒瑞约+3.55%。它构成“上涨本身足以证明后继机会”的不利对照，不是经验证的动量策略回测：规则在今天写出，没有全样本、基准、公司行动、可执行入场或交易成本，不能据此算胜率、alpha或否定所有动量方法。[CUSTODY]

**经济区分的判断。** 用五例各自的关键经济问题代替共同的上涨标签，能够防止将涨跌、融资、税基、可选业务或跨市场联想直接升格为证据；但这次没有自然前向结果证明这种处理已经降低遗漏/误报或提高收益。适当结果是保留原决定，同时指出哪个具体资料可能改变较短期限判断，而不是为了产出候选擅自改变长期模型。
