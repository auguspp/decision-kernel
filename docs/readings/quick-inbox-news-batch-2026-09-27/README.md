## 1. 我国启动研制商业航天育种专用卫星

### 原观察与已确认事实

固定 R 中该条为财联社窗口观察，`qualification=CONTEXT_ONLY`、`business_linkage=NOT_ESTABLISHED`，抓取时间 2026-09-27T04:45:36Z；上游 `pubDate` 仅是“未向发布者核验的时间声明”。

公开一手材料显示：2026-09-23，陕西省航天育种工程技术研究中心与中科卫星科技集团有限公司在西安文理学院签约，共建太空生物空间诱变联合实验室，并宣布研制首个商业航天育种专用卫星。计划覆盖空间诱变机理、动植物/微生物种质搭载、在轨载荷、地面筛选和新品种选育，实验室计划向科研院所和育种单位开放。[S1]

中科卫星自身公开业务包括整星设计、SAR载荷、测控运控、数据接收处理和卫星运营，说明它具备承担卫星工程/运营的实际能力，而不是只有概念合作。[S2]

## 2. 浙江全链条打造海洋清洁能源产业集群

### 原观察与政策事实

固定 R 中该条同样只是 `CONTEXT_ONLY` 新闻观察，没有自动经济联系。

浙江省海洋经济发展厅在9月23日活动上发布《浙江省海洋清洁能源产业发展指引》。公开报道给出的2030目标包括：海洋清洁能源及装备产业规模突破3000亿元、海上风电装机超过1000万千瓦、形成千万千瓦级基地、潮流能百兆瓦级商业化、海上光伏“风光同场”、绿色氢氨醇初具规模，并培育50家以上领军/专精特新企业；产业链覆盖海上风电、海上光伏、海洋能、沿海核电。[S4]

这不是完全从零开始。浙江公开材料称苍南现有海上风电装机约130万千瓦、约占全省四分之一；温州海风规划容量超过2000万千瓦。省内还在建设深远海风电母港。[S5]

### 可验证的上市公司暴露

**运达股份（300772.SZ）**：
- 2026年获浙江深远海26MW级超大型海上风电整机研制项目立项；公司已有15–18MW海上平台并继续研发26MW级。[S6]
- 2026-08公司披露苍南6号海上风电项目核准容量从210MW增至300MW，总投资调整为30.7408亿元，由控股子公司投资建设。[S7]
- 公司2026年1月投资者交流还称，2025年已中标浙江部分深远海项目订单。[S8]

**东方电缆（603606.SH）**：
- 浙江产业活动公开材料直接把其海洋脐带缆/海缆能力作为本地制造基础案例。[S4]
- 公司2026年半年报披露，截至8月3日在手订单约179.34亿元，其中海底电缆与高压电缆91.28亿元、海洋装备与工程运维39.56亿元；但这些订单并不等于全部来自浙江，也不能用政策目标倒算公司份额。[S9]

因此，这条新闻比一般“产业规划”更值得继续：**政策目标、资源禀赋、母港、核准项目、上市公司已有业务能力和已披露项目之间已经存在可验证连接。**

### 仍不能跳过的反证与未知

- “3000亿元产业规模”是产业目标，不是政府已批资本开支，也不是上市公司可分配收入。
- 海风>1000万千瓦需要逐项目核准、海域/并网、资本金、招标与施工兑现；时间节奏可能明显后移。
- 运达既是整机商，也通过子公司直接投资项目，新增规模可能增加订单，也可能增加资本占用与项目回报风险；不能只看装机。
- 东方电缆的订单池很大，但必须区分浙江新增项目带来的**增量**订单与现有已在手订单。
- 金风、远景、正泰等也在浙江布局；地方产业政策并不保证单一供应商份额。

### 处置

**建议形成一个有界 Full 候选，但不在本次自动执行。**

具体问题不是“浙江海风好不好”，而是：

> 到2030政策目标中，未来2–3年已经进入核准/建设/招标阶段的浙江深远海项目有多少？运达股份和东方电缆分别在哪些项目上有已披露的开发权、设备订单或高概率投标资格？这些增量相对现有订单、资本开支和利润基数是否足够重要？

建议 Full 的最小范围：
1. 建浙江已核准/在建/待招标项目表，不把远期规划算订单；
2. 运达拆开“开发商资本回报”与“整机销售利润”；
3. 东方电缆拆开海缆/工程运维的已在手订单与新浙江增量；
4. 核对招标主体、交付年份、竞争格局和产能约束；
5. 最后才比较市场预期；本 Quick 不重算 Odds。

## 3. 滹沱河供水工程正式向太原市供水

### 这条新闻真正新增了什么

2026-09-27报道确认，滹沱河供水工程已向太原上原地表水厂供水，线路约82公里，三级加压，近期年引水能力3000万立方米。[S10]

但这并不是新工程。中国水利系统2022年开工资料已经给出：项目总投资12.8亿元、建设期2年，近期/远期年引水能力分别为3000万/5000万立方米，目标是太原第二水源和太忻一体化区域供水。[S11]

### 已有上市公司映射其实是历史订单

青龙管业（002457.SZ）2022年公告：与山西水务集团建设投资组成联合体，中标滹沱河供水工程建安02标；青龙负责PCCP制作，中标金额4619.0078万元，占其2021年营业收入1.90%，公司当时明确预计主要影响2022–2023年业绩。[S12]

因此，2026“正式供水”对这笔上市公司订单更像**项目已进入运行阶段的后验确认**，不是新的订单或新利润来源。项目建设主体万家寨水务控股集团为省属水务集团；本次公开报道未给出新的上市公司运营合同、扩建订单或设备增量。

### 处置

**STOP。** 本次新闻本身不足以继续投入公司 Full。

可重开条件：
1. 远期5000万立方米能力扩建进入新招标/核准；
2. 上原调蓄、泵站、管线等出现新的上市公司重大中标；
3. 山西现代水网后续项目形成可重复、对某上市公司显著的订单序列；
4. 运营/水价/长期供水合同转化为上市公司可识别利润来源。

不把“山西继续建水网”自动推成青龙管业或其他公司的新增订单。
