## PIT与期限：有比较依据，不回填历史能力

公告覆盖1月1日至6月30日，文档日期7月10日；这是期末之后的预告，而非6月末以前冻结的预测。较早文档相对正式中报的比较用途，与本次10月7日读到它、原系统当时是否已采集，是不同事实。原Full保存者声明的8月时钟本轮不改写；最早交易所公开分钟、历次更正与期间市场共识未穷尽。[G、A1]

本次有用的区分是将“同比增长”“对既有公司近似预告的差额”“对市场预期的变化”分开：第一项可以很大，第二项可以很小且两口径异号，第三项仍需独立证据。不能把第三项未知写成市场没有变化，也不能为了留候选把第一项升级为未定价信息。

对日到数周的机会，本件不确认正向意外或排除所有机会；缺适用事件价／公司行动／可执行时点，不给回报归因或买卖结论。对中期，真正仍有区分力的是原产品供给和成本后毛利、现金转换，以及同机构同年度预测的可比修订；本件不重算已完成的价格／倍数、库存和采购额度敏感性。[PRE]
