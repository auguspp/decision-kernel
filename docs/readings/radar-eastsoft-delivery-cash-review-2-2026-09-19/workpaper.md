## 本轮结论

东软载波仍是有真实电力通信业务暴露、值得跟踪验证的候选；但现有材料不足以认定经营复苏已经发生。本轮把原来笼统的“等待交付”拆成三项可核验条件：收入确认、毛利覆盖费用、实际回款及减值。新增的是同一原件上的分析与反证，不是新公告、股价变化或新的自动 Pre/Quick。

## C1. 新增分析二：先算一个可解释的费用覆盖门槛

原报告第47页，单位元：

| 项目 | 2026H1 |
|---|---:|
| 营业收入 | 414,836,129.08 |
| 营业成本 | 302,021,581.15 |
| 毛利，收入减成本 | 112,814,547.93 |
| 销售费用 | 28,705,547.47 |
| 管理费用 | 52,574,989.84 |
| 研发费用 | 73,670,051.96 |
| 上述三项费用合计 | 154,950,589.27 |
| 毛利减上述三项费用 | -42,136,041.34 |

这一小计不是报告营业利润、扣非净利润或自由现金流。报告营业利润为-27,108,923.06元；税金及附加、财务费用、其他收益、投资/公允价值、信用/资产减值和处置收益等仍须独立勾稽。calculate.py 已逐项核对两者之间的桥，没有把两种口径混为一谈。

以下只是一项明确条件的敏感性：假定未来一个相同长度期间维持2026H1的合并产品结构及毛利率27.1949669%，且三项费用金额维持154,950,589.27元，则：

`仅覆盖三项费用所需收入 = 154,950,589.27 / (112,814,547.93 / 414,836,129.08) = 569,776,716.13元`

比半年报收入高154,940,587.05元，约37.35%。这不是预测下半年收入，也不是认定增长37.35%就能实现净利润盈亏平衡；产品组合、售价/成本、费用、税息、补助和减值都会改变结果。

另一个单轴敏感性：若其他业务毛利及集团三项费用不变，通信维持原实际毛利率约34.7116%，则通信收入要从258,967,979.04元增至约380,356,795.10元，才能填平同一个小计缺口，约增长46.87%。这也不是份额或订单预测。

意义：小幅收入回升不足以自动证明利润桥已修复。需要同时看交付量、毛利率和费用，而不是只有“订单仍在”。但不能反向断言半年报未履约收入小于费用覆盖所需收入，就证明下半年必亏；6月末余额不包含之后可能形成并交付的订单，且本表缺少可比和产品拆分。

## C2. 新增分析三：合同资产下降里，存在明确的减值因素

原报告第90至92页，单位元：

| 项目 | 期初 | 期末 | 变化 |
|---|---:|---:|---:|
| 合同资产账面余额 | 43,540,230.62 | 33,326,456.11 | -10,213,774.51 |
| 减值准备 | 5,518,684.03 | 9,034,627.09 | +3,515,943.06 |
| 账面净额 | 38,021,546.59 | 24,291,829.02 | -13,729,717.57 |

`净额减少13,729,717.57 = 余额减少10,213,774.51 + 准备增加3,515,943.06`。

准备增加解释净额下降的25.61%。因此净额下降不能整体当作现金收回；其余余额变化也可能含转应收、核销及新履约等，不凭这一张表反推现金流。准备占余额的比例由约12.67%升至27.11%，发行人单项计提类的计提比例由30%升至50%，计提理由为信用风险变化。

进一步核对准备滚动：

`5,518,684.03 + 本期净计提5,607,053.07 - 核销2,091,110.01 = 9,034,627.09`。

核销不能再与净计提机械相加，作为本期额外损失重复扣减。相关计提已进入报表，也不能再从报告净利润中扣一次。

第92页还说明两笔子公司智能化项目债权和解及核销。这是可见的合同执行/回款反证，但不能未经客户映射就泛化为电网客户普遍信用恶化，更不能说通信订单必然坏账。合同资产不是未履约收入，两项金额也不可相减求“净订单”。
