## 1. 经营侧：已有敏感性继续用，但先看净作用

沿前驱保存的67.57%存储毛利率构造单一等价产品，销量增加20%、售价下降10%，若单位成本不变，毛利额增加2.24%；若单位成本增加10%，毛利额反而下降3.52%。保持旧毛利额分别需要约17.37%和24.38%的销量增长。它说明供给恢复同时影响可交付量、实现价与成本，不能单列为支持或反证；这些不是实际SKU、预测或概率。[S1、S3；本次复算]

旧H1经营现金流与扣非归母利润的差额约11.6531亿元。假设以后额外现金融资的库存占用等于旧期末库存30%、且无应付抵消，会增加12.5527亿元占用；按旧现金流尺度的条件结果为47.9307亿元，约旧扣非利润0.9816倍。**没有从历史经营现金流再次扣除历史期末库存**，30%也不是公司预测。另需强调：集团经营现金流与扣非归母利润并非同一归属口径，这个比值只是尺度对照，不是净利润到现金的完整勾稽，更不是股东自由现金流。[S1、S3；本次复算]

## 3. 现在怎么继续判断，不等待价格窗口才研究

本件优先级判断：先在现有公开分部收入／成本／毛利、库存／应收／预付／应付与回款资料里核产品传导，缺容量级拆分只限制归因精度，不阻塞整个研究；找到有明确机构、币种、归属口径、预测年度和报告日期的可比修订，再判断兑现是否超出原预期。无法确定修订时保留UNKNOWN，不能用重复转载数量替代证据。

原长期Research和Human决定继续独立适用。中期需要自己的催化、失效和剩余问题；短期价格观察只能陈述真实合格窗口。公司供给恢复、原料／代工成本与行业报价都是机制输入，并不能直接移植美光的产品组合、客户合同或现金保护。

| 毛利额／现金改善，价格下跌 | 经营与价格表达有分歧；进一步检验估值压缩、预期和其他风险 | 单凭跌价否定已核经营事实 |
