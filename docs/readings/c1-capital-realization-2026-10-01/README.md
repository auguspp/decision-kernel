## 1. 本次改变的研究判断

原R2/#700选择AT&S与深南作为有限类比，已明确不能移植毛利率或成功概率。本次补上目标公司自身一份完整历史资金用途表：**同一次募资的原三项承诺，经过调整形成七项最终去向；两项有数值化项目效益，五项不适用。** 既保留载板项目2025年达到所列效益的正面记录，也保留宜兴项目连续年度亏损、缩减计划及终止剩余募投的反例。不再只以成功同行回答新资本是否能兑现。

这不是行业成功率样本。一个项目的资金流向另一个用途，不能当成两个独立试验；收购同一家公司的25%和24%权益也不是两个独立新产能。`是/否/不适用`不是两胜负加五个零，不能算成50%或1/7成功率。资金账户结清、项目进度、年度税前效益与全寿命股东回报分别成立。

近三年合计分别为-10,209.70、5,025.69万元，与报告“截至日累计”不同。报告没有在这里给出完整累计起始区间，本例不强行勾平、不反推某个未提供年份。比较器将年度与累计、原达产基准与实际期间明确列为不可直接同口径比较，尤其不把宜兴变更前基准当固定经营条件下的预测误差。

宜兴注释披露扩产计划由8万平方米/月降到2万平方米/月。这是规模降到原计划25%，**不是25%的实际产能利用率**；表中累计利用率本来就是“不适用”。原利润基准也不能乘25%后自动变成新基准。公司解释涉及价格竞争、产品/客户组合、产能释放以及2025年数字系统适配对质量和交付的影响，并称年底改善、第四季度接近盈亏平衡。这些是管理层的历史解释，不是本次独立因果识别或2026年盈利保证。

2025年董事会/股东会批准终止剩余宜兴募投计划，正文还记录了永久补流的实际金额和完成时点；这比单纯批准更具体，但不证明整个工厂停业。附表某些“预定可使用状态日期”早于募集资金上市时间，同一文件又说明置换先期投入。因此日期列不能不加辨别地用于统计募资后的建设周期、满产或全部原计划落地。

## 4. 实际应用到当前资本问题

**对兴森当前新mSAP/CSP计划：**原R2的投资、设备、面积及静态单位贡献要求继续保留。新证据增加的是“实际投放是否继续沿原设计、资金有无改作收购或补流、缩减后单位经济是否仍成立”的检查，不另造悲观概率，也不把历史用途变更当成新项目必然变更。停止继续投入可能减少进一步损失，但没有增量现金流反事实，不能把停止本身认证成创造价值。

**对#700同业承诺：**客户、产能和资金支持仍是有价值的类比；但目标公司历史显示资金到位并不锁定最终项目范围。成熟同行成功与本公司历史失败都不能被挑选成唯一结论，亦不能将广州项目标签自动等同于R2中的纯FC-BGA法律主体/产线。

**对#703/#706后继使用：**激励条件不等于业绩承诺、资金来源不等于经营造血的区分已被实际采用。本例进一步分开项目税前效益与股东回报。没有把项目利润除本次募集资金分配额当ROIC：分配额不等于全部投入资本，原项目还可能有自筹投入、存量资产、后续再投资、税费及权益变化。
