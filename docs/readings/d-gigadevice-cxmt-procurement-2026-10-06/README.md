## 判断推进在哪里

原经济桥已经知道采购不等于销货成本、行业涨价未必留给股东。本次新增的是公司自己的具体采购安排：**DRAM代工价格上涨已经被公司列为提高关联采购预计额度的主要原因；成本风险不再只是行业层面的泛泛假设。** 同时，2027年前四个月计划还关联利基型DRAM及定制化产品推出，支持继续查实际产品兑现。它既不是单向利空，也不足以证明利润增量。[S1、S2]

这些公告在9月已经发布，本次是较晚补读，不是10月6日新发生的催化，不回写原冻结时系统已经知道。NOR容量涨价、兆易DRAM采购、MU自身利润是不同对象；这份DRAM安排不能替NOR收入、MU合同或整家公司利润背书。

## 传导方向：同一涨价对上下游并非同一种收益

这条信息首先接到兆易的**投入成本和可采购产品**，不是直接接到其客户实现售价。销售数量、组合、良率、采购与销货的时间差、存货/预付及应付款共同决定成本后毛利和现金，公告未给出足以完成这些拆分的数字。本次没有为此填入概率或凭空生成公司DRAM毛利率。

不能用原H1全部存储业务67.57%的毛利率，将44.11亿元采购预计额除以`1−毛利率`再年化成DRAM收入。该变换同时假设额度全额执行、采购全在同一期间结转为成本、DRAM与整个存储组合利润率相同，且没有其他成本与期间变化；这些条件未取得。原毛利率属于前驱保存口径，这里只用于指出不适配，不复算旧毛利压力表。[PRE；本次分析]

**建设性路径仍成立：** 更充分的供应和新品覆盖可以促进交付；若公司实际售价/组合、可交付数量及效率改善超过新增成本，毛利额可能增长。**相反路径也成立：** 金额上涨主要由代工价格或现金占用驱动，而客户售价/销量未能补偿，股东经济会弱于“采购高增”的叙事。两条路径下一步都以公司实际经营与现金材料裁定，不按采购额越高越好或毛利率下降即失败机械分类。
