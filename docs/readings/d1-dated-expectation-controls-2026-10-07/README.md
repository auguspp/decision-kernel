## 1. 恒瑞：真正的中报后对照，与被再次转载的旧下修分开

本轮打开的同花顺F10正文，表内中邮证券/盛丽华条目标为5月7日，2026/27/28年净利润显示93.03/109.07/129.64亿元。[H0] 另一中邮《肿瘤创新药销售承压，研发保持高强度投入》索引标8月24日，摘要明确归母利润84.7/97.7/114.7亿元，并讨论中报及肿瘤创新药承压。[H1]

两端都已具名，不是拿两家机构冒充修订。但旧表的通用“净利润”标签没有独立闭合全部归属/调整口径，原报告与模型也未取回。因此下表仅为**额外假定同归母、同调整口径时的显示值差额**，不宣称正式forecast consumer通过或认证中邮完整模型修订：

| 目标年度 | 5月条目（亿元） | 8月摘要（亿元） | 后值减前值（亿元） | 条件显示值变化 |
|---|---:|---:|---:|---:|
| 2026 | 93.03 | 84.70 | -8.33 | -8.9541% |
| 2027 | 109.07 | 97.70 | -11.37 | -10.4245% |
| 2028 | 129.64 | 114.70 | -14.94 | -11.5242% |

不同显示精度保留，不将后值补出的尾零称为源精度。这个对照提示应检查产品净价/销售结构及费用，而不是只谈新药数量；但不能将全部差额归因于其中一个因素，更不能据此计算公司实际现金变化。

**时间反例：** 8月26日汇总文章还引用国金87/104/125亿元（前值99/118/142亿元）的下修。[H2] 实际打开的具名条目与另一个报告目录将该国金《蓝海市场开花，眼科领域步入收获期》标为7月16日；理由为BD首付款确认节奏。[H0、H3] 因此不能把8月26日文章日期当这次预测首次修订日，再把它全部解释为8月中报冲击。同样不能把87与表内86.66的显示精度差当另一轮修订。

**经济处置：** 产品销售持续性、许可收入确认、实际收款及后续履约支出是不同变量。一次会计确认推迟不必然改变全生命周期净现金；产品净价/销量或支出变化则可能改变它。所选摘要尚不能量化各自贡献。保留原恒瑞条件与长期研究，不把9月后来上涨当上述疑问已解决，也不把旧国金下修反复作为新事件交付。

## 2. 三花：一个盈利下修对照，一个倍数下修对照

国信条目提供明确的2026/27/28归母旧/新值48.34/56.81/64.04→44.94/54.25/63.96亿元，并将原因指向汇兑与原材料成本等因素。[S1] 旧值亦出现在本轮打开的4月8日国信行；新报告的目录标签有9月2日与9月7日差别，未认证统一原报告日期。[S0、S2] 两个标签都早于历史界线，但不能据此宣称具体哪一天发生全部市场重估。

| 目标年度 | 旧值（亿元） | 新值（亿元） | 差额（亿元） | 显示值变化 |
|---|---:|---:|---:|---:|
| 2026 | 48.34 | 44.94 | -3.40 | -7.0335% |
| 2027 | 56.81 | 54.25 | -2.56 | -4.5062% |
| 2028 | 64.04 | 63.96 | -0.08 | -0.1249% |

这组三年度差异并不等比例。它与“永久利润统一打七折”不是同一个判断；但摘要不足以证明汇率一定均值回归或远期模型更可靠，也不能把2028小差额说成风险已经消失。只作具名摘要中自带前值的名义算术，不改原source-binding资格。[S1]

华泰《关注液冷与机器人增长曲线》则明确维持26–28年收入及归母预测，归母摘要为48/58/63亿元；估值由26E 48倍改为41倍，目标价54.72改为46.74元。[S1、S3] 3月26日旧具名行也留有47.83/57.56/63.32亿元及54.72元目标记录；整数摘要不是新的精确利润表。[S0、S4]

`46.74 / 54.72 = 41 / 48`，目标名义降幅为14.5833%；两端目标价除对应PE均为1.14元。这只验证所选显示数的**倍数变化解释**，不是认证EPS分母或我们接受的公允倍数。不能把目标下调14.58%写成盈利下调14.58%。英文对应条目显示RMB4.8/5.8/6.3bn；与48/58/63亿元是同一金额尺度，不能再放大十倍。[S3]

华泰中文条目标9月6日，另有9月7日转载及9月14日英文条目；相同预测与目标并未证明三次独立修订、三个独立观点或一条完整翻译发布链。相关版本仍需分开保留，不能只按页面日期计“新增机构变化”。[S1、S3]

**经济处置：** 国信的经营/财务预测风险与华泰的竞争、成长持续期及相对估值表达分开。即使利润兑现，倍数仍可下降；同为新业务积极叙事也不保证价格上涨。反过来，下调目标不独立证明核心业务恶化。原30元附条件首笔、真实执行后3–6个月评价、长期研究日不改；不以外部目标价代替Human条件，也不重做已交付的分红端点比较。

## 3. 兆易：不能将61→140.69当同一机构盈利上修

本轮打开的中邮《全芯赋能，智创未来》条目标5月26日，26/27/28归母摘要为61/75/90亿元。[G0] 8月24日财信中报点评索引则列140.69/168.68/176.21亿元并称上修；另有9月4日文章重引财信这组数。[G1、G2]

这里同时改变了**机构与信息时点**。不能用61作财信旧模型前值，不能由两行之差声称“市场盈利预期上调某百分比”；财信自述上修的原前值本轮未找到。也不能把早期中邮年度值低于后来中报实绩，直接计为AI预测失误或今日仍有效的中邮观点。未作跨机构差额/增长率，不伪造一次同机构配对。

**经济处置：** 高增长已有较早材料和中报后具名预期，不能只凭同比数字证明9月尚未定价的意外。中邮旧样本不能代当前共识，财信高样本也不是我们认定的盈利底。实际产品组合、实现价、采购成本、非经常损益与库存现金仍按既有兆易研究桥分别解释；原MU→兆易冻结与Human约350复核/320–335条件带均不改变。

复用同M的[原预测比较合同][CONTRACT]与原生Git底稿/Book导航；本轮没有新增解析器、validator、依赖或常驻测试。以下为已实际执行的Decimal/Fraction四则复算，非生产forecast consumer测试、全量pytest或研究有效性认证：

```python
from decimal import Decimal as D, getcontext
from fractions import Fraction as F
getcontext().prec = 50
pairs = [
    (['93.03','109.07','129.64'], ['84.7','97.7','114.7'], ['-8.33','-11.37','-14.94']),
    (['48.34','56.81','64.04'], ['44.94','54.25','63.96'], ['-3.40','-2.56','-0.08']),
]
for old, new, differences in pairs:
    for a, b, delta in zip(old, new, differences):
        a, b, delta = D(a), D(b), D(delta)
        assert b - a == delta and F(b) - F(a) == F(delta)
        change = b/a - 1
        exact = F(b)/F(a) - 1
        assert abs(change - D(exact.numerator)/D(exact.denominator)) < D('1e-48')
assert F('46.74')/F('54.72') == F(41,48)
assert D('46.74')/D(41) == D('54.72')/D(48) == D('1.14')
assert D('4.8') * D(10) == D('48')  # RMB bn -> 亿元
assert '中邮证券' != '财信证券'  # no same-broker revision asserted
```
