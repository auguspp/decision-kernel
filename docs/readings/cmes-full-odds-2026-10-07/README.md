## 2. 经济结构与关键问题

招商是综合航运集团，VLCC/其他油运、干散货/VLOC、集装箱/滚装及LNG各有不同收入与资本结构。油轮主要看实际净TCE×归母有效船天；干散货看矿石等需求、长协和现货；班轮与滚装看网络/装载/租船和汽车贸易；LNG部分通过合营/长期运输协议体现。不能把各类船当同质VLCC，也不能将JV全部船舶或净利润视为100%归母可用现金。

四类引擎共享融资与资本配置：油轮高收益可以资助其他扩张；利润上升、可分配现金下降可以同时发生。行业高收益催生订单，新增自有船交付时同行供给也可能增加。先分经济轴，再构造共同可行的世界，不强迫所有业务一起好/一起坏。

H1正文披露50艘全资拥有经营管理VLCC、绝大部分现货；库存表51艘不能自动等于51艘净即期权益。逐船现货/期租、航区、成交/空驶及年度有效天数，本次没有获得完整合同矩阵。[S02][S03]

五项负载问题：实际赚到什么运价；高收益持续多久；资本投入后归股东多少现金；低谷时业务/资产值多少；当前股价已经要求什么。公司销量下降而利润上升，说明不能把量、价和现金合并成一个景气分数。油运H1货运3912万吨同比-8.9%，周转量2996.96亿吨海里同比-2.22%，不是所有业务运量均增长。[S02][S03]

## 8. 同研究者Challenger与结论修订

这是同一实施者审查，不冒充独立Human或独立模型复核。
- 否定极端航线报价×总船数×365的盈利捷径；改为归母有效船天和年度实现TCE。

- 否定订单免费成长与合同总额即价值；投资净额、供给时滞与融资分别计。
- 否定历史子公司警示即当前利润造假，保留具体年份/范围。
- 否定条件DCF输出即确定价值；净即期合同、成本、税与项目值尚有实质缺口。
