## 1. 不可破坏的项目规则

Decision Kernel 不是交易系统、自动选股器、通用 Agent Framework 或行情平台。

核心 epistemic rule：

- **Evidence changes Belief.**
- **Price changes Odds.**
- `Data != Evidence != Judgment != Decision`
- `Radar = attention allocation`，不是投资决定。
- Kernel 验证 identity / time / source / frozen state consistency，不认证 truth。
- `UNKNOWN` 合法；不要为了完整而发明 WHY。
- AI 无 Investment Authority；Human 拥有最终研究接受、判断与资本决定权。
- GitHub 是 canonical state / evidence / process backend；ChatGPT 是 research / decision interaction layer。

Authority 边界始终保留：

```text
Retained
!= Kernel Accepted / Committed
!= Human Accepted
!= Investment Decision
```

### Reuse First / 自建举证

自 2026-09-10 起长期生效：

1. 先复用仓库已有轮子；
2. 再找成熟外部 SDK / API / Action / CLI / 服务；
3. 局部缺口优先配置、组合或 thin adapter；
4. 只有具体 blocker evidence 才允许 `NEW_BUILD_JUSTIFIED`。

施工记录用：

`Reuse Decision: REUSE / THIN_ADAPTER / NEW_BUILD_JUSTIFIED`

不要为了 Reuse First 新造 Gate / provider framework / DAG / scheduler framework。
