## Purpose

This is the third zero-schema Decision Hygiene dogfood after YTO and GigaDevice.

The experiment deliberately selects a different economic species:

> a long-established qualified industrial component supplier with relatively stable core margins, plus liquid-cooling and humanoid-robot adjacencies whose economics are not yet separately disclosed.

The question is:

> Does a more stable core business make probability genuinely easier to establish, and if so, can that probability knowledge be separated from unqualified optionality rather than forcing both into one total-company terminal-world distribution?

It does **not**:

- change Kernel Constitution;
- add schema, enums, state machines, probability-readiness fields, or optionality objects;
- change `ResearchSnapshot`, Kernel `Scenario`, live Odds, or production policy;
- rewrite or delete Sanhua Full Research v1;
- change Sanhua's production Inbox state;
- treat A-share or H-share price as a Fundamental Belief input;
- issue a Recommendation, Human investment decision, or investment action.

The existing Sanhua v1 remains a frozen counterfactual baseline. This dogfood tests whether its exact total-company `15/25/35/20/5` probability measure was epistemically qualified, not whether its deterministic arithmetic was correct.

## 4. Reference Frame battle

### Frame A — Qualified thermal-management industrial franchise / compounder

Mechanism:

```text
high qualification / reliability requirements
+ broad valve / pump / heat-exchanger product families
+ deep global OEM relationships
+ global manufacturing / localization
+ engineering iteration and process efficiency
→ durable share / content gains
→ relatively stable segment gross margins
→ recurring cash generation
→ adjacent applications can be entered using the same thermal-control capabilities
→ long-duration owner earnings
```

Evidence supporting this frame:

- multi-year refrigeration and automotive revenue growth;
- segment gross margins remained around 27–29% across 2023–H1 2026;
- 2025 profit grew faster than revenue while core segment economics remained healthy;
- H1 2026 deducted profit and OCF remained resilient despite FX drag;
- customer qualification and global manufacturing are economically relevant barriers in automotive / HVAC components.

### Frame B — Mature component supplier with optionality premium

Mechanism:

```text
core HVAC is mature
+ automotive content growth moderates
+ core margins are good but not infinitely expandable
→ core earnings grow at a moderate industrial rate
while
robot / liquid-cooling narratives receive premium capitalization before economics are visible
→ valuation becomes increasingly dependent on optionality duration / TAM assumptions
```

Evidence supporting this frame:

- H1 refrigeration revenue grew only ~0.5%;
- automotive grew ~9.9%, healthy but not hypergrowth;
- post-H1 CICC reduced 2026/27 forecasts because automotive growth slowed;
- robot and liquid-cooling standalone economics remain unquantified;
- future capex explicitly supports both global core expansion and emerging businesses, so optionality must eventually prove cash returns rather than only commercialization milestones.

### Current frame disposition

Retain:

> **Qualified thermal-management industrial franchise with a relatively stable, auditable core earnings engine and genuine but economically unproven adjacent call options.**

This is different from treating the entire company as one blended high-growth optionality story.

### Retrospective fit

This frame explains why Sanhua can simultaneously have:

- stable segment margins;
- mature refrigeration growth in some periods;
- faster automotive growth;
- good cash generation;
- a premium market multiple;
- legitimate liquid-cooling / robot upside;
- yet insufficient evidence to place large new-business profit in the base case.

### Prospective discrimination

If the franchise/compounder frame is correct:

- core refrigeration and automotive earnings should remain resilient without requiring robot success;
- segment margins should stay broadly stable through normal input / FX / volume fluctuations;
- cash conversion should remain healthy;
- new businesses should be additive rather than required to defend the core earnings floor.

If the optionality-premium frame dominates:

- core growth should decelerate toward mature-industrial levels;
- valuation support should increasingly depend on robot/liquid-cooling milestones;
- delays in new-business revenue / margins should create much more valuation risk than core operating deterioration alone would imply.

```text

+ automotive grows high-single / low-double digits
+ segment margins remain near historical range

```

This world is closest to the current published expectation center.

That makes it an important market world to underwrite, not a truth claim.

### World C — Core compounding + measurable liquid-cooling contribution

Illustrative 2027 parent NP anchor: **~CNY5.7–6.4bn**.

```text
core businesses remain healthy
+ data-center liquid cooling scales from current commercial supply
→ new revenue becomes separately economically visible
→ contribution is meaningful but does not require humanoid mass adoption
```

This world is easier to underwrite than a robot breakout because liquid cooling already has product supply to some global customers, but the current PIT still lacks standalone profit economics.

### World D — Adjacent-business scaling / robot right tail

Illustrative 2027 parent NP anchor: **>CNY6.4bn**, with **>CNY7.5bn** requiring a much stronger robot contribution.

```text
core remains intact
+ robot batch delivery converts to repeatable customer allocation
+ production-line ramp achieves usable yield / utilization
+ ASP and margins support attractive economics
+ liquid cooling also contributes
→ new businesses become material group profit engines
```

This world requires several currently unobserved links:

```text
batch delivery
→ sustained allocation
→ volume
→ revenue
→ margin
→ cash conversion
→ incremental ROIC
```

A large humanoid TAM is not evidence that these links have already resolved.

### World coverage assessment

These worlds are sufficient to represent the current public-PIT debate.

The important methodological issue is that **World A/B probability is supported by a much richer realized core history than World C/D probability**.

That asymmetry should be preserved rather than hidden inside one smooth five-state distribution.

## 11. Anchoring audit

Sanhua presents a different anchoring risk from GigaDevice.

Because sell-side 2027 forecasts are tightly clustered near CNY5.4–5.5bn, a researcher can easily mistake **consensus agreement** for **fundamental probability evidence**.

The correct use is narrower:

- the cluster proves that CNY5.3–5.8bn is a serious published Market Belief envelope;
- same-house revisions help reveal which business drivers analysts changed;
- analyst reasoning can expose variables worth checking;
- the narrowness of consensus does **not** create a base rate or a probability distribution for the core business;
- no number of robot-themed research notes can turn unreported unit economics into realized evidence.

The post-expectation Fundamental Belief therefore remains:

> **Core earnings are better constrained than in the first two dogfood cases, and a ~CNY5bn-plus 2027 core world is economically plausible from realized history; however, exact core probabilities and optionality probabilities require different evidence and should not be collapsed simply because sell-side estimates cluster tightly.**

## 12. Probability Qualification Review

### 12.1 What is materially better established than in YTO / GigaDevice

The core business supplies real probability-relevant structure:

1. **Multi-year realized history exists.** Segment revenue and gross margins can be observed across multiple years.
2. **The core reference frame is relatively stable.** HVAC / auto thermal components remain the economic center; the company is not undergoing a wholesale model-class transition.
3. **Core margins are historically bounded.** Refrigeration / automotive gross margins around 27–29% provide a useful empirical range.
4. **H1 2026 does not represent an obvious peak-margin regime.** The core margin is near historical levels, unlike GigaDevice storage at 67.57%.
5. **Cash conversion is observable.** H1 OCF remains strong relative to profit.
6. **A core slowdown world requires identifiable operating deterioration rather than a hidden regime change.**

Therefore the evidence can support stronger ordinal statements such as:

> **A stable-core world is better grounded than either a severe unexplained core collapse or a large robot-driven 2027 earnings jump.**

### 12.2 Why exact core probabilities are still not fully established

Even the core does not yet justify exact `15/25/35` weights from this PIT record alone.

Reasons:

1. **Historical driver distributions were not formally reconstructed.** We have useful realized ranges, not a calibrated conditional distribution for 2027 refrigeration / automotive growth.
2. **FX, customer mix, commodity pass-through and auto platform cycles interact.** Their joint distribution is not represented by one narrow consensus range.
3. **Consensus is expectation evidence, not a prior.** A 20-house cluster does not mechanically become a probability distribution.
4. **Terminal multiple is not the same uncertainty as earnings.** A premium qualified-component franchise can be valued very differently at the same 2027 NP depending on duration and new-business credibility.

The core is therefore **more probability-ready**, but exact cardinal weights remain more precise than the current dogfood can defend.

### 12.3 Why optionality probability is clearly not established

Liquid cooling and robot actuators currently provide commercialization evidence, not enough realized economics for cardinal probability.

For robots in particular, several links remain open:

```text
batch delivery
→ repeatable customer allocation
→ annualized volume
→ ASP
→ revenue
→ gross margin
→ capex / working capital
→ incremental ROIC
```

Assigning exactly 5% to an CNY8.5bn right tail is therefore a **research proposal**, not an empirically calibrated probability.

The same problem, to a lesser degree, applies to a CNY6.5bn `new_business_success` world.

### 12.4 Current qualification verdict

```text
CORE WORLD COVERAGE                  = SUFFICIENT
CORE ORDINAL PROBABILITY KNOWLEDGE   = MEANINGFUL
CORE CARDINAL PROBABILITIES          = NOT FULLY ESTABLISHED
LIQUID-COOLING OPTIONALITY PROB       = NOT ESTABLISHED
ROBOT OPTIONALITY PROBABILITY         = NOT ESTABLISHED
TOTAL-COMPANY CARDINAL MEASURE        = NOT ESTABLISHED
PROBABILITY-WEIGHTED EV               = WITHHELD IN THIS DOGFOOD
NUMERICAL ODDS                        = WITHHELD IN THIS DOGFOOD
```

Therefore the existing Full Research v1 `15/25/35/20/5` should be described as:

> **a frozen historical probability proposal that mixes a relatively well-grounded core with much less-qualified optionality probabilities.**

That is the key methodological learning from Sanhua.

## 14. Resolution paths / reopen triggers

Research should reopen when one or more of these become observable:

1. **Core refrigeration:** sustained departure from historical revenue / margin behavior.
2. **Automotive:** material change in growth, content per vehicle, customer mix or segment margin.
3. **Core cash conversion / ROIC:** OCF deterioration or global-expansion capex that fails to create adequate returns.
4. **Liquid cooling:** separately observable revenue, margin, customer scale or capital-return evidence.
5. **Robots:** repeatable allocation, volume, ASP, margin and utilization rather than only batch-delivery language.
6. **Matched estimate revisions:** same-house changes that reveal new Market Belief about core versus optionality.
7. **Valuation surface:** material price change can reopen Odds / market-compatible-world analysis, but must not silently change Fundamental Belief.

## 17. Failure-attribution lens for later review

If later results differ materially, inspect:

- **Evidence Failure:** were reported segment / IR records wrong?
- **Classification Failure:** did management commercialization statements get promoted into future realized economics?
- **Reference Frame Failure:** was the core less durable than the qualified-franchise frame assumed, or did new businesses become the dominant economic engine faster than expected?
- **Inference Failure:** did stable historical margins fail to imply the future resilience we inferred?
- **Assumption Failure:** did core growth, FX, customer mix or new-business conversion fail?
- **Probability Failure:** were the causal worlds reasonable but our eventual weights badly calibrated?
- **Valuation Failure:** did earnings land near expectations but premium duration / terminal multiple prove wrong?
- **Odds Failure:** was Fundamental Belief reasonable but the price / share-class expression unattractive?
- **Exogenous Surprise:** only after those layers are inspected.

Sanhua is particularly useful for testing whether **optionality attribution** should remain distinct from core-underwriting error.

```text
Research complete enough to stop
→ core probability structure is materially stronger
→ exact core weights still not fully calibrated
→ optionality probability NOT ESTABLISHED
→ total-company cardinal measure NOT ESTABLISHED
→ Numerical Odds withheld
```

This third case adds an important qualification:

> **The problem is not that all investing is “too uncertain for probability.” Probability support can be much stronger for one part of the business than another. The current Kernel scenario model encourages those heterogeneous uncertainty qualities to be collapsed into a single complete probability measure.**

That is more specific evidence of potential probability theater than simply saying uncertainty exists.

## 19. Constitution-review threshold — strengthened, not yet closed

Before dogfood, the working Constitution-review trigger was:

> If multiple different business models repeatedly produce Research that is complete and Human-useful while numerical probability is not genuinely supportable, then review whether `Research Commit` must imply `Probability Commit`.

Three live cases now support opening that question seriously:

1. YTO: no trustworthy total-world probabilities.
2. GigaDevice: ordinal / tail probability knowledge, but no qualified cardinal distribution.
3. Sanhua: better-constrained core, but optionality probabilities remain unqualified and contaminate a one-layer total-company measure.

However, this dogfood still does **not** authorize a code change.

One important validation remains before a Constitution proposal:

> **Run the same Decision Hygiene framework against at least one historical case where the Human / system investment judgment was materially wrong, using strict PIT reconstruction, and test whether the new distinctions improve failure attribution rather than merely making current research sound more sophisticated.**

That historical negative-control case should come before any architecture PR.
