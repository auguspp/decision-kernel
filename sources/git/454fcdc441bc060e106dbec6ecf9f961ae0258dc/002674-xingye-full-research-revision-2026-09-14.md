## 1. 修订原因

本轮最初把兴业科技近似理解为“可修复的皮革主业 + 磷化铟新业务期权”，并主要用旧业务与新业务同向好坏的对角线世界做压力测试。Human 质疑后，发现这会遗漏该公司的关键转型世界：

```text
旧业务经济价值继续衰减
+
磷化铟业务真实兑现并逐渐接管利润与资本配置
```

因此旧模型不能继续作为当前 Research authority。算术结果若来自错误 Reference Frame，即使数字后来碰巧接近，也不能以数值相似证明旧模型有效。

## 2. 当前 Reference Frame

```text
LEGACY ECONOMIC DECAY
+ CAPITAL REALLOCATION
+ EARLY InP INDUSTRIAL TRANSITION
+ UNRESOLVED DISCLOSURE / GOVERNANCE RISK
```

这不是“皮革收入正在崩塌”的判断。现有证据更支持：传统皮革收入总体尚未持续下降，但利润、ROE、增量资本效率及部分业务毛利率已经明显承压；同时公司仍在扩产，资本占用不能被忽略。

## 3. 传统皮革业务 — 当前 Belief

### 已支持

- 2023–2025 集团收入没有持续萎缩，但归母利润由约 CNY1.86亿元降至约 CNY1.01亿元，ROE降至约4.19%。
- 2026H1鞋包皮革收入与毛利率有局部修复；汽车皮革收入基本持平，但毛利率明显下降，宏兴汽车皮革利润同比大幅承压。
- 2026H1皮革总产能同比显著增加，而产能利用率仍约65%附近，说明不能用“扩产”本身证明新增资本回报。

### 当前解释

```text
LEGACY REVENUE COLLAPSE = NOT ESTABLISHED
LEGACY ECONOMIC-PROFIT DECAY = MATERIALLY SUPPORTED
LEGACY HIGH-RETURN GROWTH REBASE = NOT ESTABLISHED
```

未来估值必须同时问利润水平、资本继续占用、现金回报和增量ROIC，不能只问“还能赚多少钱”。

## 4. 磷化铟业务 — 当前 Belief

### 已支持

- 2026-07 正式签署 CNY55m 磷化铟相关资产组收购协议；买入的是相关设备、人员、知识产权、合同和业务关系，不是卖方全部半导体业务。
- 相关资产组已经具有2英寸、3英寸工艺、客户认证与小批量交付记录。
- 2025年标的收入约 CNY4.44m、仍亏损；2026年前5个月收入约 CNY2.34m、仍亏损。

交易不存在全国排他性：正式限制主要是不在江苏邳州新建相关产线；卖方相关体系仍公开从事磷化铟等半导体材料业务。因此不能把本次收购写成“买断整个卖方体系的InP能力”。

## 5. 行业外部尺度

行业需求是真实的，不能因为兴业当前基数极小就把数亿元收入视为行业不可能：

- AXT 已披露数据中心光互连需求推动InP收入明显增长，并存在客户预付款、长期供应/产能承诺等更高等级商业证据；
- 云南锗业已有较大InP产能及实际产量，并披露过数亿元级长期供货合同；
- JX Advanced Metals 等供应商同时在大幅扩产。

这些同行证据只用于说明“产业规模可能达到什么数量级”和“成熟产业化应出现什么证据”，不证明兴业科技获得同样订单、良率、利润率或发生概率。

## 6. Proof ladder — 不得越级

对转型新业务，今后按以下证据梯度判断：

```text
收购意向 / 项目备案
→ 真实资产、团队、IP完成迁移
→ 客户认证
→ 小批量交付
→ 重复采购
→ 千万级及更大订单
→ 可观产能稳定爬坡
→ 良率 / ASP / 毛利可验证
→ 经营现金回款
→ 扩产后的ROIC仍可接受
```

兴业当前已经越过“只有概念”的阶段，但尚不能从认证/小批交付直接升级到规模化利润。
