# 苏垦农发：价格领先之后，先查净收益而不是套用粮价受益叙事

2026-09-11完成的有限Pre/Quick；市场观察截至2026-09-09，业务材料为2026H1报告选页。**本案没有新增需要Human作投资判断的事项。**

## 这次研究改变了什么

苏垦进入研究，是因为粮食种植两个已保存成员的共同5日、20日比较：苏垦分别上涨14.48%、24.91%，北大荒为9.87%、15.52%。苏垦是这两个窗口的价格领先候选，北大荒是主要成交载体候选；不是单日排名、全市场优选或基本面龙头认证。苏垦60日跨分红，不能拿未复权切片直接排名。原比较见[保存的成员阅读](https://github.com/auguspp/decision-kernel/blob/d8775e5eba1ac7e6d290716686d4fcff82ec040b/docs/readings/sector-member-2026-09-09.md)。

**新的认识不是“粮价涨，所以苏垦利润涨”，而是“自产粮收益与外购加工、农资成本要放在合并口径一起看”。** 报告第11—13页显示，苏垦既种植和销售稻麦，也经营种业、大米、麦芽、食用油加工与购销、农资和社会化服务。大米加工原粮以自产为主、外购为辅，麦芽原料以进口为主，食用油加工需要外购原料。其他条件不变时，自产商品粮外销涨价可能增加收益；外购原料与农资涨价却可能压缩价差。内部供应不能重复计算成新增合并利润。这些是有来源支持的业务映射和条件推断，不是已量化的净利润敏感性。

反证不能省略：第7页披露2026H1收入43.32亿元，同比-5.59%；归母净利润1.44亿元，同比-32.48%；扣非归母1.16亿元，同比-33.85%；经营现金流1.67亿元，同比-76.84%。第19—20页将经营现金流下降主要归因于上年同期销售库存小麦增加，以及本期农资价格上涨和采购备货增加。货币资金增加主要与江苏种业增资扩股相关，不能当作经营回款改善。这里不能把全部利润下降归因于粮价，也不能推断下半年方向。

**最值得保留的问题：自产粮销售收益，能否覆盖农资与外购加工成本的变化，并真正变成归母利润和经营现金流？** 分业务利润权重、自产外销与内部供应比例、采购/库存时点、合并抵销后的净敞口、半年报后的变化和市场预期仍未核验。
