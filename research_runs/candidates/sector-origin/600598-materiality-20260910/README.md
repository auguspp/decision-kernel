6月23日公司公告[2]披露：16家农业分公司从非职工家庭农场取得的土地承包费收入不应享受所述所得税优惠；需补缴2021—2025年所得税约10.24亿元、滞纳金约3.86亿元，合计约14.10亿元。公司预计计入2026年当期损益。该额约相当于2025归母净利润11.66亿元的1.21倍、经营现金流净额12.40亿元的1.14倍。后两个比较仅说明量级，不是现金余额测试，也不说明每年重复发生同额费用。

7月14日业绩预告[3]预计上半年归母亏损约5.37亿元、扣非亏损约2.09亿元，并说明六月税费是主要原因。这仍是未经审计的预告，不冒充最终半年报实际值或当前支付凭证。

## 真正要区分的两种解释

仅把14.10亿元加回并维持旧盈利基准，可能忽略以后年度税负；反过来，把跨五年的补税及滞纳金当作每年费用，又会夸大持续损失。两者都是需要证据区分的解释，当前并未核验市场实际采取哪种定价。

最有辨识力的资料不是又一个行业涨幅，而是最终半年报中的所得税、历史费用入账及支付、可用现金，以及后续年度税惠适用范围、税基和土地合同收费。若持续税负重要且无法由收费/效率改善抵消，正常税后盈利要下修；若影响主要为历史结算且经常性影响可控，则不能机械把历史总额年化。上述均为条件推理，尚无对应量化预测。
